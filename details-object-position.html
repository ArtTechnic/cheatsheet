object-position

Choose object-position when the design needs different position of replaced content. It helps decide where an element sits and how it relates to nearby boxes.

Different values give object-position different instructions.

Use this object-position sample as a starting point, then change one piece at a time:

object-position: 50% 50%;

What this example does: Here, 50% 50% is the value attached to object-position.
