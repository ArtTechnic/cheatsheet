font-synthesis-weight

The browser looks at font-synthesis-weight when working out whether weight is synthesized. It changes the presentation or flow of writing.

CSS reads this as the name font-synthesis-weight, a colon, and then a value.

A practical font-synthesis-weight example is shown below:

/* Keyword values */
font-synthesis-weight: auto;
font-synthesis-weight: none;

/* Global values */
font-synthesis-weight: inherit;
font-synthesis-weight: initial;
font-synthesis-weight: revert;
font-synthesis-weight: revert-layer;
font-synthesis-weight: unset;

What this example does: The important instruction in the sample is auto. It is assigned to font-synthesis-weight and changes only the part described above.
