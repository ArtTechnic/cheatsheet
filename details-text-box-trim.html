text-box-trim

With text-box-trim, you can control trims text box overflow. It changes the presentation or flow of writing.

CSS reads this as the name text-box-trim, a colon, and then a value. As you compare values, test several lines, long words, and zoomed text—a single short sentence can hide problems.

Here is a text-box-trim example to try in a practice page:

/* Keywords */
text-box-trim: none;
text-box-trim: trim-both;
text-box-trim: trim-start;
text-box-trim: trim-end;

/* Global values */
text-box-trim: inherit;
text-box-trim: initial;
text-box-trim: revert;
text-box-trim: revert-layer;
text-box-trim: unset;

What this example does: Here, none is the value attached to text-box-trim. Change it, refresh the page, and compare the new result with the original.
