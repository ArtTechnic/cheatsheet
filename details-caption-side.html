caption-side

The caption-side property tells you where the caption of a table should go. You can put it above the table (that is called top) or below the table (that is called bottom). By default the caption sits on top.

All you need is one line of CSS to move the caption to the bottom. The example below puts it underneath the table.

table {
    caption-side: bottom;
}
