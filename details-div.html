div

In an HTML document, div represents generic container. Think of it as an HTML building block specifically meant for generic container.

The opening div tag starts its area and the matching closing tag ends it. Use it when that description matches the content, not simply because its default appearance seems useful.

Try the following div code in a spare practice file:

<div class="warning">
  <img
    src="https://mdn.github.iohttps://mdn.github.iohttps://mdn.github.io/shared-assets/images/examples/leopard.jpg"
    alt="An intimidating leopard." />
  <p>Beware of the leopard</p>
</div>

Reading the example: Start with the div tag in the code, then inspect what sits inside it and which attributes have been added to its opening tag.
