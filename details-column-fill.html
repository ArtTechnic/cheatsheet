column-fill

Think of column-fill as the control for how columns are filled. It controls how content is divided across columns, pages, or separate pieces.

A rule using column-fill needs a value after the colon. One useful test is to change only that value; the browser may need enough content before the effect becomes obvious.

A small column-fill example looks like this:

column-fill: auto;

The important part: Here, auto is the value attached to column-fill. Change it, refresh the page, and compare the new result with the original.
