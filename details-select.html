select

The name select tells you what it represents: drop-down list. It is a form building block: forms let a visitor enter information, choose something, or start an action.

Put the content belonging to select between its opening and closing tags. Every control needs a clear label, and the page should still make sense when somebody uses only a keyboard.

The code below shows a simple use of select:

<label for="pet-select">Choose a pet:</label>

<select name="pets" id="pet-select">
  <option value="">--Please choose an option--</option>
  <option value="dog">Dog</option>
  <option value="cat">Cat</option>
  <option value="hamster">Hamster</option>
  <option value="parrot">Parrot</option>
  <option value="spider">Spider</option>
  <option value="goldfish">Goldfish</option>
</select>

Reading the example: This sample puts select into a small piece of realistic HTML. Change its content or one attribute at a time and watch what differs.
