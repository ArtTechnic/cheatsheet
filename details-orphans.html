orphans

Think of orphans as the control for minimum lines left at bottom of page. It controls how content is divided across columns, pages, or separate pieces.

Add orphans inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: The browser may need enough content before the effect becomes obvious.

Here is an orphans example to try in a practice page:

/* <integer> values */
orphans: 2;
orphans: 3;

/* Global values */
orphans: inherit;
orphans: initial;
orphans: revert;
orphans: revert-layer;
orphans: unset;

What to notice: The sample asks the browser to use 2 for orphans. The property stays the same when you experiment; the value is the part to change.
