grid-auto-rows

Changing grid-auto-rows changes size of auto-generated grid rows. It helps arrange children inside a layout.

The value written after grid-auto-rows: chooses the result.

Try the following grid-auto-rows code in a spare practice file:

grid-auto-rows: auto;

The important part: The colon separates grid-auto-rows from its chosen value, auto.
