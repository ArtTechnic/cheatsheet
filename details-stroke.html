stroke

With stroke, you can control sVG stroke color.

CSS reads this as the name stroke, a colon, and then a value.

A small stroke example looks like this:

/* assorted color values */
stroke: rgb(153 51 102 / 1);
stroke: color-mix(in lch, var(--primaryColor) 35%, gray 15%);
stroke: dodgerblue;
stroke: currentColor;
stroke: transparent;
stroke: context-stroke;

/* Global values */
stroke: inherit;
stroke: initial;
stroke: revert;
stroke: revert-layer;
stroke: unset;

How this sample works: In this case stroke receives rgb(153 51 102 / 1).
