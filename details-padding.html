padding

Choose padding when the design needs different inner spacing. It changes space around, inside, or between boxes.

Add padding inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Add a temporary border while practising so you can see exactly which space moved.

This short sample shows padding in use:

padding: 1em;

What to notice: Here, 1em is the value attached to padding. Change it, refresh the page, and compare the new result with the original.
