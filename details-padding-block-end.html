padding-block-end

Think of padding-block-end as the control for padding on block end edge. It changes space around, inside, or between boxes.

CSS reads this as the name padding-block-end, a colon, and then a value. As you compare values, add a temporary border while practising so you can see exactly which space moved.

A practical padding-block-end example is shown below:

padding-block-end: 20px;
writing-mode: horizontal-tb;

How this sample works: Here, 20px is the value attached to padding-block-end. Change it, refresh the page, and compare the new result with the original.
