mask-origin

With mask-origin, you can control origin box of mask.

The value written after mask-origin: chooses the result.

This short sample shows mask-origin in use:

/* Keyword values */
mask-origin: content-box;
mask-origin: padding-box;
mask-origin: border-box;
mask-origin: fill-box;
mask-origin: stroke-box;
mask-origin: view-box;

/* Multiple values */
mask-origin: padding-box, content-box;
mask-origin: view-box, fill-box, border-box;

/* Global values */
mask-origin: inherit;
mask-origin: initial;
mask-origin: revert;
mask-origin: revert-layer;
mask-origin: unset;

The important part: The sample asks the browser to use content-box for mask-origin.
