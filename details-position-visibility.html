position-visibility

Think of position-visibility as the control for visibility based on anchor. It helps decide where an element sits and how it relates to nearby boxes.

Add position-visibility inside a CSS rule and follow it with a colon and value.

This short sample shows position-visibility in use:

/* Single values */
position-visibility: always;
position-visibility: anchors-valid;
position-visibility: anchors-visible;
position-visibility: no-overflow;

/* Global values */
position-visibility: inherit;
position-visibility: initial;
position-visibility: revert;
position-visibility: revert-layer;
position-visibility: unset;

Reading the example: The sample asks the browser to use always for position-visibility.
