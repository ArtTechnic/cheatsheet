offset-position

Use offset-position when you need to change anchor position for offset. It helps decide where an element sits and how it relates to nearby boxes.

The value written after offset-position: chooses the result. While experimenting, keep in mind that positioning properties work as a team, so inspect the containing box as well as the element itself.

Here is an offset-position example to try in a practice page:

/* Keyword values */
offset-position: normal;
offset-position: auto;
offset-position: top;
offset-position: bottom;
offset-position: left;
offset-position: right;
offset-position: center;

/* <percentage> values */
offset-position: 25% 75%;

/* <length> values */
offset-position: 0 0;
offset-position: 1cm 2cm;
offset-position: 10ch 8em;

/* Edge offsets values */
offset-position: bottom 10px right 20px;
offset-position: right 3em bottom 10px;
offset-position: bottom 10px right;
offset-position: top right 10px;

/* Global values */
offset-position: inherit;
offset-position: initial;
offset-position: revert;
offset-position: revert-layer;
/* More lines are shown on MDN. */

What this example does: This declaration gives offset-position the value normal. Replace that value with another valid choice to compare the two results.
