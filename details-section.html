section

The section tag marks part of the page as thematic grouping. It identifies what kind of section this is, rather like putting a label on a folder before placing papers inside it.

The opening section tag starts its area and the matching closing tag ends it. Choose it because the content has that meaning. If you only need an unlabelled box for styling, a div may be the clearer choice.

Here is a section example to try in a practice page:

<h1>Choosing an Apple</h1>
<section>
  <h2>Introduction</h2>
  <p>
    This document provides a guide to help with the important task of choosing
    the correct Apple.
  </p>
</section>

<section>
  <h2>Criteria</h2>
  <p>
    There are many different criteria to be considered when choosing an Apple —
    size, color, firmness, sweetness, tartness...
  </p>
</section>

What this example does: Here section supplies the meaning described above; the surrounding tags provide the context needed for the example to make sense.
