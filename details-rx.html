rx

Place a colon after rx, then supply the value you want.

Here is a compact rx example you can inspect and alter:

/* Initial value */
rx: auto;

/* Length and percentage values */
rx: 20px;
rx: 20%;

/* Global values */
rx: inherit;
rx: initial;
rx: revert;
rx: revert-layer;
rx: unset;

The important part: The sample asks the browser to use auto for rx.
