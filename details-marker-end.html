marker-end

Use marker-end when you need to change marker at end of element. It changes list markers, numbering, or generated punctuation.

A rule using marker-end needs a value after the colon.

Here is a marker-end example to try in a practice page:

marker-end: none;
marker-end: url("markers.svg#arrow");

/* Global values */
marker-end: inherit;
marker-end: initial;
marker-end: revert;
marker-end: revert-layer;
marker-end: unset;

What this example does: The important instruction in the sample is none. It is assigned to marker-end and changes only the part described above.
