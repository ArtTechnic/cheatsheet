center

In an HTML document, center represents deprecated centering. Think of it as an HTML building block specifically meant for deprecated centering.

The opening center tag starts its area and the matching closing tag ends it. Use it when that description matches the content, not simply because its default appearance seems useful.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

Try the following center code in a spare practice file:

<center>
  This text will be centered.
  <p>So will this paragraph.</p>
</center>

What to notice: The key piece in this sample is <center>. Read outward from that tag to see what belongs to it and how it is configured.
