print-color-adjust

The browser looks at print-color-adjust when working out color and image fidelity for printing. It changes how something looks rather than changing what the HTML means.

The value written after print-color-adjust: chooses the result. While experimenting, keep in mind that check that text remains easy to read and that important information does not depend on colour alone.

This short sample shows print-color-adjust in use:

print-color-adjust: economy;
print-color-adjust: exact;

/* Global values */
print-color-adjust: inherit;
print-color-adjust: initial;
print-color-adjust: revert;
print-color-adjust: revert-layer;
print-color-adjust: unset;

How this sample works: Here, economy is the value attached to print-color-adjust. Change it, refresh the page, and compare the new result with the original.
