nav

When you write nav, you are marking something as navigation links. It identifies what kind of section this is, rather like putting a label on a folder before placing papers inside it.

Anything meant to belong to nav normally sits inside the pair of tags. Choose it because the content has that meaning. If you only need an unlabelled box for styling, a div may be the clearer choice.

Try the following nav code in a spare practice file:

<nav class="crumbs">
  <ol>
    <li class="crumb"><a href="#">Bikes</a></li>
    <li class="crumb"><a href="#">BMX</a></li>
    <li class="crumb">Jump Bike 3000</li>
  </ol>
</nav>

<h1>Jump Bike 3000</h1>
<p>
  This BMX bike is a solid step into the pro world. It looks as legit as it
  rides and is built to polish your skills.
</p>

Reading the example: Start with the nav tag in the code, then inspect what sits inside it and which attributes have been added to its opening tag.
