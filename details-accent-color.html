accent-color

The accent-color property controls uI accent color for form controls. It changes how something looks rather than changing what the HTML means.

CSS reads this as the name accent-color, a colon, and then a value. As you compare values, check that text remains easy to read and that important information does not depend on colour alone.

This short sample shows accent-color in use:

accent-color: red;

How this sample works: Here, red is the value attached to accent-color. Change it, refresh the page, and compare the new result with the original.
