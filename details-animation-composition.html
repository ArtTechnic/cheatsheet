animation-composition

The animation-composition property controls how animation handles conflicting animatable properties. It helps decide where an element sits and how it relates to nearby boxes.

Different values give animation-composition different instructions. Try them one at a time, and remember that positioning properties work as a team, so inspect the containing box as well as the element itself.

This short sample shows animation-composition in use:

/* Single animation */
animation-composition: replace;
animation-composition: add;
animation-composition: accumulate;

/* Multiple animations */
animation-composition: replace, add;
animation-composition: add, accumulate;
animation-composition: replace, add, accumulate;

/* Global values */
animation-composition: inherit;
animation-composition: initial;
animation-composition: revert;
animation-composition: revert-layer;
animation-composition: unset;

What this example does: This declaration gives animation-composition the value replace. Replace that value with another valid choice to compare the two results.
