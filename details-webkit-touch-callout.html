-webkit-touch-callout

In CSS, -webkit-touch-callout is the setting for defines the -webkit-touch-callout property. It changes part of the way a visitor interacts with an element.

Place a colon after -webkit-touch-callout, then supply the value you want. When testing this property, remember: do not make an object look clickable unless it really performs an action.

Important: This is not a standard feature, so different browsers may handle it differently. Treat it as something to recognize rather than a dependable first choice.

A practical -webkit-touch-callout example is shown below:

/* Keyword values */
-webkit-touch-callout: default;
-webkit-touch-callout: none;

/* Global values */
-webkit-touch-callout: initial;
-webkit-touch-callout: inherit;
-webkit-touch-callout: revert;
-webkit-touch-callout: revert-layer;
-webkit-touch-callout: unset;

Reading the example: This declaration gives -webkit-touch-callout the value default. Replace that value with another valid choice to compare the two results.
