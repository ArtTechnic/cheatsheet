box-direction

With box-direction, you can control direction of box content layout. It changes one particular part of the browser’s styling calculation.

A rule using box-direction needs a value after the colon. One useful test is to change only that value; change only this property while practising, then compare the before and after result.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

This short sample shows box-direction in use:

/* Keyword values */
box-direction: normal;
box-direction: reverse;

/* Global values */
box-direction: inherit;
box-direction: initial;
box-direction: revert;
box-direction: revert-layer;
box-direction: unset;

What to notice: In this case box-direction receives normal. Trying a contrasting valid value makes the difference easier to spot.
