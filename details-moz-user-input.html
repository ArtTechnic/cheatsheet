-moz-user-input

The browser looks at -moz-user-input when working out defines the -moz-user-input property. It changes one particular part of the browser’s styling calculation.

CSS reads this as the name -moz-user-input, a colon, and then a value. As you compare values, change only this property while practising, then compare the before and after result.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

A practical -moz-user-input example is shown below:

/* Keyword values */
-moz-user-input: auto;
-moz-user-input: none;

/* Global values */
-moz-user-input: inherit;
-moz-user-input: initial;
-moz-user-input: unset;

The important part: This declaration gives -moz-user-input the value auto. Replace that value with another valid choice to compare the two results.
