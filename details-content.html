content

Choose content when the design needs different generated content. It changes one particular part of the browser’s styling calculation.

CSS reads this as the name content, a colon, and then a value. As you compare values, change only this property while practising, then compare the before and after result.

This short sample shows content in use:

.topic-games::before {
  content: "🎮 " / "games";
}

.topic-weather::before {
  content: "⛅ " / "cloudy";
}

.topic-hot::before {
  content: url("https://mdn.github.iohttps://mdn.github.iohttps://mdn.github.io/shared-assets/images/examples/fire.png") / "On fire";
  margin-right: 6px;
}

What to notice: The sample asks the browser to use "🎮 " / "games" for content. The property stays the same when you experiment; the value is the part to change.
