mask-mode

With mask-mode, you can control alpha or luminance for mask. It changes one particular part of the browser’s styling calculation.

A rule using mask-mode needs a value after the colon. One useful test is to change only that value; change only this property while practising, then compare the before and after result.

A practical mask-mode example is shown below:

/* Keyword values */
mask-mode: alpha;
mask-mode: luminance;
mask-mode: match-source;

/* Multiple values */
mask-mode: alpha, match-source;

/* Global values */
mask-mode: inherit;
mask-mode: initial;
mask-mode: revert;
mask-mode: revert-layer;
mask-mode: unset;

What to notice: The important instruction in the sample is alpha. It is assigned to mask-mode and changes only the part described above.
