-moz-force-broken-image-icon

Use -moz-force-broken-image-icon when you need to change defines the -moz-force-broken-image-icon property. It changes one particular part of the browser’s styling calculation.

Place a colon after -moz-force-broken-image-icon, then supply the value you want. When testing this property, remember: change only this property while practising, then compare the before and after result.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

Use this -moz-force-broken-image-icon sample as a starting point, then change one piece at a time:

-moz-force-broken-image-icon: 1;
-moz-force-broken-image-icon: 0;

/* Global values */
-moz-force-broken-image-icon: inherit;
-moz-force-broken-image-icon: initial;
-moz-force-broken-image-icon: revert;
-moz-force-broken-image-icon: revert-layer;
-moz-force-broken-image-icon: unset;

What to notice: In this case -moz-force-broken-image-icon receives 1. Trying a contrasting valid value makes the difference easier to spot.
