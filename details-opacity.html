opacity

The browser looks at opacity when working out transparency. It changes how something looks rather than changing what the HTML means.

Add opacity inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Check that text remains easy to read and that important information does not depend on colour alone.

Try the following opacity code in a spare practice file:

opacity: 0;

Reading the example: Read the line as ‘set opacity to 0.’ That value is the instruction controlling what you see.
