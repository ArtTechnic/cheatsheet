-webkit-tap-highlight-color

It changes how something looks rather than changing what the HTML means.

Add -webkit-tap-highlight-color inside a CSS rule and follow it with a colon and value.

Important: This is not a standard feature, so different browsers may handle it differently. Treat it as something to recognize rather than a dependable first choice.

Try the following -webkit-tap-highlight-color code in a spare practice file:

-webkit-tap-highlight-color: red;
-webkit-tap-highlight-color: transparent; /* for removing the highlight */

/* Global values */
-webkit-tap-highlight-color: inherit;
-webkit-tap-highlight-color: initial;
-webkit-tap-highlight-color: revert;
-webkit-tap-highlight-color: revert-layer;
-webkit-tap-highlight-color: unset;

Reading the example: This declaration gives -webkit-tap-highlight-color the value red.
