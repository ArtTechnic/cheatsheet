scroll-timeline-axis

The browser looks at scroll-timeline-axis when working out defines the scroll-timeline-axis property. It changes the presentation or flow of writing.

Different values give scroll-timeline-axis different instructions. Try them one at a time, and remember that test several lines, long words, and zoomed text—a single short sentence can hide problems.

Use this scroll-timeline-axis sample as a starting point, then change one piece at a time:

/* Logical property values */
scroll-timeline-axis: block;
scroll-timeline-axis: inline;

/* Physical property values */
scroll-timeline-axis: y;
scroll-timeline-axis: x;

/* Global values */
scroll-timeline-axis: inherit;
scroll-timeline-axis: initial;
scroll-timeline-axis: revert;
scroll-timeline-axis: revert-layer;
scroll-timeline-axis: unset;

Reading the example: The colon separates scroll-timeline-axis from its chosen value, block. The semicolon marks the end of this declaration.
