scroll-margin-right

In CSS, scroll-margin-right is the setting for defines the scroll-margin-right property. It changes space around, inside, or between boxes.

Place a colon after scroll-margin-right, then supply the value you want. When testing this property, remember: add a temporary border while practising so you can see exactly which space moved.

The code below shows a simple use of scroll-margin-right:

scroll-margin-right: 0;

The important part: This declaration gives scroll-margin-right the value 0. Replace that value with another valid choice to compare the two results.
