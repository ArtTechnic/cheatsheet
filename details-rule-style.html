rule-style

Changing rule-style changes defines the rule-style property. It changes one particular part of the browser’s styling calculation.

Add rule-style inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Change only this property while practising, then compare the before and after result.

Important: This feature is experimental. Check browser support before relying on it.

This short sample shows rule-style in use:

rule-style: solid;

How this sample works: Read the line as ‘set rule-style to solid.’ That value is the instruction controlling what you see.
