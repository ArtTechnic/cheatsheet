align-items

Choose align-items when the design needs different cross-axis alignment. It helps arrange children inside a layout.

Add align-items inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Some layout properties only work after the parent has been made a grid or flex container.

Use this align-items sample as a starting point, then change one piece at a time:

align-items: stretch;

The important part: Read the line as ‘set align-items to stretch.’ That value is the instruction controlling what you see.
