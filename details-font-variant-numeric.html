font-variant-numeric

Choose font-variant-numeric when the design needs different numeric variants for font. It changes the presentation or flow of writing.

Place a colon after font-variant-numeric, then supply the value you want.

Try the following font-variant-numeric code in a spare practice file:

font-variant-numeric: normal;

What this example does: This declaration gives font-variant-numeric the value normal.
