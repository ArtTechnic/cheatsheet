style

Browsers read style as a label meaning embedded CSS. This tag supports how a page is built or behaves rather than representing an ordinary paragraph or picture.

The opening style tag starts its area and the matching closing tag ends it. Place it in the correct part of the document and use it only when that extra behaviour or reusable structure is needed.

A small style example looks like this:

<style>
  p {
    color: #26b72b;
  }
  code {
    font-weight: bold;
  }
</style>

<p>
  This text will be green. Inline styles take precedence over CSS included
  externally.
</p>

<p style="color: blue">
  The <code>style</code> attribute can override it, though.
</p>

Reading the example: This sample puts style into a small piece of realistic HTML. Change its content or one attribute at a time and watch what differs.
