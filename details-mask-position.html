mask-position

In CSS, mask-position is the setting for position of mask image. It helps decide where an element sits and how it relates to nearby boxes.

Place a colon after mask-position, then supply the value you want. When testing this property, remember: positioning properties work as a team, so inspect the containing box as well as the element itself.

Here is a compact mask-position example you can inspect and alter:

/* Single <position> keyword value */
/* Sets second value to 'center' */
mask-position: left;
mask-position: center;
mask-position: right;
mask-position: top;
mask-position: bottom;

/* Two <position> keyword values */
mask-position: left center;
mask-position: right top;

/* One length or percentage <position> value */
/* Horizontal position. Vertical position set to 'center' */
mask-position: 25%;
mask-position: 0px;
mask-position: 8em;

/* Two length or percentage <position> values */
/* First value: horizontal position. Second value: vertical position */
mask-position: 25% 75%;
mask-position: 0px 0px;
mask-position: 10% 8em;

/* Edge offsets: Four <position> values */
mask-position: bottom 10px right 20px;
mask-position: right 3em bottom 10px;
mask-position: bottom 10px right 0;
/* More lines are shown on MDN. */

Reading the example: The important instruction in the sample is left. It is assigned to mask-position and changes only the part described above.
