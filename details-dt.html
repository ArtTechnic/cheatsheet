dt

In an HTML document, dt represents term/name in dl. It is one of the building blocks used to organise related items into a list instead of leaving them as loose paragraphs.

Treat the two dt tags like the covers of a folder: the related content goes between them. Lists have a container and items inside it, so check that each item is nested inside the correct kind of list.

This short sample shows dt in use:

<p>Please use the following paint colors for the new house:</p>

<dl>
  <dt>Denim (semigloss finish)</dt>
  <dd>Ceiling</dd>

  <dt>Denim (eggshell finish)</dt>
  <dt>Evening Sky (eggshell finish)</dt>
  <dd>Layered on the walls</dd>
</dl>

The important part: Here dt supplies the meaning described above; the surrounding tags provide the context needed for the example to make sense.
