box-sizing

The box-sizing property controls box sizing model. It changes one particular part of the browser’s styling calculation.

A rule using box-sizing needs a value after the colon. One useful test is to change only that value; change only this property while practising, then compare the before and after result.

This short sample shows box-sizing in use:

box-sizing: content-box;
width: 100%;

What this example does: This declaration gives box-sizing the value content-box. Replace that value with another valid choice to compare the two results.
