big

The big tag marks part of the page as deprecated larger text. Think of it as an HTML building block specifically meant for deprecated larger text.

Treat the two big tags like the covers of a folder: the related content goes between them. Use it when that description matches the content, not simply because its default appearance seems useful.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

A small big example looks like this:

<p>
  This is the first sentence.
  <big>This whole sentence is in bigger letters.</big>
</p>

What this example does: The key piece in this sample is <big>. Read outward from that tag to see what belongs to it and how it is configured.
