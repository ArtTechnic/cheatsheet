hyphenate-character

In CSS, hyphenate-character is the setting for character used for hyphenation. It changes the presentation or flow of writing.

Add hyphenate-character inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Test several lines, long words, and zoomed text—a single short sentence can hide problems.

A small hyphenate-character example looks like this:

hyphenate-character: auto;

The important part: The important instruction in the sample is auto. It is assigned to hyphenate-character and changes only the part described above.
