math-shift

In CSS, math-shift is the setting for shift behavior of MathML scripts.

The value written after math-shift: chooses the result.

Here is a compact math-shift example you can inspect and alter:

/* Keyword values */
math-shift: normal;
math-shift: compact;

/* Global values */
math-shift: inherit;
math-shift: initial;
math-shift: revert;
math-shift: revert-layer;
math-shift: unset;

How this sample works: In this case math-shift receives normal.
