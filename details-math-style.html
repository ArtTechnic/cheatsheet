math-style

Changing math-style changes style of MathML rendering. It changes one particular part of the browser’s styling calculation.

A rule using math-style needs a value after the colon. One useful test is to change only that value; change only this property while practising, then compare the before and after result.

Try the following math-style code in a spare practice file:

/* Keyword values */
math-style: normal;
math-style: compact;

/* Global values */
math-style: inherit;
math-style: initial;
math-style: revert;
math-style: revert-layer;
math-style: unset;

How this sample works: In this case math-style receives normal. Trying a contrasting valid value makes the difference easier to spot.
