box-align

With box-align, you can control alignment of content in box. It helps arrange children inside a layout.

The value written after box-align: chooses the result.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

Here is a compact box-align example you can inspect and alter:

/* Keyword values */
box-align: start;
box-align: center;
box-align: end;
box-align: baseline;
box-align: stretch;

/* Global values */
box-lines: inherit;
box-lines: initial;
box-lines: unset;

What to notice: Read the line as ‘set box-align to start.’ That value is the instruction controlling what you see.
