scroll-timeline

In CSS, scroll-timeline is the setting for defines the scroll-timeline property. It changes the presentation or flow of writing.

Different values give scroll-timeline different instructions. Try them one at a time, and remember that test several lines, long words, and zoomed text—a single short sentence can hide problems.

A small scroll-timeline example looks like this:

/* One value */
scroll-timeline: none;
scroll-timeline: --custom_name_for_timeline;

/* Two values */
scroll-timeline: --custom_name_for_timeline block;
scroll-timeline: --custom_name_for_timeline x;
scroll-timeline: none inline;
scroll-timeline: none y;

/* Global values */
scroll-timeline: inherit;
scroll-timeline: initial;
scroll-timeline: revert;
scroll-timeline: revert-layer;
scroll-timeline: unset;

Reading the example: In this case scroll-timeline receives none. Trying a contrasting valid value makes the difference easier to spot.
