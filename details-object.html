object

Use object when a piece of HTML represents fallback embeddable content. It places another resource or browsing area inside the current page, like making a window that looks into something else.

Anything meant to belong to object normally sits inside the pair of tags. Embedded material can affect security, speed, and accessibility, so include only resources you trust and actually need.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

Here is an object example to try in a practice page:

<object
  type="video/mp4"
  data="https://mdn.github.iohttps://mdn.github.iohttps://mdn.github.io/shared-assets/videos/flower.mp4"
  width="250"
  height="200"></object>

The important part: Start with the object tag in the code, then inspect what sits inside it and which attributes have been added to its opening tag.
