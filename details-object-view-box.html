object-view-box

Use object-view-box when you need to change viewport box for replaced elements.

A rule using object-view-box needs a value after the colon.

Important: This feature is experimental. Check browser support before relying on it.

Use this object-view-box sample as a starting point, then change one piece at a time:

object-view-box: inset(0 0);

What this example does: Read the line as ‘set object-view-box to inset(0 0).’ That value is the instruction controlling what you see.
