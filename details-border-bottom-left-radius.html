border-bottom-left-radius

The browser looks at border-bottom-left-radius when working out radius of bottom-left corner. It changes a line, edge, or corner around an element.

A rule using border-bottom-left-radius needs a value after the colon. One useful test is to change only that value; borders take up space in the box; outlines usually draw outside it without changing the layout.

A small border-bottom-left-radius example looks like this:

border-bottom-left-radius: 80px 80px;

What to notice: Here, 80px 80px is the value attached to border-bottom-left-radius. Change it, refresh the page, and compare the new result with the original.
