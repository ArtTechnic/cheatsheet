background-image

Use background-image when you need to change background image. It changes how something looks rather than changing what the HTML means.

The value written after background-image: chooses the result. While experimenting, keep in mind that check that text remains easy to read and that important information does not depend on colour alone.

Here is a compact background-image example you can inspect and alter:

background-image: url("https://mdn.github.iohttps://mdn.github.iohttps://mdn.github.io/shared-assets/images/examples/lizard.png");

Reading the example: The sample asks the browser to use url("https://mdn.github.iohttps://mdn.github.iohttps://mdn.github.io/shared-assets/images/examples/lizard.png") for background-image. The property stays the same when you experiment; the value is the part to change.
