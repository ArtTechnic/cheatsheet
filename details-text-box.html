text-box

The browser looks at text-box when working out shorthand for text box edge and trim. It changes the presentation or flow of writing.

Place a colon after text-box, then supply the value you want. When testing this property, remember: test several lines, long words, and zoomed text—a single short sentence can hide problems.

Try the following text-box code in a spare practice file:

/* Single keyword */
text-box: normal;

/* One text-box-edge keyword */
text-box: trim-start text;
text-box: trim-both text;

/* Two text-box-edge keywords */
text-box: trim-start cap alphabetic;
text-box: trim-both ex text;

/* Global values */
text-box: inherit;
text-box: initial;
text-box: revert;
text-box: revert-layer;
text-box: unset;

What to notice: The important instruction in the sample is normal. It is assigned to text-box and changes only the part described above.
