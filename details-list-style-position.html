list-style-position

Use list-style-position when you need to change position of list marker. It helps decide where an element sits and how it relates to nearby boxes.

A rule using list-style-position needs a value after the colon. One useful test is to change only that value; positioning properties work as a team, so inspect the containing box as well as the element itself.

Try the following list-style-position code in a spare practice file:

list-style-position: inside;

What to notice: Here, inside is the value attached to list-style-position. Change it, refresh the page, and compare the new result with the original.
