margin-block-start

The browser looks at margin-block-start when working out margin on block start edge. It changes space around, inside, or between boxes.

Different values give margin-block-start different instructions. Try them one at a time, and remember that add a temporary border while practising so you can see exactly which space moved.

This short sample shows margin-block-start in use:

margin-block-start: 20px;
writing-mode: horizontal-tb;

What this example does: In this case margin-block-start receives 20px. Trying a contrasting valid value makes the difference easier to spot.
