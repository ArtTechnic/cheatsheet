letter-spacing

The letter-spacing property controls space between letters. It changes space around, inside, or between boxes.

Add letter-spacing inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Add a temporary border while practising so you can see exactly which space moved.

Try the following letter-spacing code in a spare practice file:

letter-spacing: normal;

What to notice: The colon separates letter-spacing from its chosen value, normal. The semicolon marks the end of this declaration.
