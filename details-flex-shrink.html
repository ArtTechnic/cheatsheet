flex-shrink

The browser looks at flex-shrink when working out shrink factor. It helps arrange children inside a layout.

A rule using flex-shrink needs a value after the colon.

Try the following flex-shrink code in a spare practice file:

flex-shrink: 0;

Reading the example: In this case flex-shrink receives 0.
