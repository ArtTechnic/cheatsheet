border-end-end-radius

Use border-end-end-radius when you need to change radius of end edge in end direction. It changes a line, edge, or corner around an element.

Different values give border-end-end-radius different instructions. Try them one at a time, and remember that borders take up space in the box; outlines usually draw outside it without changing the layout.

Try the following border-end-end-radius code in a spare practice file:

border-end-end-radius: 80px 80px;

The important part: The colon separates border-end-end-radius from its chosen value, 80px 80px. The semicolon marks the end of this declaration.
