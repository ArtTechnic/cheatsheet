filter

Choose filter when the design needs different visual effects filter. It changes how something looks rather than changing what the HTML means.

The value written after filter: chooses the result.

The code below shows a simple use of filter:

filter: url("https://mdn.github.iohttps://mdn.github.iohttps://mdn.github.io/shared-assets/images/examples/shadow.svg#element-id");

How this sample works: Here, url("https://mdn.github.iohttps://mdn.github.iohttps://mdn.github.io/shared-assets/images/examples/shadow.svg#element-id") is the value attached to filter.
