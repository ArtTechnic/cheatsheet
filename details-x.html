x

Changing x changes x coordinate of SVG element. It changes one particular part of the browser’s styling calculation.

CSS reads this as the name x, a colon, and then a value. As you compare values, change only this property while practising, then compare the before and after result.

The code below shows a simple use of x:

/* length and percentage values */
x: 40px;
x: 40%;

/* Global values */
x: inherit;
x: initial;
x: revert;
x: revert-layer;
x: unset;

The important part: The colon separates x from its chosen value, 40px. The semicolon marks the end of this declaration.
