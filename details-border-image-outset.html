border-image-outset

Think of border-image-outset as the control for how far border image extends beyond border box. It changes a line, edge, or corner around an element.

Place a colon after border-image-outset, then supply the value you want.

Try the following border-image-outset code in a spare practice file:

border-image-outset: 0;

Reading the example: In this case border-image-outset receives 0.
