-moz-orient

With -moz-orient, you can control defines the -moz-orient property. It changes one particular part of the browser’s styling calculation.

Add -moz-orient inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Change only this property while practising, then compare the before and after result.

Important: This is not a standard feature, so different browsers may handle it differently. Treat it as something to recognize rather than a dependable first choice.

A small -moz-orient example looks like this:

-moz-orient: inline;

/* Global values */
-moz-orient: inherit;
-moz-orient: initial;
-moz-orient: revert;
-moz-orient: revert-layer;
-moz-orient: unset;

What to notice: Read the line as ‘set -moz-orient to inline.’ That value is the instruction controlling what you see.
