left

Changing left changes position offset left. It helps decide where an element sits and how it relates to nearby boxes.

The value written after left: chooses the result. While experimenting, keep in mind that positioning properties work as a team, so inspect the containing box as well as the element itself.

The code below shows a simple use of left:

left: 0;

How this sample works: This declaration gives left the value 0. Replace that value with another valid choice to compare the two results.
