stroke-opacity

Choose stroke-opacity when the design needs different opacity of stroke. It changes how something looks rather than changing what the HTML means.

CSS reads this as the name stroke-opacity, a colon, and then a value. As you compare values, check that text remains easy to read and that important information does not depend on colour alone.

Use this stroke-opacity sample as a starting point, then change one piece at a time:

/* numeric and percentage values */
stroke-opacity: 1;
stroke-opacity: 0.3;
stroke-opacity: 50%;

/* Global values */
stroke-opacity: inherit;
stroke-opacity: initial;
stroke-opacity: revert;
stroke-opacity: revert-layer;
stroke-opacity: unset;

How this sample works: The sample asks the browser to use 1 for stroke-opacity. The property stays the same when you experiment; the value is the part to change.
