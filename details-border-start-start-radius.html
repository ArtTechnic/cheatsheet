border-start-start-radius

The browser looks at border-start-start-radius when working out radius of start edge in start direction. It changes a line, edge, or corner around an element.

CSS reads this as the name border-start-start-radius, a colon, and then a value. As you compare values, borders take up space in the box; outlines usually draw outside it without changing the layout.

This short sample shows border-start-start-radius in use:

border-start-start-radius: 80px 80px;

What to notice: This declaration gives border-start-start-radius the value 80px 80px. Replace that value with another valid choice to compare the two results.
