corner-bottom-right-shape

Think of corner-bottom-right-shape as the control for shape of bottom-right corner. It helps decide where an element sits and how it relates to nearby boxes.

The value written after corner-bottom-right-shape: chooses the result. While experimenting, keep in mind that positioning properties work as a team, so inspect the containing box as well as the element itself.

Important: This feature is experimental. Check browser support before relying on it.

This short sample shows corner-bottom-right-shape in use:

/* Keyword values */
corner-bottom-right-shape: notch;
corner-bottom-right-shape: scoop;

/* superellipse() function values */
corner-bottom-right-shape: superellipse(1.7);
corner-bottom-right-shape: superellipse(-3);

/* Global values */
corner-bottom-right-shape: inherit;
corner-bottom-right-shape: initial;
corner-bottom-right-shape: revert;
corner-bottom-right-shape: revert-layer;
corner-bottom-right-shape: unset;

What this example does: In this case corner-bottom-right-shape receives notch. Trying a contrasting valid value makes the difference easier to spot.
