position-try-order

The browser looks at position-try-order when working out order of position tries. It helps arrange children inside a layout.

CSS reads this as the name position-try-order, a colon, and then a value. As you compare values, some layout properties only work after the parent has been made a grid or flex container.

Try the following position-try-order code in a spare practice file:

/* Keywords */
position-try-order: normal;
position-try-order: most-height;
position-try-order: most-width;
position-try-order: most-block-size;
position-try-order: most-inline-size;

/* Global values */
position-try-order: inherit;
position-try-order: initial;
position-try-order: revert;
position-try-order: revert-layer;
position-try-order: unset;

What this example does: The important instruction in the sample is normal. It is assigned to position-try-order and changes only the part described above.
