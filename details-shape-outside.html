shape-outside

The browser looks at shape-outside when working out defines the shape-outside property. It changes one particular part of the browser’s styling calculation.

CSS reads this as the name shape-outside, a colon, and then a value. As you compare values, change only this property while practising, then compare the before and after result.

A practical shape-outside example is shown below:

shape-outside: circle(50%);

What this example does: In this case shape-outside receives circle(50%). Trying a contrasting valid value makes the difference easier to spot.
