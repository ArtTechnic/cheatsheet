reading-flow

The reading-flow property controls reading order of elements.

The value written after reading-flow: chooses the result.

Important: This feature is experimental. Check browser support before relying on it.

Here is a reading-flow example to try in a practice page:

/* Keyword values */
reading-flow: normal;
reading-flow: flex-visual;
reading-flow: flex-flow;
reading-flow: grid-columns;
reading-flow: grid-rows;
reading-flow: grid-order;
reading-flow: source-order;

/* Global values */
reading-flow: inherit;
reading-flow: initial;
reading-flow: revert;
reading-flow: revert-layer;
reading-flow: unset;

Reading the example: The important instruction in the sample is normal. It is assigned to reading-flow and changes only the part described above.
