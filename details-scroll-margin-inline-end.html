scroll-margin-inline-end

In CSS, scroll-margin-inline-end is the setting for defines the scroll-margin-inline-end property. It changes space around, inside, or between boxes.

Add scroll-margin-inline-end inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Add a temporary border while practising so you can see exactly which space moved.

Try the following scroll-margin-inline-end code in a spare practice file:

scroll-margin-inline-end: 0;

Reading the example: The colon separates scroll-margin-inline-end from its chosen value, 0. The semicolon marks the end of this declaration.
