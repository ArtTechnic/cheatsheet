scroll-initial-target

Use scroll-initial-target when you need to change defines the scroll-initial-target property. It helps decide whether a box is shown and what happens when its contents do not fit normally.

Place a colon after scroll-initial-target, then supply the value you want. When testing this property, remember: hidden or clipped content may become impossible to reach, so test with more content than you expect.

Important: This feature is experimental. Check browser support before relying on it.

A practical scroll-initial-target example is shown below:

/* Keyword values */
scroll-initial-target: none;
scroll-initial-target: nearest;

/* Global values */
scroll-initial-target: inherit;
scroll-initial-target: initial;
scroll-initial-target: revert;
scroll-initial-target: revert-layer;
scroll-initial-target: unset;

What to notice: The sample asks the browser to use none for scroll-initial-target. The property stays the same when you experiment; the value is the part to change.
