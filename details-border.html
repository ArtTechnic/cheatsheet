border

With border, you can control shorthand border. It changes a line, edge, or corner around an element.

CSS reads this as the name border, a colon, and then a value.

The code below shows a simple use of border:

border: solid;

How this sample works: Read the line as ‘set border to solid.’ That value is the instruction controlling what you see.
