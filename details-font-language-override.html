font-language-override

In CSS, font-language-override is the setting for overrides language for fonts. It changes the presentation or flow of writing.

A rule using font-language-override needs a value after the colon. One useful test is to change only that value; test several lines, long words, and zoomed text—a single short sentence can hide problems.

Here is a compact font-language-override example you can inspect and alter:

/* Keyword value */
font-language-override: normal;

/* <string> values */
font-language-override: "ENG"; /* Use English glyphs */
font-language-override: "TRK"; /* Use Turkish glyphs */

/* Global values */
font-language-override: inherit;
font-language-override: initial;
font-language-override: revert;
font-language-override: revert-layer;
font-language-override: unset;

The important part: Here, normal is the value attached to font-language-override. Change it, refresh the page, and compare the new result with the original.
