border-left-width

Changing border-left-width changes width of left border. It helps decide how large a box or part of a box becomes.

A rule using border-left-width needs a value after the colon. One useful test is to change only that value; padding and borders can also affect the final visible size, especially when box-sizing changes.

A small border-left-width example looks like this:

border-left-width: thick;

What this example does: The important instruction in the sample is thick. It is assigned to border-left-width and changes only the part described above.
