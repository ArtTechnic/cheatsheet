margin-inline-end

The margin-inline-end property controls margin on inline end edge. It changes space around, inside, or between boxes.

CSS reads this as the name margin-inline-end, a colon, and then a value. As you compare values, add a temporary border while practising so you can see exactly which space moved.

Here is a margin-inline-end example to try in a practice page:

margin-inline-end: 20px;
writing-mode: horizontal-tb;

Reading the example: The colon separates margin-inline-end from its chosen value, 20px. The semicolon marks the end of this declaration.
