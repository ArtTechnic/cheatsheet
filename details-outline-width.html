outline-width

Think of outline-width as the control for outline width. It helps decide how large a box or part of a box becomes.

CSS reads this as the name outline-width, a colon, and then a value.

Try the following outline-width code in a spare practice file:

outline-width: 12px;

What to notice: The sample asks the browser to use 12px for outline-width.
