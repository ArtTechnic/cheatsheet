frameset

Use frameset when a piece of HTML represents obsolete frame container. Think of it as an HTML building block specifically meant for obsolete frame container.

The opening frameset tag starts its area and the matching closing tag ends it. Use it when that description matches the content, not simply because its default appearance seems useful.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

Try the following frameset code in a spare practice file:

<!doctype html>
<html lang="en-US">
  <head>
    <!-- Document metadata goes here -->
  </head>
  <frameset cols="50%, 50%">
    <frame
      src="https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe" />
    <frame
      src="https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/frame" />
  </frameset>
</html>

What to notice: Here frameset supplies the meaning described above; the surrounding tags provide the context needed for the example to make sense.
