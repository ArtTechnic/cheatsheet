view-timeline-name

The view-timeline-name property controls name of view timeline. It changes the presentation or flow of writing.

CSS reads this as the name view-timeline-name, a colon, and then a value. As you compare values, test several lines, long words, and zoomed text—a single short sentence can hide problems.

Here is a view-timeline-name example to try in a practice page:

/* Keyword value */
view-timeline-name: none;

/* Custom identifier */
view-timeline-name: --custom_name_for_timeline;

/* Multiple identifiers */
view-timeline-name: --first_timeline_name, --another_timeline_name;

/* Global values */
view-timeline-name: inherit;
view-timeline-name: initial;
view-timeline-name: revert;
view-timeline-name: revert-layer;
view-timeline-name: unset;

What this example does: In this case view-timeline-name receives none. Trying a contrasting valid value makes the difference easier to spot.
