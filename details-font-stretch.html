font-stretch

The font-stretch property controls width of font face. It changes the presentation or flow of writing.

The value written after font-stretch: chooses the result.

Use this font-stretch sample as a starting point, then change one piece at a time:

font-stretch: condensed;

How this sample works: Read the line as ‘set font-stretch to condensed.’ That value is the instruction controlling what you see.
