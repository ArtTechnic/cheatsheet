offset-path

Use offset-path when you need to change path for offset positioning. It controls movement or a visual change over time or space.

CSS reads this as the name offset-path, a colon, and then a value. As you compare values, use gentle motion and remember that some visitors ask their device to reduce animation.

Here is a compact offset-path example you can inspect and alter:

offset-path: path("M-70,-40 C-70,70 70,70 70,-40");

What to notice: The important instruction in the sample is path("M-70,-40 C-70,70 70,70 70,-40"). It is assigned to offset-path and changes only the part described above.
