border-image-source

The browser looks at border-image-source when working out source image for border image. It changes a line, edge, or corner around an element.

Different values give border-image-source different instructions.

A small border-image-source example looks like this:

border-image-source: url("https://mdn.github.iohttps://mdn.github.iohttps://mdn.github.io/shared-assets/images/examples/border-diamonds.png");

The important part: The sample asks the browser to use url("https://mdn.github.iohttps://mdn.github.iohttps://mdn.github.io/shared-assets/images/examples/border-diamonds.png") for border-image-source.
