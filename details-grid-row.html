grid-row

Choose grid-row when the design needs different grid row placement. It helps arrange children inside a layout.

A rule using grid-row needs a value after the colon. One useful test is to change only that value; some layout properties only work after the parent has been made a grid or flex container.

Try the following grid-row code in a spare practice file:

grid-row: 1;

Reading the example: Here, 1 is the value attached to grid-row. Change it, refresh the page, and compare the new result with the original.
