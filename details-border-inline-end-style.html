border-inline-end-style

Changing border-inline-end-style changes style of end edge of inline border. It changes a line, edge, or corner around an element.

Add border-inline-end-style inside a CSS rule and follow it with a colon and value.

Here is a compact border-inline-end-style example you can inspect and alter:

border-inline-end-style: dotted;
writing-mode: horizontal-tb;

What this example does: Here, dotted is the value attached to border-inline-end-style.
