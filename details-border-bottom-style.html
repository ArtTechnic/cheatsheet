border-bottom-style

The browser looks at border-bottom-style when working out style of bottom border. It changes a line, edge, or corner around an element.

Add border-bottom-style inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Borders take up space in the box; outlines usually draw outside it without changing the layout.

Try the following border-bottom-style code in a spare practice file:

border-bottom-style: none;

What to notice: The important instruction in the sample is none. It is assigned to border-bottom-style and changes only the part described above.
