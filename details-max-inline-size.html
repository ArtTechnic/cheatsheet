max-inline-size

Choose max-inline-size when the design needs different maximum inline size of element. It helps decide how large a box or part of a box becomes.

A rule using max-inline-size needs a value after the colon. One useful test is to change only that value; padding and borders can also affect the final visible size, especially when box-sizing changes.

Here is a max-inline-size example to try in a practice page:

max-inline-size: 150px;
writing-mode: horizontal-tb;

How this sample works: Here, 150px is the value attached to max-inline-size. Change it, refresh the page, and compare the new result with the original.
