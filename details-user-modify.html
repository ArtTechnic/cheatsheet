user-modify

Changing user-modify changes whether user can modify element.

Add user-modify inside a CSS rule and follow it with a colon and value.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

This short sample shows user-modify in use:

/* Keyword values */
user-modify: read-only;
user-modify: read-write;
user-modify: write-only;

/* Global values */
user-modify: inherit;
user-modify: initial;
user-modify: revert;
user-modify: unset;

Reading the example: The sample asks the browser to use read-only for user-modify.
