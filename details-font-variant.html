font-variant

Changing font-variant changes shorthand for font variant. It changes the presentation or flow of writing.

Different values give font-variant different instructions. Try them one at a time, and remember that test several lines, long words, and zoomed text—a single short sentence can hide problems.

Use this font-variant sample as a starting point, then change one piece at a time:

font-variant: normal;

What this example does: The sample asks the browser to use normal for font-variant. The property stays the same when you experiment; the value is the part to change.
