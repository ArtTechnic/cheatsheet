body

When you write body, you are marking something as document body. Think of a web page as a labelled storage box: this tag marks one of the large, important parts of that box.

The opening body tag starts its area and the matching closing tag ends it. Use it for its intended page section rather than merely to change the appearance; CSS handles the appearance.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

A small body example looks like this:

<html lang="en">
  <head>
    <title>Document title</title>
  </head>
  <body>
    <p>
      The <code>&lt;body&gt;</code> HTML element represents the content of an
      HTML document. There can be only one <code>&lt;body&gt;</code> element in
      a document.
    </p>
  </body>
</html>

What to notice: Here body supplies the meaning described above; the surrounding tags provide the context needed for the example to make sense.
