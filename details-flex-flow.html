flex-flow

Choose flex-flow when the design needs different shorthand for flex-direction and flex-wrap. It helps arrange children inside a layout.

Place a colon after flex-flow, then supply the value you want. When testing this property, remember: some layout properties only work after the parent has been made a grid or flex container.

A practical flex-flow example is shown below:

flex-flow: row wrap;

What to notice: The colon separates flex-flow from its chosen value, row wrap. The semicolon marks the end of this declaration.
