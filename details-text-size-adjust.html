text-size-adjust

The text-size-adjust property scales text size on mobile. It helps decide how large a box or part of a box becomes.

The value written after text-size-adjust: chooses the result.

Important: This feature is experimental. Check browser support before relying on it.

Use this text-size-adjust sample as a starting point, then change one piece at a time:

/* Keyword values */
text-size-adjust: none;
text-size-adjust: auto;

/* <percentage> value */
text-size-adjust: 80%;

/* Global values */
text-size-adjust: inherit;
text-size-adjust: initial;
text-size-adjust: revert;
text-size-adjust: revert-layer;
text-size-adjust: unset;

The important part: The sample asks the browser to use none for text-size-adjust.
