text-wrap-style

The text-wrap-style property controls style of text wrapping. It changes the presentation or flow of writing.

A rule using text-wrap-style needs a value after the colon. One useful test is to change only that value; test several lines, long words, and zoomed text—a single short sentence can hide problems.

Use this text-wrap-style sample as a starting point, then change one piece at a time:

text-wrap-style: auto;

How this sample works: Read the line as ‘set text-wrap-style to auto.’ That value is the instruction controlling what you see.
