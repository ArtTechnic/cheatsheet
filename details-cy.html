cy

Choose cy when the design needs different y coordinate of SVG element center.

Different values give cy different instructions.

Here is a compact cy example you can inspect and alter:

/* length and percentage values */
cy: 3px;
cy: 20%;

/* Global values */
cy: inherit;
cy: initial;
cy: revert;
cy: revert-layer;
cy: unset;

How this sample works: In this case cy receives 3px.
