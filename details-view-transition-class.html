view-transition-class

It controls movement or a visual change over time or space.

CSS reads this as the name view-transition-class, a colon, and then a value.

Use this view-transition-class sample as a starting point, then change one piece at a time:

/* <custom-ident> value examples */
view-transition-class: card;
view-transition-class: card fast-slide;

/* Keyword value */
view-transition-class: none;

/* Global values */
view-transition-class: inherit;
view-transition-class: initial;
view-transition-class: revert;
view-transition-class: revert-layer;
view-transition-class: unset;

The important part: Here, card is the value attached to view-transition-class.
