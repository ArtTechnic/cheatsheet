font-variant-caps

In CSS, font-variant-caps is the setting for alternates for capital glyphs. It changes the presentation or flow of writing.

Place a colon after font-variant-caps, then supply the value you want. When testing this property, remember: test several lines, long words, and zoomed text—a single short sentence can hide problems.

Try the following font-variant-caps code in a spare practice file:

font-variant-caps: normal;

Reading the example: The sample asks the browser to use normal for font-variant-caps. The property stays the same when you experiment; the value is the part to change.
