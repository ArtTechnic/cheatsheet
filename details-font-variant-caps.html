font-variant-caps

In CSS, font-variant-caps is the setting for alternates for capital glyphs. It changes the presentation or flow of writing.

Place a colon after font-variant-caps, then supply the value you want.

Try the following font-variant-caps code in a spare practice file:

font-variant-caps: normal;

Reading the example: The sample asks the browser to use normal for font-variant-caps.
