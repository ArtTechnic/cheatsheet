baseline-shift

Changing baseline-shift changes shifts baseline of inline elements. It changes the presentation or flow of writing.

Different values give baseline-shift different instructions. Try them one at a time, and remember that test several lines, long words, and zoomed text—a single short sentence can hide problems.

Here is a compact baseline-shift example you can inspect and alter:

/* <length-percentage> values */
baseline-shift: -0.5px;
baseline-shift: 4%;

/* keyword values */
baseline-shift: sub;
baseline-shift: super;

/* Global values */
baseline-shift: inherit;
baseline-shift: initial;
baseline-shift: revert;
baseline-shift: revert-layer;
baseline-shift: unset;

How this sample works: This declaration gives baseline-shift the value -0.5px. Replace that value with another valid choice to compare the two results.
