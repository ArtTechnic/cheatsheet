scroll-padding-top

It changes space around, inside, or between boxes.

A rule using scroll-padding-top needs a value after the colon.

Here is a scroll-padding-top example to try in a practice page:

scroll-padding-top: 0;

What this example does: In this case scroll-padding-top receives 0.
