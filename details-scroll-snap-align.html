scroll-snap-align

The scroll-snap-align property controls snap alignment for child. It helps arrange children inside a layout.

Place a colon after scroll-snap-align, then supply the value you want. When testing this property, remember: some layout properties only work after the parent has been made a grid or flex container.

Try the following scroll-snap-align code in a spare practice file:

scroll-snap-align: start;

What this example does: Read the line as ‘set scroll-snap-align to start.’ That value is the instruction controlling what you see.
