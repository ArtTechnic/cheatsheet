tt

The name tt tells you what it represents: deprecated teletype text. Think of it as an HTML building block specifically meant for deprecated teletype text.

The opening tt tag starts its area and the matching closing tag ends it. Use it when that description matches the content, not simply because its default appearance seems useful.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

This short sample shows tt in use:

<p>
  Enter the following at the telnet command prompt:
  <code>set localecho</code><br />

  The telnet client should display: <tt>Local Echo is on</tt>
</p>

Reading the example: Start with the tt tag in the code, then inspect what sits inside it and which attributes have been added to its opening tag.
