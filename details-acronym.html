acronym

The name acronym tells you what it represents: deprecated abbreviation. Think of it as an HTML building block specifically meant for deprecated abbreviation.

The opening acronym tag starts its area and the matching closing tag ends it. Use it when that description matches the content, not simply because its default appearance seems useful.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

The code below shows a simple use of acronym:

<p>
  The <acronym title="World Wide Web">WWW</acronym> is only a component of the
  Internet.
</p>

Reading the example: Start with the acronym tag in the code, then inspect what sits inside it and which attributes have been added to its opening tag.
