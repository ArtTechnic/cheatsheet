text-emphasis-style

In CSS, text-emphasis-style is the setting for style of text emphasis. It changes the presentation or flow of writing.

Place a colon after text-emphasis-style, then supply the value you want. When testing this property, remember: test several lines, long words, and zoomed text—a single short sentence can hide problems.

The code below shows a simple use of text-emphasis-style:

text-emphasis-style: none;

Reading the example: In this case text-emphasis-style receives none. Trying a contrasting valid value makes the difference easier to spot.
