scroll-padding-inline

In CSS, scroll-padding-inline is the setting for defines the scroll-padding-inline property. It changes space around, inside, or between boxes.

A rule using scroll-padding-inline needs a value after the colon. One useful test is to change only that value; add a temporary border while practising so you can see exactly which space moved.

Here is a scroll-padding-inline example to try in a practice page:

scroll-padding-inline: 0;

How this sample works: Here, 0 is the value attached to scroll-padding-inline. Change it, refresh the page, and compare the new result with the original.
