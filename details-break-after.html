break-after

In CSS, break-after is the setting for how page/column break after element. It controls how content is divided across columns, pages, or separate pieces.

The value written after break-after: chooses the result.

Try the following break-after code in a spare practice file:

break-after: auto;

The important part: Read the line as ‘set break-after to auto.’ That value is the instruction controlling what you see.
