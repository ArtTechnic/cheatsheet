scroll-margin-bottom

Changing scroll-margin-bottom changes defines the scroll-margin-bottom property. It changes space around, inside, or between boxes.

Add scroll-margin-bottom inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Add a temporary border while practising so you can see exactly which space moved.

This short sample shows scroll-margin-bottom in use:

scroll-margin-bottom: 0;

How this sample works: In this case scroll-margin-bottom receives 0. Trying a contrasting valid value makes the difference easier to spot.
