tab-size

Choose tab-size when the design needs different width of tab characters. It helps decide how large a box or part of a box becomes.

Add tab-size inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Padding and borders can also affect the final visible size, especially when box-sizing changes.

Here is a compact tab-size example you can inspect and alter:

tab-size: 10px;

How this sample works: The sample asks the browser to use 10px for tab-size. The property stays the same when you experiment; the value is the part to change.
