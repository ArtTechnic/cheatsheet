interest-delay

Changing interest-delay changes delay for interest. It changes one particular part of the browser’s styling calculation.

Different values give interest-delay different instructions. Try them one at a time, and remember that change only this property while practising, then compare the before and after result.

Important: This feature is experimental. Check browser support before relying on it.

Use this interest-delay sample as a starting point, then change one piece at a time:

/* Single value */
interest-delay: normal;
interest-delay: 2s;
interest-delay: 250ms;

/* Two values */
interest-delay: 1s normal;
interest-delay: 0s 500ms;

/* Global values */
interest-delay: inherit;
interest-delay: initial;
interest-delay: revert;
interest-delay: revert-layer;
interest-delay: unset;

Reading the example: Here, normal is the value attached to interest-delay. Change it, refresh the page, and compare the new result with the original.
