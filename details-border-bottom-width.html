border-bottom-width

With border-bottom-width, you can control width of bottom border. It helps decide how large a box or part of a box becomes.

A rule using border-bottom-width needs a value after the colon.

Here is a border-bottom-width example to try in a practice page:

border-bottom-width: thick;

Reading the example: The important instruction in the sample is thick. It is assigned to border-bottom-width and changes only the part described above.
