d

Use d when you need to change path data for SVG. It changes one particular part of the browser’s styling calculation.

A rule using d needs a value after the colon. One useful test is to change only that value; change only this property while practising, then compare the before and after result.

Here is a compact d example you can inspect and alter:

/* Default */
d: none;

/* Basic usage */
d: path("m 5,5 h 35 L 20,30 z");
d: path("M 0,25 l 50,150 l 200,50 z");
d: path("M 10,5 l 90,0 -80,80 0,-60 80,80 -90,0 z");

/* Global values */
d: inherit;
d: initial;
d: revert;
d: revert-layer;
d: unset;

Reading the example: The important instruction in the sample is none. It is assigned to d and changes only the part described above.
