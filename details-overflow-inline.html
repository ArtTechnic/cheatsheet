overflow-inline

Think of overflow-inline as the control for overflow in inline dimension. It changes the presentation or flow of writing.

Add overflow-inline inside a CSS rule and follow it with a colon and value.

Try the following overflow-inline code in a spare practice file:

/* Keyword values */
overflow-inline: visible;
overflow-inline: hidden;
overflow-inline: clip;
overflow-inline: scroll;
overflow-inline: auto;

/* Global values */
overflow-inline: inherit;
overflow-inline: initial;
overflow-inline: revert;
overflow-inline: revert-layer;
overflow-inline: unset;

What this example does: In this case overflow-inline receives visible.
