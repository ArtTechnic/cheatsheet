interest-delay-start

Changing interest-delay-start changes start of interest delay period. It changes one particular part of the browser’s styling calculation.

Add interest-delay-start inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Change only this property while practising, then compare the before and after result.

Important: This feature is experimental. Check browser support before relying on it.

Here is an interest-delay-start example to try in a practice page:

/* Keyword or custom delay */
interest-delay-start: normal;
interest-delay-start: 2s;
interest-delay-start: 250ms;

/* Global values */
interest-delay-start: inherit;
interest-delay-start: initial;
interest-delay-start: revert;
interest-delay-start: revert-layer;
interest-delay-start: unset;

The important part: In this case interest-delay-start receives normal. Trying a contrasting valid value makes the difference easier to spot.
