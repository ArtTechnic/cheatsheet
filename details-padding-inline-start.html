padding-inline-start

Think of padding-inline-start as the control for padding on inline start edge. It changes space around, inside, or between boxes.

Place a colon after padding-inline-start, then supply the value you want. When testing this property, remember: add a temporary border while practising so you can see exactly which space moved.

This short sample shows padding-inline-start in use:

padding-inline-start: 20px;
writing-mode: horizontal-tb;

How this sample works: This declaration gives padding-inline-start the value 20px. Replace that value with another valid choice to compare the two results.
