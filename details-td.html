td

A td (table data) element is the most common cell in a table. It holds a single piece of data -- a number, a word, a date, whatever. Every row of your table is made up of td cells (unless a cell is a header, in which case you use th instead).

By default, browsers left-align the text inside td cells. If you want a cell to stretch across multiple columns, use the colspan attribute. For example, colspan="2" makes the cell take up two columns side by side. This is handy for summary rows at the bottom that need to span the whole width of the table.

You can also make a cell stretch across multiple rows with the rowspan attribute. This is less common, but it is useful when one label applies to several rows stacked vertically below it.

The examples below show both colspan and rowspan in action.

Use colspan to merge cells horizontally (across columns):



<tr>
    <td>Notebook</td>
    <td>$4</td>
    <td>10 in stock</td>
</tr>
<!-- Cell spans two columns -->
<tr>
    <td colspan="2">Summary total</td>
    <td>$4</td>
</tr>

Use rowspan to merge cells vertically (across rows). This is less common but handy for grouped data where one label applies to multiple rows below it:

<tr>
    <td rowspan="2">Office</td>
    <td>Pens</td>
    <td>12</td>
</tr>
<tr>
    <td>Pencils</td>
    <td>8</td>
</tr>
