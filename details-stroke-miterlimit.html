stroke-miterlimit

In CSS, stroke-miterlimit is the setting for miter limit for stroke joins. It changes one particular part of the browser’s styling calculation.

The value written after stroke-miterlimit: chooses the result. While experimenting, keep in mind that change only this property while practising, then compare the before and after result.

Use this stroke-miterlimit sample as a starting point, then change one piece at a time:

/* number values */
stroke-miterlimit: 1;
stroke-miterlimit: 3.1416;

/* Global values */
stroke-miterlimit: inherit;
stroke-miterlimit: initial;
stroke-miterlimit: revert;
stroke-miterlimit: revert-layer;
stroke-miterlimit: unset;

How this sample works: The important instruction in the sample is 1. It is assigned to stroke-miterlimit and changes only the part described above.
