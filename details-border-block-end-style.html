border-block-end-style

In CSS, border-block-end-style is the setting for style of end edge of block border. It changes a line, edge, or corner around an element.

The value written after border-block-end-style: chooses the result. While experimenting, keep in mind that borders take up space in the box; outlines usually draw outside it without changing the layout.

A small border-block-end-style example looks like this:

border-block-end-style: dotted;
writing-mode: horizontal-tb;

Reading the example: Here, dotted is the value attached to border-block-end-style. Change it, refresh the page, and compare the new result with the original.
