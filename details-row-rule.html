row-rule

In CSS, row-rule is the setting for shorthand for row rule in grid/table.

The value written after row-rule: chooses the result.

Important: This feature is experimental. Check browser support before relying on it.

Here is a row-rule example to try in a practice page:

row-rule: solid;

The important part: The sample asks the browser to use solid for row-rule.
