text-decoration-color

The browser looks at text-decoration-color when working out color of text decoration. It changes how something looks rather than changing what the HTML means.

A rule using text-decoration-color needs a value after the colon. One useful test is to change only that value; check that text remains easy to read and that important information does not depend on colour alone.

Use this text-decoration-color sample as a starting point, then change one piece at a time:

text-decoration-color: red;

What this example does: Read the line as ‘set text-decoration-color to red.’ That value is the instruction controlling what you see.
