script

When you write script, you are marking something as embeds script code. This tag supports how a page is built or behaves rather than representing an ordinary paragraph or picture.

The opening script tag starts its area and the matching closing tag ends it. Place it in the correct part of the document and use it only when that extra behaviour or reusable structure is needed.

Important: This feature is experimental. Check browser support before relying on it.

A small script example looks like this:

<script
        src="myscript.js"
        attributionsrc="https://a.example/register-source https://b.example/register-source"></script>

What this example does: Start with the script tag in the code, then inspect what sits inside it and which attributes have been added to its opening tag.
