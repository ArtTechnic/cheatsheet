anchor-scope

The anchor-scope property defines scope of anchor name references.

Add anchor-scope inside a CSS rule and follow it with a colon and value.

Try the following anchor-scope code in a spare practice file:

/* Single values */
anchor-scope: none;
anchor-scope: all;
anchor-scope: --anchor-name;

/* Multiple <dashed-ident> values */
anchor-scope: --anchor-name, --another-name;

/* Global values */
anchor-scope: inherit;
anchor-scope: initial;
anchor-scope: revert;
anchor-scope: revert-layer;
anchor-scope: unset;

How this sample works: In this case anchor-scope receives none.
