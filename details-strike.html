strike

Browsers read strike as a label meaning deprecated strikethrough. Think of it as an HTML building block specifically meant for deprecated strikethrough.

Treat the two strike tags like the covers of a folder: the related content goes between them. Use it when that description matches the content, not simply because its default appearance seems useful.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

Here is a strike example to try in a practice page:

&lt;strike&gt;: <strike>Today's Special: Salmon</strike> SOLD OUT<br />
&lt;s&gt;: <s>Today's Special: Salmon</s> SOLD OUT

Reading the example: Here strike supplies the meaning described above; the surrounding tags provide the context needed for the example to make sense.
