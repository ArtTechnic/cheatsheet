mask-image

Use mask-image when you need to change masking image.

CSS reads this as the name mask-image, a colon, and then a value.

Here is a mask-image example to try in a practice page:

/* Keyword value */
mask-image: none;

/* <mask-source> value */
mask-image: url("masks.svg#mask1");

/* <image> values */
mask-image: linear-gradient(black, transparent);
mask-image: image(url("mask.png"), skyblue);

/* Multiple values */
mask-image: url("mask.png"), linear-gradient(black 25%, transparent 35%);

/* Global values */
mask-image: inherit;
mask-image: initial;
mask-image: revert;
mask-image: revert-layer;
mask-image: unset;

What to notice: This declaration gives mask-image the value none.
