menuitem

In an HTML document, menuitem represents deprecated menu item. Think of it as an HTML building block specifically meant for deprecated menu item.

Put the content belonging to menuitem between its opening and closing tags. Use it when that description matches the content, not simply because its default appearance seems useful.

Important: This element is obsolete and modern browsers may ignore it. Use a normal button inside a suitable menu or list instead.

Use this menuitem sample as a starting point, then change one piece at a time:

<!-- Old code you may encounter: -->
<menuitem label="Save"></menuitem>

<!-- A modern alternative: -->
<menu>
    <li><button type="button">Save</button></li>
</menu>

How this sample works: Find <menuitem> in the sample first. Its attributes and enclosed content provide the information this element needs.
