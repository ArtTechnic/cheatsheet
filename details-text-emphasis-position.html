text-emphasis-position

Think of text-emphasis-position as the control for position of text emphasis. It helps decide where an element sits and how it relates to nearby boxes.

The value written after text-emphasis-position: chooses the result. While experimenting, keep in mind that positioning properties work as a team, so inspect the containing box as well as the element itself.

Here is a text-emphasis-position example to try in a practice page:

text-emphasis-position: auto;

The important part: In this case text-emphasis-position receives auto. Trying a contrasting valid value makes the difference easier to spot.
