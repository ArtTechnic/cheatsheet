flex-basis

Changing flex-basis changes initial main size. It helps arrange children inside a layout.

Different values give flex-basis different instructions. Try them one at a time, and remember that some layout properties only work after the parent has been made a grid or flex container.

A practical flex-basis example is shown below:

flex-basis: auto;

What to notice: This declaration gives flex-basis the value auto. Replace that value with another valid choice to compare the two results.
