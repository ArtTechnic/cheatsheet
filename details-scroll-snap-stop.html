scroll-snap-stop

Choose scroll-snap-stop when the design needs different defines the scroll-snap-stop property. It helps decide where an element sits and how it relates to nearby boxes.

Place a colon after scroll-snap-stop, then supply the value you want. When testing this property, remember: positioning properties work as a team, so inspect the containing box as well as the element itself.

Try the following scroll-snap-stop code in a spare practice file:

scroll-snap-stop: normal;

What to notice: Here, normal is the value attached to scroll-snap-stop. Change it, refresh the page, and compare the new result with the original.
