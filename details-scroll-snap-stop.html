scroll-snap-stop

It helps decide where an element sits and how it relates to nearby boxes.

Place a colon after scroll-snap-stop, then supply the value you want.

Try the following scroll-snap-stop code in a spare practice file:

scroll-snap-stop: normal;

What to notice: Here, normal is the value attached to scroll-snap-stop.
