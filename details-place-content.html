place-content

Changing place-content changes alignment and justification in container. It helps arrange children inside a layout.

The value written after place-content: chooses the result. While experimenting, keep in mind that some layout properties only work after the parent has been made a grid or flex container.

Here is a place-content example to try in a practice page:

place-content: end space-between;

The important part: Here, end space-between is the value attached to place-content. Change it, refresh the page, and compare the new result with the original.
