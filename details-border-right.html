border-right

Think of border-right as the control for shorthand for right border. It changes a line, edge, or corner around an element.

Add border-right inside a CSS rule and follow it with a colon and value.

A practical border-right example is shown below:

border-right: solid;

What to notice: This declaration gives border-right the value solid.
