corner-top-shape

Choose corner-top-shape when the design needs different shape of top edge corners. It helps decide where an element sits and how it relates to nearby boxes.

The value written after corner-top-shape: chooses the result.

Important: This feature is experimental. Check browser support before relying on it.

A practical corner-top-shape example is shown below:

/* Single keyword value set for both corners */
corner-top-shape: notch;
corner-top-shape: squircle;

/* Single superellipse() value set for both corners */
corner-top-shape: superellipse(3);
corner-top-shape: superellipse(-1.5);

/* Left-hand corner, right-hand corner */
corner-top-shape: notch squircle;
corner-top-shape: notch superellipse(-1.5);

/* Global values */
corner-top-shape: inherit;
corner-top-shape: initial;
corner-top-shape: revert;
corner-top-shape: revert-layer;
corner-top-shape: unset;

What to notice: The colon separates corner-top-shape from its chosen value, notch.
