column-rule-style

With column-rule-style, you can control rule style. It controls how content is divided across columns, pages, or separate pieces.

The value written after column-rule-style: chooses the result.

Try the following column-rule-style code in a spare practice file:

column-rule-style: dotted;

The important part: The sample asks the browser to use dotted for column-rule-style.
