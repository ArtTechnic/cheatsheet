column-rule-style

With column-rule-style, you can control rule style. It controls how content is divided across columns, pages, or separate pieces.

The value written after column-rule-style: chooses the result. While experimenting, keep in mind that the browser may need enough content before the effect becomes obvious.

Try the following column-rule-style code in a spare practice file:

column-rule-style: dotted;

The important part: The sample asks the browser to use dotted for column-rule-style. The property stays the same when you experiment; the value is the part to change.
