output

In an HTML document, output represents result of a calculation. It is a form building block: forms let a visitor enter information, choose something, or start an action.

The opening output tag starts its area and the matching closing tag ends it. Every control needs a clear label, and the page should still make sense when somebody uses only a keyboard.

A practical output example is shown below:

<form id="example-form">
  <input type="range" id="b" name="b" value="50" /> +
  <input type="number" id="a" name="a" value="10" /> =
  <output name="result" for="a b">60</output>
</form>

What this example does: Find <output> in the sample first. Its attributes and enclosed content provide the information this element needs.
