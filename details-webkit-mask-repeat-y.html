-webkit-mask-repeat-y

Choose -webkit-mask-repeat-y when the design needs different defines the -webkit-mask-repeat-y property. It changes one particular part of the browser’s styling calculation.

Different values give -webkit-mask-repeat-y different instructions. Try them one at a time, and remember that change only this property while practising, then compare the before and after result.

Important: This is not a standard feature, so different browsers may handle it differently. Treat it as something to recognize rather than a dependable first choice.

A practical -webkit-mask-repeat-y example is shown below:

/* Keyword values */
-webkit-mask-repeat-y: repeat;
-webkit-mask-repeat-y: no-repeat;
-webkit-mask-repeat-y: space;
-webkit-mask-repeat-y: round;

/* Multiple values */
-webkit-mask-repeat-y: repeat, no-repeat, space;

/* Global values */
-webkit-mask-repeat-y: inherit;
-webkit-mask-repeat-y: initial;
-webkit-mask-repeat-y: revert;
-webkit-mask-repeat-y: revert-layer;
-webkit-mask-repeat-y: unset;

How this sample works: The important instruction in the sample is repeat. It is assigned to -webkit-mask-repeat-y and changes only the part described above.
