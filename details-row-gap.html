row-gap

Choose row-gap when the design needs different gap between rows in a grid. It changes space around, inside, or between boxes.

The value written after row-gap: chooses the result. While experimenting, keep in mind that add a temporary border while practising so you can see exactly which space moved.

The code below shows a simple use of row-gap:

row-gap: 0;

What this example does: This declaration gives row-gap the value 0. Replace that value with another valid choice to compare the two results.
