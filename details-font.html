font

Browsers read font as a label meaning deprecated font styling. Think of it as an HTML building block specifically meant for deprecated font styling.

The opening font tag starts its area and the matching closing tag ends it. Use it when that description matches the content, not simply because its default appearance seems useful.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

Use this font sample as a starting point, then change one piece at a time:

<font>...</font>

The important part: The key piece in this sample is <font>. Read outward from that tag to see what belongs to it and how it is configured.
