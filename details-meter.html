meter

When you write meter, you are marking something as scalar measurement. It is a form building block: forms let a visitor enter information, choose something, or start an action.

The opening meter tag starts its area and the matching closing tag ends it. Every control needs a clear label, and the page should still make sense when somebody uses only a keyboard.

The code below shows a simple use of meter:

<label for="fuel">Fuel level:</label>

<meter id="fuel" min="0" max="100" low="33" high="66" optimum="80" value="50">
  at 50/100
</meter>

What this example does: Here meter supplies the meaning described above; the surrounding tags provide the context needed for the example to make sense.
