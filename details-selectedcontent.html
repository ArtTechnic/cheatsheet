selectedcontent

The selectedcontent tag marks part of the page as experimental selected content. Think of it as an HTML building block specifically meant for experimental selected content.

Put the content belonging to selectedcontent between its opening and closing tags. Use it when that description matches the content, not simply because its default appearance seems useful.

Try the following selectedcontent code in a spare practice file:

<select>
  <button>
    <selectedcontent></selectedcontent>
  </button>
  <option></option>
  ...
</select>
