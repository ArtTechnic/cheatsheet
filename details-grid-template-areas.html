grid-template-areas

The browser looks at grid-template-areas when working out named grid areas. It helps arrange children inside a layout.

Place a colon after grid-template-areas, then supply the value you want.

Try the following grid-template-areas code in a spare practice file:

grid-template-areas:
  "a a a"
  "b c c"
  "b c c";

What to notice: The colon separates grid-template-areas from its chosen value, "a a a" "b c c" "b c c".
