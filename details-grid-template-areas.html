grid-template-areas

The browser looks at grid-template-areas when working out named grid areas. It helps arrange children inside a layout.

Place a colon after grid-template-areas, then supply the value you want. When testing this property, remember: some layout properties only work after the parent has been made a grid or flex container.

Try the following grid-template-areas code in a spare practice file:

grid-template-areas:
  "a a a"
  "b c c"
  "b c c";

What to notice: The colon separates grid-template-areas from its chosen value, "a a a" "b c c" "b c c". The semicolon marks the end of this declaration.
