stroke-dasharray

The browser looks at stroke-dasharray when working out pattern of dashes for stroke. It changes one particular part of the browser’s styling calculation.

CSS reads this as the name stroke-dasharray, a colon, and then a value. As you compare values, change only this property while practising, then compare the before and after result.

A small stroke-dasharray example looks like this:

/* Keywords */
stroke-dasharray: none;

/* Numeric, length, and percentage values */
stroke-dasharray: 2px, 5px;
stroke-dasharray: 20%, 50%;
stroke-dasharray: 2, 5;

/* The following two rules are equivalent */
stroke-dasharray: 2, 5, 3;
stroke-dasharray: 2, 5, 3, 2, 5, 3;

/* Global values */
stroke-dasharray: inherit;
stroke-dasharray: initial;
stroke-dasharray: revert;
stroke-dasharray: revert-layer;
stroke-dasharray: unset;

The important part: In this case stroke-dasharray receives none. Trying a contrasting valid value makes the difference easier to spot.
