input

Browsers read input as a label meaning input control. It is a form building block: forms let a visitor enter information, choose something, or start an action.

Do not add a separate closing tag for input. It is a void element, with its information supplied through attributes. Every control needs a clear label, and the page should still make sense when somebody uses only a keyboard.

Important: This feature is experimental. Check browser support before relying on it.

Try the following input code in a spare practice file:

<label for="name">Name (4 to 8 characters):</label>

<input
  type="text"
  id="name"
  name="name"
  required
  minlength="4"
  maxlength="8"
  size="10" />

How this sample works: The key piece in this sample is <input>. Read outward from that tag to see what belongs to it and how it is configured.
