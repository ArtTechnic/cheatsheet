mask-composite

With mask-composite, you can control compositing operator for mask layers.

The value written after mask-composite: chooses the result.

Try the following mask-composite code in a spare practice file:

/* Keyword values */
mask-composite: add;
mask-composite: subtract;
mask-composite: intersect;
mask-composite: exclude;

/* Global values */
mask-composite: inherit;
mask-composite: initial;
mask-composite: revert;
mask-composite: revert-layer;
mask-composite: unset;

Reading the example: The important instruction in the sample is add. It is assigned to mask-composite and changes only the part described above.
