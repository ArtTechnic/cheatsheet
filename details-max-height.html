max-height

With max-height, you can control max height. It helps decide how large a box or part of a box becomes.

Place a colon after max-height, then supply the value you want. When testing this property, remember: padding and borders can also affect the final visible size, especially when box-sizing changes.

The code below shows a simple use of max-height:

max-height: 150px;

What this example does: The sample asks the browser to use 150px for max-height. The property stays the same when you experiment; the value is the part to change.
