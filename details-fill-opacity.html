fill-opacity

With fill-opacity, you can control opacity of fill. It changes how something looks rather than changing what the HTML means.

CSS reads this as the name fill-opacity, a colon, and then a value. As you compare values, check that text remains easy to read and that important information does not depend on colour alone.

A practical fill-opacity example is shown below:

/* numeric and percentage values */
fill-opacity: 0.2;
fill-opacity: 20%;

/* Global values */
fill-opacity: inherit;
fill-opacity: initial;
fill-opacity: revert;
fill-opacity: revert-layer;
fill-opacity: unset;

How this sample works: This declaration gives fill-opacity the value 0.2. Replace that value with another valid choice to compare the two results.
