corner-start-start-shape

The browser looks at corner-start-start-shape when working out shape of start corner in start direction. It changes one particular part of the browser’s styling calculation.

CSS reads this as the name corner-start-start-shape, a colon, and then a value. As you compare values, change only this property while practising, then compare the before and after result.

Important: This feature is experimental. Check browser support before relying on it.

Try the following corner-start-start-shape code in a spare practice file:

/* Keyword values */
corner-start-start-shape: notch;
corner-start-start-shape: squircle;

/* superellipse() function values */
corner-start-start-shape: superellipse(3);
corner-start-start-shape: superellipse(-1.5);

/* Global values */
corner-start-start-shape: inherit;
corner-start-start-shape: initial;
corner-start-start-shape: revert;
corner-start-start-shape: revert-layer;
corner-start-start-shape: unset;

What this example does: This declaration gives corner-start-start-shape the value notch. Replace that value with another valid choice to compare the two results.
