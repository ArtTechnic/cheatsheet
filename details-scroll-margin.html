scroll-margin

It changes space around, inside, or between boxes.

Add scroll-margin inside a CSS rule and follow it with a colon and value.

Try the following scroll-margin code in a spare practice file:

scroll-margin: 0;

The important part: This declaration gives scroll-margin the value 0.
