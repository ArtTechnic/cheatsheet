scroll-margin

Choose scroll-margin when the design needs different defines the scroll-margin property. It changes space around, inside, or between boxes.

Add scroll-margin inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Add a temporary border while practising so you can see exactly which space moved.

Try the following scroll-margin code in a spare practice file:

scroll-margin: 0;

The important part: This declaration gives scroll-margin the value 0. Replace that value with another valid choice to compare the two results.
