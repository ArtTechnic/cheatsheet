image-resolution

With image-resolution, you can control resolution for images. It changes one particular part of the browser’s styling calculation.

Place a colon after image-resolution, then supply the value you want. When testing this property, remember: change only this property while practising, then compare the before and after result.

Important: This feature is experimental. Check browser support before relying on it.

Here is a compact image-resolution example you can inspect and alter:

image-resolution: from-image;
image-resolution: 300dpi;
image-resolution: from-image 300dpi;
image-resolution: 300dpi snap;

/* Global values */
image-resolution: inherit;
image-resolution: initial;
image-resolution: revert;
image-resolution: revert-layer;
image-resolution: unset;

The important part: Here, from-image is the value attached to image-resolution. Change it, refresh the page, and compare the new result with the original.
