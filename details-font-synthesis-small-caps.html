font-synthesis-small-caps

The browser looks at font-synthesis-small-caps when working out whether small caps are synthesized. It changes the presentation or flow of writing.

CSS reads this as the name font-synthesis-small-caps, a colon, and then a value.

The code below shows a simple use of font-synthesis-small-caps:

/* Keyword values */
font-synthesis-small-caps: auto;
font-synthesis-small-caps: none;

/* Global values */
font-synthesis-small-caps: inherit;
font-synthesis-small-caps: initial;
font-synthesis-small-caps: revert;
font-synthesis-small-caps: revert-layer;
font-synthesis-small-caps: unset;

What to notice: The important instruction in the sample is auto. It is assigned to font-synthesis-small-caps and changes only the part described above.
