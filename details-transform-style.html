transform-style

In CSS, transform-style is the setting for 3D transform behavior of children. It controls movement or a visual change over time or space.

The value written after transform-style: chooses the result.

Try the following transform-style code in a spare practice file:

transform-style: flat;

What this example does: This declaration gives transform-style the value flat.
