border-top-right-radius

Use border-top-right-radius when you need to change radius of top-right corner. It changes a line, edge, or corner around an element.

A rule using border-top-right-radius needs a value after the colon. One useful test is to change only that value; borders take up space in the box; outlines usually draw outside it without changing the layout.

Here is a compact border-top-right-radius example you can inspect and alter:

border-top-right-radius: 80px 80px;

Reading the example: In this case border-top-right-radius receives 80px 80px. Trying a contrasting valid value makes the difference easier to spot.
