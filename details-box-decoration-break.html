box-decoration-break

Changing box-decoration-break changes how fragments render across lines. It controls how content is divided across columns, pages, or separate pieces.

A rule using box-decoration-break needs a value after the colon. One useful test is to change only that value; the browser may need enough content before the effect becomes obvious.

This short sample shows box-decoration-break in use:

-webkit-box-decoration-break: slice;
box-decoration-break: slice;

Reading the example: This declaration gives box-decoration-break the value slice. Replace that value with another valid choice to compare the two results.
