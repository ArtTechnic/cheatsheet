-webkit-text-stroke

It changes the presentation or flow of writing.

A rule using -webkit-text-stroke needs a value after the colon.

Here is a -webkit-text-stroke example to try in a practice page:

/* Width and color values */
-webkit-text-stroke: 4px navy;

/* Global values */
-webkit-text-stroke: inherit;
-webkit-text-stroke: initial;
-webkit-text-stroke: revert;
-webkit-text-stroke: revert-layer;
-webkit-text-stroke: unset;

What this example does: The sample asks the browser to use 4px navy for -webkit-text-stroke.
