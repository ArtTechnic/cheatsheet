scrollbar-color

It changes how something looks rather than changing what the HTML means.

The value written after scrollbar-color: chooses the result.

A small scrollbar-color example looks like this:

/* Keyword values */
scrollbar-color: auto;

/* <color> values */
scrollbar-color: rebeccapurple green; /* Two valid colors.
The first applies to the thumb of the scrollbar, the second to the track. */

/* Global values */
scrollbar-color: inherit;
scrollbar-color: initial;
scrollbar-color: revert;
scrollbar-color: revert-layer;
scrollbar-color: unset;

How this sample works: The sample asks the browser to use auto for scrollbar-color.
