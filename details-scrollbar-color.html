scrollbar-color

The browser looks at scrollbar-color when working out defines the scrollbar-color property. It changes how something looks rather than changing what the HTML means.

The value written after scrollbar-color: chooses the result. While experimenting, keep in mind that check that text remains easy to read and that important information does not depend on colour alone.

A small scrollbar-color example looks like this:

/* Keyword values */
scrollbar-color: auto;

/* <color> values */
scrollbar-color: rebeccapurple green; /* Two valid colors.
The first applies to the thumb of the scrollbar, the second to the track. */

/* Global values */
scrollbar-color: inherit;
scrollbar-color: initial;
scrollbar-color: revert;
scrollbar-color: revert-layer;
scrollbar-color: unset;

How this sample works: The sample asks the browser to use auto for scrollbar-color. The property stays the same when you experiment; the value is the part to change.
