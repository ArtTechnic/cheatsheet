border-image-repeat

Changing border-image-repeat changes whether border image is repeated or stretched. It changes a line, edge, or corner around an element.

Add border-image-repeat inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Borders take up space in the box; outlines usually draw outside it without changing the layout.

This short sample shows border-image-repeat in use:

border-image-repeat: stretch;

How this sample works: In this case border-image-repeat receives stretch. Trying a contrasting valid value makes the difference easier to spot.
