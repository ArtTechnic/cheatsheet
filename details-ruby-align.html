ruby-align

Changing ruby-align changes alignment of ruby annotation. It helps arrange children inside a layout.

CSS reads this as the name ruby-align, a colon, and then a value. As you compare values, some layout properties only work after the parent has been made a grid or flex container.

Here is a compact ruby-align example you can inspect and alter:

/* Keyword values */
ruby-align: start;
ruby-align: center;
ruby-align: space-between;
ruby-align: space-around;

/* Global values */
ruby-align: inherit;
ruby-align: initial;
ruby-align: revert;
ruby-align: revert-layer;
ruby-align: unset;

Reading the example: Here, start is the value attached to ruby-align. Change it, refresh the page, and compare the new result with the original.
