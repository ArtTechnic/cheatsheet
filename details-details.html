details

Use details when a piece of HTML represents disclosure widget. It creates a part of the page that a visitor can open, close, or interact with instead of only reading it.

Anything meant to belong to details normally sits inside the pair of tags. Make its purpose clear in the visible text so the visitor knows what will happen before using it.

Here is a details example to try in a practice page:

<details>
  <summary>Details</summary>
  Something small enough to escape casual notice.
</details>

Reading the example: Here details supplies the meaning described above; the surrounding tags provide the context needed for the example to make sense.
