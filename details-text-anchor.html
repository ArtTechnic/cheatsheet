text-anchor

Think of text-anchor as the control for alignment of text inline. It changes the presentation or flow of writing.

CSS reads this as the name text-anchor, a colon, and then a value. As you compare values, test several lines, long words, and zoomed text—a single short sentence can hide problems.

Here is a compact text-anchor example you can inspect and alter:

text-anchor: start;
text-anchor: middle;
text-anchor: end;

/* Global values */
text-anchor: inherit;
text-anchor: initial;
text-anchor: revert;
text-anchor: revert-layer;
text-anchor: unset;

How this sample works: Here, start is the value attached to text-anchor. Change it, refresh the page, and compare the new result with the original.
