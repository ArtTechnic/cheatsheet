row-rule-width

Think of row-rule-width as the control for width of row rule. It helps decide how large a box or part of a box becomes.

The value written after row-rule-width: chooses the result.

Important: This feature is experimental. Check browser support before relying on it.

Try the following row-rule-width code in a spare practice file:

row-rule-width: thin;

The important part: In this case row-rule-width receives thin.
