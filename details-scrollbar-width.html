scrollbar-width

It helps decide how large a box or part of a box becomes.

CSS reads this as the name scrollbar-width, a colon, and then a value.

Try the following scrollbar-width code in a spare practice file:

/* Keyword values */
scrollbar-width: auto;
scrollbar-width: thin;
scrollbar-width: none;

/* Global values */
scrollbar-width: inherit;
scrollbar-width: initial;
scrollbar-width: revert;
scrollbar-width: revert-layer;
scrollbar-width: unset;

What to notice: The important instruction in the sample is auto. It is assigned to scrollbar-width and changes only the part described above.
