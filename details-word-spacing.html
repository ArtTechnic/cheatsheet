word-spacing

Use word-spacing when you need to change space between words. It changes space around, inside, or between boxes.

Add word-spacing inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Add a temporary border while practising so you can see exactly which space moved.

The code below shows a simple use of word-spacing:

word-spacing: normal;

The important part: Read the line as ‘set word-spacing to normal.’ That value is the instruction controlling what you see.
