background-clip

The browser looks at background-clip when working out paint area for background. It changes how something looks rather than changing what the HTML means.

Place a colon after background-clip, then supply the value you want.

Try the following background-clip code in a spare practice file:

background-clip: border-box;

What to notice: Here, border-box is the value attached to background-clip.
