col

The col element represents one or more columns inside your table. A column is the vertical stack of cells in the same position. You usually put col elements inside a colgroup so you can style whole columns at once.

Each col by itself targets one column. But you can use the span attribute to make one col cover multiple columns. For instance, span="2" means this col applies to two columns side by side. Remember: col elements must live inside a colgroup, and that colgroup must be the first thing inside the table.

In the example below, the first column has a grey background to show how it works.



<table>
    <colgroup>
        <col style="background-color: lightgrey">
        <col>
    </colgroup>
    <tr>
        <td>First column</td>
        <td>Second column</td>
    </tr>
</table>
