box-flex

With box-flex, you can control sets flex grow factor of box. It helps arrange children inside a layout.

CSS reads this as the name box-flex, a colon, and then a value. As you compare values, some layout properties only work after the parent has been made a grid or flex container.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

Use this box-flex sample as a starting point, then change one piece at a time:

/* <number> values */
-moz-box-flex: 0;
-moz-box-flex: 2;
-moz-box-flex: 3.5;
-webkit-box-flex: 0;
-webkit-box-flex: 2;
-webkit-box-flex: 3.5;

/* Global values */
-moz-box-flex: inherit;
-moz-box-flex: initial;
-moz-box-flex: revert;
-moz-box-flex: revert-layer;
-moz-box-flex: unset;
-webkit-box-flex: inherit;
-webkit-box-flex: initial;
-webkit-box-flex: revert;
-webkit-box-flex: revert-layer;
-webkit-box-flex: unset;

The important part: Read the line as ‘set box-flex to 0.’ That value is the instruction controlling what you see.
