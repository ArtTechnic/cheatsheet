forced-color-adjust

In CSS, forced-color-adjust is the setting for how element responds to forced colors. It changes how something looks rather than changing what the HTML means.

Add forced-color-adjust inside a CSS rule and follow it with a colon and value.

This short sample shows forced-color-adjust in use:

forced-color-adjust: auto;
forced-color-adjust: none;
forced-color-adjust: preserve-parent-color;

/* Global values */
forced-color-adjust: inherit;
forced-color-adjust: initial;
forced-color-adjust: revert;
forced-color-adjust: revert-layer;
forced-color-adjust: unset;

The important part: In this case forced-color-adjust receives auto.
