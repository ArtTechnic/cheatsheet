z-index

Choose z-index when the design needs different stacking order. It helps decide where an element sits and how it relates to nearby boxes.

The value written after z-index: chooses the result.

This short sample shows z-index in use:

z-index: auto;

How this sample works: This declaration gives z-index the value auto.
