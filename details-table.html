table

A table is the HTML element that holds tabular data -- information that fits nicely into rows and columns, like a spreadsheet or a multiplication chart. Each piece of data lives in a cell, and cells are organized into rows and columns so it is easy to read.

A well-built table uses several helper elements inside it. The thead holds the header row (the labels at the top), tbody holds all the data rows in the middle, and tfoot holds summary rows at the bottom (like a "Total" row). You should write them in this order in your code, even though the browser will show the footer at the very bottom no matter what.

The example below shows a small table with a header row, a couple of data rows, and a total row at the bottom.



<table>
    <thead>
        <tr>
            <th>Language</th>
            <th>Type</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>HTML</td>
            <td>Markup</td>
        </tr>
        <tr>
            <td>CSS</td>
            <td>Styling</td>
        </tr>
    </tbody>
    <tfoot>
        <tr>
            <th>Total</th>
            <td>2</td>
        </tr>
    </tfoot>
</table>
