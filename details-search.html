search

Use search when a piece of HTML represents search controls group. Think of it as an HTML building block specifically meant for search controls group.

The opening search tag starts its area and the matching closing tag ends it. Use it when that description matches the content, not simply because its default appearance seems useful.

Here is a search example to try in a practice page:

<header>
  <h1>Movie website</h1>
  <search>
    <form action="./search/">
      <label for="movie">Find a Movie</label>
      <input type="search" id="movie" name="q" />
      <button type="submit">Search</button>
    </form>
  </search>
</header>

What to notice: The key piece in this sample is <search>. Read outward from that tag to see what belongs to it and how it is configured.
