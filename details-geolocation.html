geolocation

The geolocation tag marks part of the page as not an HTML element. Think of it as an HTML building block specifically meant for not an html element.

Treat the two geolocation tags like the covers of a folder: the related content goes between them. Use it when that description matches the content, not simply because its default appearance seems useful.

Important: This feature is experimental. Check browser support before relying on it.

Use this geolocation sample as a starting point, then change one piece at a time:

<geolocation>
  <p>Your browser doesn't support the Geolocation element.</p>
</geolocation>

What this example does: Find <geolocation> in the sample first. Its attributes and enclosed content provide the information this element needs.
