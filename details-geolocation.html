geolocation

The experimental geolocation element creates a browser-made control that lets a visitor choose whether to share their location with the page.

The browser handles the permission request. The page can then use the location data and react when that data or permission changes.

Important: This feature is experimental. Check browser support before relying on it.

Use this geolocation sample as a starting point, then change one piece at a time:

<geolocation>
  <p>Your browser doesn't support the Geolocation element.</p>
</geolocation>

What this example does: It creates the location-sharing control and supplies fallback text for browsers that do not support the element.
