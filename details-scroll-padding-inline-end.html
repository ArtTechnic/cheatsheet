scroll-padding-inline-end

Think of scroll-padding-inline-end as the control for defines the scroll-padding-inline-end property. It changes space around, inside, or between boxes.

Place a colon after scroll-padding-inline-end, then supply the value you want. When testing this property, remember: add a temporary border while practising so you can see exactly which space moved.

A practical scroll-padding-inline-end example is shown below:

scroll-padding-inline-end: 0;

What to notice: This declaration gives scroll-padding-inline-end the value 0. Replace that value with another valid choice to compare the two results.
