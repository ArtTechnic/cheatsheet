float

In CSS, float is the setting for floating element. It helps decide where an element sits and how it relates to nearby boxes.

Add float inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Positioning properties work as a team, so inspect the containing box as well as the element itself.

A practical float example is shown below:

float: none;

The important part: This declaration gives float the value none. Replace that value with another valid choice to compare the two results.
