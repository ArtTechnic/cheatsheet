grid-row-start

With grid-row-start, you can control start edge of grid row placement. It helps arrange children inside a layout.

The value written after grid-row-start: chooses the result. While experimenting, keep in mind that some layout properties only work after the parent has been made a grid or flex container.

This short sample shows grid-row-start in use:

grid-row-start: auto;

What to notice: The colon separates grid-row-start from its chosen value, auto. The semicolon marks the end of this declaration.
