del

The name del tells you what it represents: deleted text. Think of it as an HTML building block specifically meant for deleted text.

Put the content belonging to del between its opening and closing tags. Use it when that description matches the content, not simply because its default appearance seems useful.

Here is a compact del example you can inspect and alter:

<blockquote>
  There is <del>nothing</del> <ins>no code</ins> either good or bad, but
  <del>thinking</del> <ins>running it</ins> makes it so.
</blockquote>

What this example does: Start with the del tag in the code, then inspect what sits inside it and which attributes have been added to its opening tag.
