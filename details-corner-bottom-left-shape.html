corner-bottom-left-shape

In CSS, corner-bottom-left-shape is the setting for shape of bottom-left corner. It helps decide where an element sits and how it relates to nearby boxes.

CSS reads this as the name corner-bottom-left-shape, a colon, and then a value. As you compare values, positioning properties work as a team, so inspect the containing box as well as the element itself.

Important: This feature is experimental. Check browser support before relying on it.

Here is a corner-bottom-left-shape example to try in a practice page:

/* Keyword values */
corner-bottom-left-shape: bevel;
corner-bottom-left-shape: round;

/* superellipse() function values */
corner-bottom-left-shape: superellipse(0.7);
corner-bottom-left-shape: superellipse(-1.9);

/* Global values */
corner-bottom-left-shape: inherit;
corner-bottom-left-shape: initial;
corner-bottom-left-shape: revert;
corner-bottom-left-shape: revert-layer;
corner-bottom-left-shape: unset;

The important part: In this case corner-bottom-left-shape receives bevel. Trying a contrasting valid value makes the difference easier to spot.
