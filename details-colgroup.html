colgroup

The colgroup element groups columns together. Think of your table like a spreadsheet. Each column goes up and down. You use colgroup to treat several columns as a team, so you can give them all the same width or the same background color without repeating yourself over and over.

Put the colgroup right after the opening table tag -- it should be the first child of the table. Inside the colgroup, you put col elements (one per column). Any styles you put on the colgroup or on a col element will automatically apply to every cell sitting in those columns.

The example below makes the second column a light grey so you can see how the whole column gets colored.



<table>
    <colgroup>
        <col>
        <col style="background-color: rgb(240, 240, 240)">
    </colgroup>
    <tr>
        <th>Task</th>
        <th>Status</th>
    </tr>
    <tr>
        <td>Layout</td>
        <td>Done</td>
    </tr>
</table>
