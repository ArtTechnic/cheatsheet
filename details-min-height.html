min-height

Choose min-height when the design needs different min height. It helps decide how large a box or part of a box becomes.

Place a colon after min-height, then supply the value you want. When testing this property, remember: padding and borders can also affect the final visible size, especially when box-sizing changes.

Try the following min-height code in a spare practice file:

min-height: 150px;

How this sample works: The sample asks the browser to use 150px for min-height. The property stays the same when you experiment; the value is the part to change.
