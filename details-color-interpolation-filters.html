color-interpolation-filters

The browser looks at color-interpolation-filters when working out color space for filter effects. It changes how something looks rather than changing what the HTML means.

Add color-interpolation-filters inside a CSS rule and follow it with a colon and value.

This short sample shows color-interpolation-filters in use:

color-interpolation-filters: auto;
color-interpolation-filters: linearRGB;
color-interpolation-filters: sRGB;

/* Global values */
color-interpolation-filters: inherit;
color-interpolation-filters: initial;
color-interpolation-filters: revert;
color-interpolation-filters: revert-layer;
color-interpolation-filters: unset;

Reading the example: The sample asks the browser to use auto for color-interpolation-filters.
