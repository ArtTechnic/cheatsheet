column-rule-color

The column-rule-color property controls rule color. It changes how something looks rather than changing what the HTML means.

The value written after column-rule-color: chooses the result. While experimenting, keep in mind that check that text remains easy to read and that important information does not depend on colour alone.

Here is a column-rule-color example to try in a practice page:

column-rule-color: purple;

The important part: Here, purple is the value attached to column-rule-color. Change it, refresh the page, and compare the new result with the original.
