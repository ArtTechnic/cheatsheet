background-position

In CSS, background-position is the setting for position of background. It changes how something looks rather than changing what the HTML means.

Add background-position inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Check that text remains easy to read and that important information does not depend on colour alone.

A small background-position example looks like this:

background-position: top;

What this example does: The important instruction in the sample is top. It is assigned to background-position and changes only the part described above.
