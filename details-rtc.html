rtc

When you write rtc, you are marking something as ruby annotation group. Think of it as an HTML building block specifically meant for ruby annotation group.

Put the content belonging to rtc between its opening and closing tags. Use it when that description matches the content, not simply because its default appearance seems useful.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

This short sample shows rtc in use:

<ruby lang="zh-Hant">
  <rbc>
    <rb>馬</rb><rp>(</rp><rt>mǎ</rt><rp>)</rp>
    <rb>來</rb><rp>(</rp><rt>lái</rt><rp>)</rp>
    <rb>西</rb><rp>(</rp><rt>xī</rt><rp>)</rp>
    <rb>亞</rb><rp>(</rp><rt>yà</rt><rp>)</rp>
  </rbc>
  <rtc lang="en">
    <rp>(</rp><rt>Malaysia</rt><rp>)</rp>
  </rtc>
</ruby>

What to notice: Here rtc supplies the meaning described above; the surrounding tags provide the context needed for the example to make sense.
