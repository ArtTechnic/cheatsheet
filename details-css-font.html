font

The browser looks at font when working out shorthand for font properties. It changes the presentation or flow of writing.

A rule using font needs a value after the colon. One useful test is to change only that value; test several lines, long words, and zoomed text—a single short sentence can hide problems.

Use this font sample as a starting point, then change one piece at a time:

font:
  1.2rem "Fira Sans",
  sans-serif;

The important part: Here, 1.2rem "Fira Sans", sans-serif is the value attached to font. Change it, refresh the page, and compare the new result with the original.
