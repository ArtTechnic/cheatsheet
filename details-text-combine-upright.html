text-combine-upright

The text-combine-upright property controls combines characters for vertical text. It helps decide where an element sits and how it relates to nearby boxes.

The value written after text-combine-upright: chooses the result. While experimenting, keep in mind that positioning properties work as a team, so inspect the containing box as well as the element itself.

A small text-combine-upright example looks like this:

text-combine-upright: none;

What this example does: This declaration gives text-combine-upright the value none. Replace that value with another valid choice to compare the two results.
