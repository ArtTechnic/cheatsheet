text-combine-upright

The text-combine-upright property controls combines characters for vertical text. It helps decide where an element sits and how it relates to nearby boxes.

The value written after text-combine-upright: chooses the result.

A small text-combine-upright example looks like this:

text-combine-upright: none;

What this example does: This declaration gives text-combine-upright the value none.
