math-depth

The math-depth property controls depth of MathML expressions. It changes one particular part of the browser’s styling calculation.

CSS reads this as the name math-depth, a colon, and then a value. As you compare values, change only this property while practising, then compare the before and after result.

A small math-depth example looks like this:

/* Keyword values */
math-depth: auto-add;

/* Relative values */
math-depth: add(2);
math-depth: add(-2);

/* Absolute value */
math-depth: 4;

/* Global values */
math-depth: inherit;
math-depth: initial;
math-depth: revert;
math-depth: revert-layer;
math-depth: unset;

The important part: In this case math-depth receives auto-add. Trying a contrasting valid value makes the difference easier to spot.
