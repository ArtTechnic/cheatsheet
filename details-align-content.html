align-content

Think of align-content as the control for flex lines alignment. It helps arrange children inside a layout.

Add align-content inside a CSS rule and follow it with a colon and value.

This short sample shows align-content in use:

align-content: start;

What this example does: The sample asks the browser to use start for align-content.
