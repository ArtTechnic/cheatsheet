align-content

Think of align-content as the control for flex lines alignment. It helps arrange children inside a layout.

Add align-content inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Some layout properties only work after the parent has been made a grid or flex container.

This short sample shows align-content in use:

align-content: start;

What this example does: The sample asks the browser to use start for align-content. The property stays the same when you experiment; the value is the part to change.
