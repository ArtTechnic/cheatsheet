grid-column-end

The grid-column-end property controls end edge of grid item placement. It helps arrange children inside a layout.

Different values give grid-column-end different instructions.

Here is a grid-column-end example to try in a practice page:

grid-column-end: auto;

What this example does: Read the line as ‘set grid-column-end to auto.’ That value is the instruction controlling what you see.
