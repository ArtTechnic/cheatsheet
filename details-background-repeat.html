background-repeat

In CSS, background-repeat is the setting for repeat behavior. It changes how something looks rather than changing what the HTML means.

The value written after background-repeat: chooses the result.

The code below shows a simple use of background-repeat:

background-repeat: repeat-x;

How this sample works: The sample asks the browser to use repeat-x for background-repeat.
