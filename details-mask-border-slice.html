mask-border-slice

The mask-border-slice property controls slice of mask border image. It changes a line, edge, or corner around an element.

The value written after mask-border-slice: chooses the result.

Here is a compact mask-border-slice example you can inspect and alter:

/* All sides */
mask-border-slice: 30%;

/* top and bottom | left and right */
mask-border-slice: 10% 30%;

/* top | left and right | bottom */
mask-border-slice: 30 30% 45;

/* top | right | bottom | left */
mask-border-slice: 7 12 14 5;

/* Using the `fill` keyword */
mask-border-slice: 10% fill 7 12;

/* Global values */
mask-border-slice: inherit;
mask-border-slice: initial;
mask-border-slice: revert;
mask-border-slice: revert-layer;
mask-border-slice: unset;

Reading the example: The sample asks the browser to use 30% for mask-border-slice.
