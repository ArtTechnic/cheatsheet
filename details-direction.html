CSS

direction

With direction, you can control text direction. It changes one particular part of the browser’s styling calculation.

A rule using direction needs a value after the colon. One useful test is to change only that value; change only this property while practising, then compare the before and after result.

A small direction example looks like this:

direction: ltr;

The important part: This declaration gives direction the value ltr. Replace that value with another valid choice to compare the two results.
