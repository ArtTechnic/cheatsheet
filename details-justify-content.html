justify-content

The justify-content property controls main-axis alignment. It helps arrange children inside a layout.

The value written after justify-content: chooses the result. While experimenting, keep in mind that some layout properties only work after the parent has been made a grid or flex container.

A small justify-content example looks like this:

justify-content: start;

Reading the example: In this case justify-content receives start. Trying a contrasting valid value makes the difference easier to spot.
