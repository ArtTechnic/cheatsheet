border-block-start-color

The border-block-start-color property controls color of start edge of block border. It changes how something looks rather than changing what the HTML means.

A rule using border-block-start-color needs a value after the colon. One useful test is to change only that value; check that text remains easy to read and that important information does not depend on colour alone.

The code below shows a simple use of border-block-start-color:

border-block-start-color: red;
writing-mode: horizontal-tb;

What this example does: The sample asks the browser to use red for border-block-start-color. The property stays the same when you experiment; the value is the part to change.
