grid-row-end

In CSS, grid-row-end is the setting for end edge of grid row placement. It helps arrange children inside a layout.

CSS reads this as the name grid-row-end, a colon, and then a value. As you compare values, some layout properties only work after the parent has been made a grid or flex container.

The code below shows a simple use of grid-row-end:

grid-row-end: auto;

Reading the example: The colon separates grid-row-end from its chosen value, auto. The semicolon marks the end of this declaration.
