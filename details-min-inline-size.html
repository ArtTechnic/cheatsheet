min-inline-size

Changing min-inline-size changes minimum inline size of element. It helps decide how large a box or part of a box becomes.

CSS reads this as the name min-inline-size, a colon, and then a value.

A practical min-inline-size example is shown below:

min-inline-size: 200px;
writing-mode: horizontal-tb;

What this example does: Read the line as ‘set min-inline-size to 200px.’ That value is the instruction controlling what you see.
