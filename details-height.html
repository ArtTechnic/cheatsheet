height

Use height when you need to change element height. It helps decide how large a box or part of a box becomes.

Add height inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Padding and borders can also affect the final visible size, especially when box-sizing changes.

A practical height example is shown below:

height: 150px;

What to notice: The colon separates height from its chosen value, 150px. The semicolon marks the end of this declaration.
