mask-type

Choose mask-type when the design needs different type of SVG mask element. It changes one particular part of the browser’s styling calculation.

Place a colon after mask-type, then supply the value you want. When testing this property, remember: change only this property while practising, then compare the before and after result.

Try the following mask-type code in a spare practice file:

/* Keyword values */
mask-type: luminance;
mask-type: alpha;

/* Global values */
mask-type: inherit;
mask-type: initial;
mask-type: revert;
mask-type: revert-layer;
mask-type: unset;

Reading the example: Read the line as ‘set mask-type to luminance.’ That value is the instruction controlling what you see.
