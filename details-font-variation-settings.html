font-variation-settings

Use font-variation-settings when you need to change low-level font variations API. It changes the presentation or flow of writing.

Add font-variation-settings inside a CSS rule and follow it with a colon and value.

Use this font-variation-settings sample as a starting point, then change one piece at a time:

font-variation-settings: "wght" 50;

The important part: Read the line as ‘set font-variation-settings to "wght" 50.’ That value is the instruction controlling what you see.
