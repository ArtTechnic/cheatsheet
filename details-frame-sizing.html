frame-sizing

Think of frame-sizing as the control for sizing of frame elements. It changes one particular part of the browser’s styling calculation.

A rule using frame-sizing needs a value after the colon. One useful test is to change only that value; change only this property while practising, then compare the before and after result.

Important: This feature is experimental. Check browser support before relying on it.

Here is a compact frame-sizing example you can inspect and alter:

/* Keyword values */
frame-sizing: auto;
frame-sizing: content-width;
frame-sizing: content-height;
frame-sizing: content-inline-size;
frame-sizing: content-block-size;

/* Global values */
frame-sizing: inherit;
frame-sizing: initial;
frame-sizing: revert;
frame-sizing: revert-layer;
frame-sizing: unset;

What to notice: The colon separates frame-sizing from its chosen value, auto. The semicolon marks the end of this declaration.
