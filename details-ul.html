ul

The ul tag marks part of the page as unordered list. It is one of the building blocks used to organise related items into a list instead of leaving them as loose paragraphs.

Put the content belonging to ul between its opening and closing tags. Lists have a container and items inside it, so check that each item is nested inside the correct kind of list.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

Here is an ul example to try in a practice page:

<ul>
  <li>Milk</li>
  <li>
    Cheese
    <ul>
      <li>Blue cheese</li>
      <li>Feta</li>
    </ul>
  </li>
</ul>

The important part: Start with the ul tag in the code, then inspect what sits inside it and which attributes have been added to its opening tag.
