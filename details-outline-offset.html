outline-offset

With outline-offset, you can control space between outline and border. It changes a line, edge, or corner around an element.

Add outline-offset inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Borders take up space in the box; outlines usually draw outside it without changing the layout.

Here is an outline-offset example to try in a practice page:

outline-offset: 4px;

What to notice: Read the line as ‘set outline-offset to 4px.’ That value is the instruction controlling what you see.
