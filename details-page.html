page

In CSS, page is the setting for adds page breaks after element. It controls how content is divided across columns, pages, or separate pieces.

A rule using page needs a value after the colon. One useful test is to change only that value; the browser may need enough content before the effect becomes obvious.

A small page example looks like this:

/* set a named page */
page: exampleName;
page: chapterIntro;

/* Use ancestors named page */
page: auto; /* default value */

/* Global values */
page: inherit;
page: initial;
page: revert;
page: revert-layer;
page: unset;

Reading the example: Here, exampleName is the value attached to page. Change it, refresh the page, and compare the new result with the original.
