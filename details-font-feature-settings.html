font-feature-settings

The browser looks at font-feature-settings when working out controls OpenType features. It changes the presentation or flow of writing.

Place a colon after font-feature-settings, then supply the value you want. When testing this property, remember: test several lines, long words, and zoomed text—a single short sentence can hide problems.

The code below shows a simple use of font-feature-settings:

font-feature-settings: normal;

The important part: The colon separates font-feature-settings from its chosen value, normal. The semicolon marks the end of this declaration.
