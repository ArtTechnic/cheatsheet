border-inline

Think of border-inline as the control for shorthand for inline-start/end borders. It changes a line, edge, or corner around an element.

Different values give border-inline different instructions.

A small border-inline example looks like this:

border-inline: solid;
writing-mode: horizontal-tb;

What to notice: This declaration gives border-inline the value solid.
