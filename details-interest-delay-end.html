interest-delay-end

The interest-delay-end property controls end of interest delay period. It changes one particular part of the browser’s styling calculation.

A rule using interest-delay-end needs a value after the colon. One useful test is to change only that value; change only this property while practising, then compare the before and after result.

Important: This feature is experimental. Check browser support before relying on it.

A practical interest-delay-end example is shown below:

/* Keyword or custom delay */
interest-delay-end: normal;
interest-delay-end: 2s;
interest-delay-end: 250ms;

/* Global values */
interest-delay-end: inherit;
interest-delay-end: initial;
interest-delay-end: revert;
interest-delay-end: revert-layer;
interest-delay-end: unset;

What this example does: This declaration gives interest-delay-end the value normal. Replace that value with another valid choice to compare the two results.
