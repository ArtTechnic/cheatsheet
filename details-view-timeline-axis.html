view-timeline-axis

Use view-timeline-axis when you need to change axis of view timeline. It changes the presentation or flow of writing.

The value written after view-timeline-axis: chooses the result.

Use this view-timeline-axis sample as a starting point, then change one piece at a time:

/* Logical property values */
view-timeline-axis: block;
view-timeline-axis: inline;

/* Physical property values */
view-timeline-axis: y;
view-timeline-axis: x;

/* Global values */
view-timeline-axis: inherit;
view-timeline-axis: initial;
view-timeline-axis: revert;
view-timeline-axis: revert-layer;
view-timeline-axis: unset;

Reading the example: The important instruction in the sample is block. It is assigned to view-timeline-axis and changes only the part described above.
