marker

Choose marker when the design needs different shorthand for marker properties. It changes list markers, numbering, or generated punctuation.

The value written after marker: chooses the result. While experimenting, keep in mind that keep the result understandable even when custom decoration is unavailable.

A practical marker example is shown below:

marker: none;
marker: url("markers.svg#arrow");

/* Global values */
marker: inherit;
marker: initial;
marker: revert;
marker: revert-layer;
marker: unset;

Reading the example: In this case marker receives none. Trying a contrasting valid value makes the difference easier to spot.
