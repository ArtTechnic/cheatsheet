line-clamp

Use line-clamp when you need to change clamping of text lines. It changes the presentation or flow of writing.

A rule using line-clamp needs a value after the colon.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

Use this line-clamp sample as a starting point, then change one piece at a time:

/* Keyword value */
line-clamp: none;

/* <integer> values */
line-clamp: 3;
line-clamp: 10;

/* Global values */
line-clamp: inherit;
line-clamp: initial;
line-clamp: revert;
line-clamp: revert-layer;
line-clamp: unset;

What this example does: Here, none is the value attached to line-clamp.
