padding-block

Think of padding-block as the control for shorthand for block-direction padding. It changes space around, inside, or between boxes.

Add padding-block inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Add a temporary border while practising so you can see exactly which space moved.

The code below shows a simple use of padding-block:

padding-block: 10px 20px;
writing-mode: horizontal-tb;

What to notice: The important instruction in the sample is 10px 20px. It is assigned to padding-block and changes only the part described above.
