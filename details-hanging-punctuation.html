hanging-punctuation

The hanging-punctuation property controls allows punctuation outside line box. It changes one particular part of the browser’s styling calculation.

Place a colon after hanging-punctuation, then supply the value you want. When testing this property, remember: change only this property while practising, then compare the before and after result.

Try the following hanging-punctuation code in a spare practice file:

/* Keyword values */
hanging-punctuation: none;
hanging-punctuation: first;
hanging-punctuation: last;
hanging-punctuation: allow-end;

/* Two keywords */
hanging-punctuation: first allow-end;
hanging-punctuation: first last;
hanging-punctuation: last allow-end;

/* Three keywords */
hanging-punctuation: first allow-end last;

/* Global values */
hanging-punctuation: inherit;
hanging-punctuation: initial;
hanging-punctuation: revert;
hanging-punctuation: revert-layer;
hanging-punctuation: unset;

How this sample works: Read the line as ‘set hanging-punctuation to none.’ That value is the instruction controlling what you see.
