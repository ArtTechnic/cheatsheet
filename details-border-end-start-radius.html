border-end-start-radius

Changing border-end-start-radius changes radius of end edge in start direction. It changes a line, edge, or corner around an element.

Add border-end-start-radius inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Borders take up space in the box; outlines usually draw outside it without changing the layout.

Try the following border-end-start-radius code in a spare practice file:

border-end-start-radius: 80px 80px;

What to notice: This declaration gives border-end-start-radius the value 80px 80px. Replace that value with another valid choice to compare the two results.
