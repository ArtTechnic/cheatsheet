border-inline-start-style

With border-inline-start-style, you can control style of start edge of inline border. It changes a line, edge, or corner around an element.

A rule using border-inline-start-style needs a value after the colon. One useful test is to change only that value; borders take up space in the box; outlines usually draw outside it without changing the layout.

Try the following border-inline-start-style code in a spare practice file:

border-inline-start-style: dotted;
writing-mode: horizontal-tb;

What this example does: Here, dotted is the value attached to border-inline-start-style. Change it, refresh the page, and compare the new result with the original.
