hyphens

In CSS, hyphens is the setting for hyphenation of text. It changes the presentation or flow of writing.

Place a colon after hyphens, then supply the value you want. When testing this property, remember: test several lines, long words, and zoomed text—a single short sentence can hide problems.

Try the following hyphens code in a spare practice file:

hyphens: none;

The important part: The sample asks the browser to use none for hyphens. The property stays the same when you experiment; the value is the part to change.
