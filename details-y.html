y

The browser looks at y when working out y coordinate of SVG element. It changes one particular part of the browser’s styling calculation.

CSS reads this as the name y, a colon, and then a value. As you compare values, change only this property while practising, then compare the before and after result.

Here is a compact y example you can inspect and alter:

/* length and percentage values */
y: 10px;
y: 10%;

/* Global values */
y: inherit;
y: initial;
y: revert;
y: revert-layer;
y: unset;

The important part: The important instruction in the sample is 10px. It is assigned to y and changes only the part described above.
