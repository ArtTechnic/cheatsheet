pointer-events

The browser looks at pointer-events when working out mouse event handling. It changes part of the way a visitor interacts with an element.

A rule using pointer-events needs a value after the colon. One useful test is to change only that value; do not make an object look clickable unless it really performs an action.

A small pointer-events example looks like this:

pointer-events: auto;

How this sample works: In this case pointer-events receives auto. Trying a contrasting valid value makes the difference easier to spot.
