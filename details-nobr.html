nobr

When you write nobr, you are marking something as non-standard no-wrap text. Think of it as an HTML building block specifically meant for non-standard no-wrap text.

Anything meant to belong to nobr normally sits inside the pair of tags. Use it when that description matches the content, not simply because its default appearance seems useful.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

Here is a compact nobr example you can inspect and alter:

<span class="nobr">Long line with no breaks</span>

What this example does: Start with the nobr tag in the code, then inspect what sits inside it and which attributes have been added to its opening tag.
