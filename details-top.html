CSS

top

The top property controls position offset top. It helps decide where an element sits and how it relates to nearby boxes.

Add top inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Positioning properties work as a team, so inspect the containing box as well as the element itself.

Here is a top example to try in a practice page:

top: 0;

What this example does: The colon separates top from its chosen value, 0. The semicolon marks the end of this declaration.
