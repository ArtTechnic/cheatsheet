shape-rendering

Changing shape-rendering changes defines the shape-rendering property. It changes one particular part of the browser’s styling calculation.

Place a colon after shape-rendering, then supply the value you want. When testing this property, remember: change only this property while practising, then compare the before and after result.

The code below shows a simple use of shape-rendering:

shape-rendering: auto;
shape-rendering: crispEdges;
shape-rendering: geometricPrecision;
shape-rendering: optimizeSpeed;

/* Global values */
shape-rendering: inherit;
shape-rendering: initial;
shape-rendering: revert;
shape-rendering: revert-layer;
shape-rendering: unset;

What this example does: The important instruction in the sample is auto. It is assigned to shape-rendering and changes only the part described above.
