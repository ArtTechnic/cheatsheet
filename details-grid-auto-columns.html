grid-auto-columns

The grid-auto-columns property controls size of auto-generated grid columns. It helps arrange children inside a layout.

The value written after grid-auto-columns: chooses the result. While experimenting, keep in mind that some layout properties only work after the parent has been made a grid or flex container.

This short sample shows grid-auto-columns in use:

grid-auto-columns: auto;

What this example does: This declaration gives grid-auto-columns the value auto. Replace that value with another valid choice to compare the two results.
