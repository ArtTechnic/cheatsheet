interpolate-size

Changing interpolate-size changes whether to interpolate size. It helps decide how large a box or part of a box becomes.

A rule using interpolate-size needs a value after the colon. One useful test is to change only that value; padding and borders can also affect the final visible size, especially when box-sizing changes.

Important: This feature is experimental. Check browser support before relying on it.

Try the following interpolate-size code in a spare practice file:

/* Keyword values */
interpolate-size: allow-keywords;
interpolate-size: numeric-only;

/* Global values */
interpolate-size: inherit;
interpolate-size: initial;
interpolate-size: revert;
interpolate-size: revert-layer;
interpolate-size: unset;

What this example does: Here, allow-keywords is the value attached to interpolate-size. Change it, refresh the page, and compare the new result with the original.
