text-wrap-mode

Choose text-wrap-mode when the design needs different mode of text wrapping. It changes the presentation or flow of writing.

CSS reads this as the name text-wrap-mode, a colon, and then a value. As you compare values, test several lines, long words, and zoomed text—a single short sentence can hide problems.

Use this text-wrap-mode sample as a starting point, then change one piece at a time:

text-wrap-mode: wrap;

The important part: This declaration gives text-wrap-mode the value wrap. Replace that value with another valid choice to compare the two results.
