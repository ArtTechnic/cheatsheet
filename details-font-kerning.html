font-kerning

With font-kerning, you can control automatic kerning of fonts. It changes the presentation or flow of writing.

The value written after font-kerning: chooses the result. While experimenting, keep in mind that test several lines, long words, and zoomed text—a single short sentence can hide problems.

A small font-kerning example looks like this:

font-kerning: auto;

What this example does: This declaration gives font-kerning the value auto. Replace that value with another valid choice to compare the two results.
