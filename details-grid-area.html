grid-area

Use grid-area when you need to change shorthand for grid placement. It helps arrange children inside a layout.

A rule using grid-area needs a value after the colon.

A small grid-area example looks like this:

grid-area: a;

How this sample works: The important instruction in the sample is a. It is assigned to grid-area and changes only the part described above.
