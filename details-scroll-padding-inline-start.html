scroll-padding-inline-start

Use scroll-padding-inline-start when you need to change defines the scroll-padding-inline-start property. It changes space around, inside, or between boxes.

The value written after scroll-padding-inline-start: chooses the result. While experimenting, keep in mind that add a temporary border while practising so you can see exactly which space moved.

A practical scroll-padding-inline-start example is shown below:

scroll-padding-inline-start: 0;

What this example does: The colon separates scroll-padding-inline-start from its chosen value, 0. The semicolon marks the end of this declaration.
