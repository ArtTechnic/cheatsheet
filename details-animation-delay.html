animation-delay

Use animation-delay when you need to change delay. It controls movement or a visual change over time or space.

Place a colon after animation-delay, then supply the value you want. When testing this property, remember: use gentle motion and remember that some visitors ask their device to reduce animation.

Try the following animation-delay code in a spare practice file:

animation-delay: 250ms;

What to notice: In this case animation-delay receives 250ms. Trying a contrasting valid value makes the difference easier to spot.
