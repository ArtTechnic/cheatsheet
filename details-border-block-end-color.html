border-block-end-color

Use border-block-end-color when you need to change color of end edge of block border. It changes how something looks rather than changing what the HTML means.

CSS reads this as the name border-block-end-color, a colon, and then a value. As you compare values, check that text remains easy to read and that important information does not depend on colour alone.

Here is a border-block-end-color example to try in a practice page:

border-block-end-color: red;
writing-mode: horizontal-tb;

What to notice: This declaration gives border-block-end-color the value red. Replace that value with another valid choice to compare the two results.
