scroll-target-group

It helps decide whether a box is shown and what happens when its contents do not fit normally.

Place a colon after scroll-target-group, then supply the value you want.

Important: This feature is experimental. Check browser support before relying on it.

This short sample shows scroll-target-group in use:

/* Keyword values */
scroll-target-group: none;
scroll-target-group: auto;

/* Global values */
scroll-target-group: inherit;
scroll-target-group: initial;
scroll-target-group: revert;
scroll-target-group: revert-layer;
scroll-target-group: unset;

What this example does: The colon separates scroll-target-group from its chosen value, none.
