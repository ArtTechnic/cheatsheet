padding-top

The padding-top property controls top padding. It changes space around, inside, or between boxes.

Add padding-top inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Add a temporary border while practising so you can see exactly which space moved.

A practical padding-top example is shown below:

padding-top: 1em;

The important part: In this case padding-top receives 1em. Trying a contrasting valid value makes the difference easier to spot.
