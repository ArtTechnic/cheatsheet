text-spacing-trim

Think of text-spacing-trim as the control for trims spacing around text. It changes space around, inside, or between boxes.

CSS reads this as the name text-spacing-trim, a colon, and then a value. As you compare values, add a temporary border while practising so you can see exactly which space moved.

Important: This feature is experimental. Check browser support before relying on it.

Use this text-spacing-trim sample as a starting point, then change one piece at a time:

/* Keyword values */
text-spacing-trim: normal;
text-spacing-trim: space-all;
text-spacing-trim: space-first;
text-spacing-trim: trim-start;

/* Global values */
text-spacing-trim: inherit;
text-spacing-trim: initial;
text-spacing-trim: revert;
text-spacing-trim: revert-layer;
text-spacing-trim: unset;

The important part: Read the line as ‘set text-spacing-trim to normal.’ That value is the instruction controlling what you see.
