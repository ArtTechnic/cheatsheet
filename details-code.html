When you write code, you are marking something as inline code. It works on a small piece of text inside a sentence, like placing a useful label or emphasis around selected words.

The opening code tag starts its area and the matching closing tag ends it. Keep the opening tag before the affected words and the closing tag immediately after them.

Use this code sample as a starting point, then change one piece at a time:

<p>
  The <code>push()</code> method adds one or more elements to the end of an
  array and returns the new length of the array.
</p>

How this sample works: This sample puts code into a small piece of realistic HTML. Change its content or one attribute at a time and watch what differs.
