flood-color

In CSS, flood-color is the setting for color of SVG filter flood. It changes how something looks rather than changing what the HTML means.

Add flood-color inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Check that text remains easy to read and that important information does not depend on colour alone.

The code below shows a simple use of flood-color:

/* <color> values */
flood-color: red;
flood-color: hsl(120deg 75% 25% / 60%);
flood-color: currentColor;

/* Global values */
flood-color: inherit;
flood-color: initial;
flood-color: revert;
flood-color: revert-layer;
flood-color: unset;

What to notice: The important instruction in the sample is red. It is assigned to flood-color and changes only the part described above.
