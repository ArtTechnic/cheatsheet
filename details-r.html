CSS

r

Think of r as the control for radius of SVG element. It changes one particular part of the browser’s styling calculation.

CSS reads this as the name r, a colon, and then a value. As you compare values, change only this property while practising, then compare the before and after result.

Here is a compact r example you can inspect and alter:

/* Length and percentage values */
r: 3px;
r: 20%;

/* Global values */
r: inherit;
r: initial;
r: revert;
r: revert-layer;
r: unset;

What to notice: Read the line as ‘set r to 3px.’ That value is the instruction controlling what you see.
