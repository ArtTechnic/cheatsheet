flex-wrap

The flex-wrap property controls wrap flex items. It helps arrange children inside a layout.

CSS reads this as the name flex-wrap, a colon, and then a value. As you compare values, some layout properties only work after the parent has been made a grid or flex container.

Here is a compact flex-wrap example you can inspect and alter:

flex-wrap: nowrap;

Reading the example: Here, nowrap is the value attached to flex-wrap. Change it, refresh the page, and compare the new result with the original.
