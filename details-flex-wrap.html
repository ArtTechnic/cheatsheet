flex-wrap

The flex-wrap property controls wrap flex items. It helps arrange children inside a layout.

CSS reads this as the name flex-wrap, a colon, and then a value.

Here is a compact flex-wrap example you can inspect and alter:

flex-wrap: nowrap;

Reading the example: Here, nowrap is the value attached to flex-wrap.
