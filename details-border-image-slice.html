border-image-slice

Choose border-image-slice when the design needs different slice inward offsets for border image. It changes a line, edge, or corner around an element.

A rule using border-image-slice needs a value after the colon. One useful test is to change only that value; borders take up space in the box; outlines usually draw outside it without changing the layout.

A small border-image-slice example looks like this:

border-image-slice: 30;

What this example does: The colon separates border-image-slice from its chosen value, 30. The semicolon marks the end of this declaration.
