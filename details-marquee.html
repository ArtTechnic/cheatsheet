marquee

The marquee tag marks part of the page as deprecated scrolling text. Think of it as an HTML building block specifically meant for deprecated scrolling text.

Treat the two marquee tags like the covers of a folder: the related content goes between them. Use it when that description matches the content, not simply because its default appearance seems useful.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

Use this marquee sample as a starting point, then change one piece at a time:

<marquee>This text will scroll from right to left</marquee>

<marquee direction="up">This text will scroll from bottom to top</marquee>

<marquee
  direction="down"
  width="250"
  height="200"
  behavior="alternate"
  class="outlined">
  <marquee behavior="alternate">This text will bounce</marquee>
</marquee>

What to notice: Start with the marquee tag in the code, then inspect what sits inside it and which attributes have been added to its opening tag.
