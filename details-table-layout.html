table-layout

The table-layout property controls how the browser decides how wide each column in your table should be. It has two common settings: auto and fixed. The auto setting (which is the default) looks at the content inside each cell to figure out the width. The fixed setting ignores the content and uses the width you set on the table itself.

With the fixed setting, the browser makes all columns the same width based on the table's total width. This means the layout does not jump around or shift as the page loads and the content changes. It is faster because the browser does not need to read every cell first. Use fixed when you want predictable, steady column widths.

With the auto setting, the browser stretches or shrinks columns to fit their content. This can look nicer sometimes, but it also means the widths might change while the page is still loading. If you do not set a width on your table, using fixed will not do much -- so always pair table-layout: fixed with a width setting.

table {table-layout: fixed; width: 360px;}
