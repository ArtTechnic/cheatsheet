vertical-align

Use vertical-align when you need to change inline element vertical alignment. It helps arrange children inside a layout.

A rule using vertical-align needs a value after the colon.

Use this vertical-align sample as a starting point, then change one piece at a time:

vertical-align: baseline;

What this example does: This declaration gives vertical-align the value baseline.
