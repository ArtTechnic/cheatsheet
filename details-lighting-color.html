lighting-color

The lighting-color property controls color of lighting for SVG. It changes how something looks rather than changing what the HTML means.

Place a colon after lighting-color, then supply the value you want. When testing this property, remember: check that text remains easy to read and that important information does not depend on colour alone.

Try the following lighting-color code in a spare practice file:

/* <color> values */
lighting-color: red;
lighting-color: hsl(120deg 75% 25% / 60%);
lighting-color: currentColor;

/* Global values */
lighting-color: inherit;
lighting-color: initial;
lighting-color: revert;
lighting-color: revert-layer;
lighting-color: unset;

What this example does: In this case lighting-color receives red. Trying a contrasting valid value makes the difference easier to spot.
