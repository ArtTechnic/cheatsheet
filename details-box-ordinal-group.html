box-ordinal-group

Choose box-ordinal-group when the design needs different ordinal order of box in container. It changes one particular part of the browser’s styling calculation.

A rule using box-ordinal-group needs a value after the colon. One useful test is to change only that value; change only this property while practising, then compare the before and after result.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

Here is a box-ordinal-group example to try in a practice page:

/* <integer> values */
box-ordinal-group: 1;
box-ordinal-group: 5;

/* Global values */
box-ordinal-group: inherit;
box-ordinal-group: initial;
box-ordinal-group: unset;

Reading the example: The sample asks the browser to use 1 for box-ordinal-group. The property stays the same when you experiment; the value is the part to change.
