box-ordinal-group

Choose box-ordinal-group when the design needs different ordinal order of box in container.

A rule using box-ordinal-group needs a value after the colon.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

Here is a box-ordinal-group example to try in a practice page:

/* <integer> values */
box-ordinal-group: 1;
box-ordinal-group: 5;

/* Global values */
box-ordinal-group: inherit;
box-ordinal-group: initial;
box-ordinal-group: unset;

Reading the example: The sample asks the browser to use 1 for box-ordinal-group.
