rule-color

It changes how something looks rather than changing what the HTML means.

CSS reads this as the name rule-color, a colon, and then a value.

Important: This feature is experimental. Check browser support before relying on it.

A practical rule-color example is shown below:

rule-color: purple;

What to notice: Here, purple is the value attached to rule-color.
