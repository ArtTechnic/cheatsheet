rule-color

Think of rule-color as the control for defines the rule-color property. It changes how something looks rather than changing what the HTML means.

CSS reads this as the name rule-color, a colon, and then a value. As you compare values, check that text remains easy to read and that important information does not depend on colour alone.

Important: This feature is experimental. Check browser support before relying on it.

A practical rule-color example is shown below:

rule-color: purple;

What to notice: Here, purple is the value attached to rule-color. Change it, refresh the page, and compare the new result with the original.
