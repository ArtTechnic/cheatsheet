plaintext

In an HTML document, plaintext represents obsolete plain-text element. Think of it as an HTML building block specifically meant for obsolete plain-text element.

The opening plaintext tag starts its area and the matching closing tag ends it. Use it when that description matches the content, not simply because its default appearance seems useful.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

The code below shows a simple use of plaintext:

<plaintext>

The important part: Here plaintext supplies the meaning described above; the surrounding tags provide the context needed for the example to make sense.
