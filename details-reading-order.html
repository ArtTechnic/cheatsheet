reading-order

In CSS, reading-order is the setting for order of reading elements. It helps arrange children inside a layout.

Add reading-order inside a CSS rule and follow it with a colon and value.

Important: This feature is experimental. Check browser support before relying on it.

Try the following reading-order code in a spare practice file:

/* <integer> values */
reading-order: 1;
reading-order: -1;

/* Global values */
reading-order: inherit;
reading-order: initial;
reading-order: revert;
reading-order: revert-layer;
reading-order: unset;

What to notice: The colon separates reading-order from its chosen value, 1.
