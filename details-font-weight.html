font-weight

Choose font-weight when the design needs different weight (boldness). It changes the presentation or flow of writing.

Add font-weight inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Test several lines, long words, and zoomed text—a single short sentence can hide problems.

A practical font-weight example is shown below:

font-weight: normal;

What this example does: This declaration gives font-weight the value normal. Replace that value with another valid choice to compare the two results.
