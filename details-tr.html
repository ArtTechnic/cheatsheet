tr

A tr (table row) element creates one horizontal line in your table. Inside each tr, you put cells -- td elements for regular data and th elements for headers. Every row of your table, whether it is in the header, body, or footer, is made of tr elements.

Try to keep the number of cells consistent from row to row. If one row has three cells and the next row has four, the browser will add an empty cell to fill in the gap. This can make your table look messy, so count your cells carefully when building each row.

When the first cell in a row is a header (an th with scope="row"), it acts like a label for that entire row. This is useful for tables where the first column names a thing and the rest of the columns describe it -- like a parts list where the first column is the part name and the other columns are its properties.



<tr>
    <th scope="row">CPU</th>
    <td>Intel Core i7</td>
    <td>$320</td>
</tr>
<tr>
    <th scope="row">RAM</th>
    <td>16GB DDR4</td>
    <td>$80</td>
</tr>
