border-spacing

The border-spacing property sets the gap between table cells. It only matters when your table uses separate borders (which is the default). Think of it like leaving a little breathing room between each cell in your table.

You give it a number, like 8px. Bigger numbers mean bigger gaps. Smaller numbers mean cells sit closer together. If you set border-collapse to collapse, border-spacing has no effect because the cells are merged anyway.

table {
    border-collapse: separate;
    border-spacing: 8px;
}
