link-parameters

Choose link-parameters when the design needs different parameters for links.

CSS reads this as the name link-parameters, a colon, and then a value.

Important: This feature is experimental. Check browser support before relying on it.

Use this link-parameters sample as a starting point, then change one piece at a time:

/* single value */
link-parameters: param(--color, red);

/* multiple values */
link-parameters:
  param(--color1, red),
  param(--color2, blue),
  param(--color3, green);

How this sample works: This declaration gives link-parameters the value param(--color, red).
