font-variant-position

The browser looks at font-variant-position when working out position variants for font. It helps decide where an element sits and how it relates to nearby boxes.

Add font-variant-position inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Positioning properties work as a team, so inspect the containing box as well as the element itself.

Here is a font-variant-position example to try in a practice page:

/* Keyword values */
font-variant-position: normal;
font-variant-position: sub;
font-variant-position: super;

/* Global values */
font-variant-position: inherit;
font-variant-position: initial;
font-variant-position: revert;
font-variant-position: revert-layer;
font-variant-position: unset;

Reading the example: The sample asks the browser to use normal for font-variant-position. The property stays the same when you experiment; the value is the part to change.
