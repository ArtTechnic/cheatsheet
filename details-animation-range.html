animation-range

Think of animation-range as the control for sets range of animation timeline progress. It controls movement or a visual change over time or space.

Place a colon after animation-range, then supply the value you want. When testing this property, remember: use gentle motion and remember that some visitors ask their device to reduce animation.

The code below shows a simple use of animation-range:

/* Range start value only*/
/* Single value syntax */
animation-range: normal;
animation-range: 20%;
animation-range: 100px;
animation-range: cover;
animation-range: contain;
/* Two value syntax */
animation-range: cover 20%;
animation-range: contain 100px;

/* Range start and end values */
/* Two value syntax */
animation-range: normal 25%;
animation-range: 25% normal;
animation-range: 25% 50%;
animation-range: entry exit;
/* Three value syntax */
animation-range: cover cover 200px;
animation-range: 10% exit 90%;
animation-range: entry 10% 90%;
/* Four value syntax */
animation-range: cover 0% cover 200px;
animation-range: entry 10% exit 100%;

/* Global values */
animation-range: inherit;
animation-range: initial;
/* More lines are shown on MDN. */

What to notice: The colon separates animation-range from its chosen value, normal. The semicolon marks the end of this declaration.
