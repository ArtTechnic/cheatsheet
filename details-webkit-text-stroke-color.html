-webkit-text-stroke-color

Changing -webkit-text-stroke-color changes defines the -webkit-text-stroke-color property. It changes how something looks rather than changing what the HTML means.

CSS reads this as the name -webkit-text-stroke-color, a colon, and then a value. As you compare values, check that text remains easy to read and that important information does not depend on colour alone.

Here is a compact -webkit-text-stroke-color example you can inspect and alter:

/* <color> values */
-webkit-text-stroke-color: red;
-webkit-text-stroke-color: #e08ab4;
-webkit-text-stroke-color: rgb(200 100 0);

/* Global values */
-webkit-text-stroke-color: inherit;
-webkit-text-stroke-color: initial;
-webkit-text-stroke-color: revert;
-webkit-text-stroke-color: revert-layer;
-webkit-text-stroke-color: unset;

What this example does: This declaration gives -webkit-text-stroke-color the value red. Replace that value with another valid choice to compare the two results.
