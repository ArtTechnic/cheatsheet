background-repeat-x

The background-repeat-x property controls horizontal tiling of background image. It changes how something looks rather than changing what the HTML means.

Add background-repeat-x inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Check that text remains easy to read and that important information does not depend on colour alone.

Important: This feature is experimental. Check browser support before relying on it.

This short sample shows background-repeat-x in use:

background-repeat-x: repeat;

How this sample works: Here, repeat is the value attached to background-repeat-x. Change it, refresh the page, and compare the new result with the original.
