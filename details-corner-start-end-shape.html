corner-start-end-shape

Changing corner-start-end-shape changes shape of start corner in end direction. It changes one particular part of the browser’s styling calculation.

Different values give corner-start-end-shape different instructions. Try them one at a time, and remember that change only this property while practising, then compare the before and after result.

Important: This feature is experimental. Check browser support before relying on it.

The code below shows a simple use of corner-start-end-shape:

/* Keyword values */
corner-start-end-shape: square;
corner-start-end-shape: bevel;

/* superellipse() function values */
corner-start-end-shape: superellipse(1.5);
corner-start-end-shape: superellipse(-2.2);

/* Global values */
corner-start-end-shape: inherit;
corner-start-end-shape: initial;
corner-start-end-shape: revert;
corner-start-end-shape: revert-layer;
corner-start-end-shape: unset;

What to notice: In this case corner-start-end-shape receives square. Trying a contrasting valid value makes the difference easier to spot.
