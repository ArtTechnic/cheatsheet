border-right-width

The border-right-width property controls width of right border. It helps decide how large a box or part of a box becomes.

A rule using border-right-width needs a value after the colon. One useful test is to change only that value; padding and borders can also affect the final visible size, especially when box-sizing changes.

Try the following border-right-width code in a spare practice file:

border-right-width: thick;

What to notice: This declaration gives border-right-width the value thick. Replace that value with another valid choice to compare the two results.
