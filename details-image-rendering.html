image-rendering

The image-rendering property controls image scaling algorithm. It changes one particular part of the browser’s styling calculation.

A rule using image-rendering needs a value after the colon. One useful test is to change only that value; change only this property while practising, then compare the before and after result.

Use this image-rendering sample as a starting point, then change one piece at a time:

image-rendering: auto;

What to notice: This declaration gives image-rendering the value auto. Replace that value with another valid choice to compare the two results.
