caret-animation

Changing caret-animation changes animation behavior of caret. It controls movement or a visual change over time or space.

Different values give caret-animation different instructions. Try them one at a time, and remember that use gentle motion and remember that some visitors ask their device to reduce animation.

Important: This feature is experimental. Check browser support before relying on it.

The code below shows a simple use of caret-animation:

/* Keyword values */
caret-animation: auto;
caret-animation: manual;

/* Global values */
caret-animation: inherit;
caret-animation: initial;
caret-animation: revert;
caret-animation: revert-layer;
caret-animation: unset;

How this sample works: In this case caret-animation receives auto. Trying a contrasting valid value makes the difference easier to spot.
