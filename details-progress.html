progress

The name progress tells you what it represents: progress indicator. It is a form building block: forms let a visitor enter information, choose something, or start an action.

Put the content belonging to progress between its opening and closing tags. Every control needs a clear label, and the page should still make sense when somebody uses only a keyboard.

The code below shows a simple use of progress:

<label for="file">File progress:</label>

<progress id="file" max="100" value="70">70%</progress>

Reading the example: Here progress supplies the meaning described above; the surrounding tags provide the context needed for the example to make sense.
