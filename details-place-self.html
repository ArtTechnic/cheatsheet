place-self

With place-self, you can control alignment and justification of self. It helps arrange children inside a layout.

Place a colon after place-self, then supply the value you want. When testing this property, remember: some layout properties only work after the parent has been made a grid or flex container.

A small place-self example looks like this:

place-self: stretch center;

What to notice: Read the line as ‘set place-self to stretch center.’ That value is the instruction controlling what you see.
