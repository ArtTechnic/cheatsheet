border-block

The border-block property controls shorthand for block-start/end border edges. It changes a line, edge, or corner around an element.

Add border-block inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Borders take up space in the box; outlines usually draw outside it without changing the layout.

The code below shows a simple use of border-block:

border-block: solid;
writing-mode: horizontal-tb;

What this example does: This declaration gives border-block the value solid. Replace that value with another valid choice to compare the two results.
