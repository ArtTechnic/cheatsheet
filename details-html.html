html

Use html when a piece of HTML represents root element. Think of a web page as a labelled storage box: this tag marks one of the large, important parts of that box.

The opening html tag starts its area and the matching closing tag ends it. Use it for its intended page section rather than merely to change the appearance; CSS handles the appearance.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

A small html example looks like this:

<!doctype html>
<html lang="en">
  <head>
    <!-- … -->
  </head>
  <body>
    <!-- … -->
  </body>
</html>

The important part: The sample demonstrates <html>.
