justify-items

The justify-items property controls alignment of content in grid cells. It helps arrange children inside a layout.

Different values give justify-items different instructions. Try them one at a time, and remember that some layout properties only work after the parent has been made a grid or flex container.

The code below shows a simple use of justify-items:

justify-items: stretch;

What to notice: The important instruction in the sample is stretch. It is assigned to justify-items and changes only the part described above.
