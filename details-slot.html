slot

The name slot tells you what it represents: web Components slot. This tag supports how a page is built or behaves rather than representing an ordinary paragraph or picture.

Put the content belonging to slot between its opening and closing tags. Place it in the correct part of the document and use it only when that extra behaviour or reusable structure is needed.

Use this slot sample as a starting point, then change one piece at a time:

<template id="element-details-template">
  <style>
    details {
      font-family: "Open Sans Light", "Helvetica", "Arial", sans-serif;
    }
    .name {
      font-weight: bold;
      color: #217ac0;
      font-size: 120%;
    }
    h4 {
      margin: 10px 0 -8px 0;
      background: #217ac0;
      color: white;
      padding: 2px 6px;
      border: 1px solid #cee9f9;
      border-radius: 4px;
    }
    .attributes {
      margin-left: 22px;
      font-size: 90%;
    }
    .attributes p {
      margin-left: 16px;
      font-style: italic;
    }
  </style>
  <details>
<!-- More lines are shown on MDN. -->

What this example does: The sample demonstrates <slot>. Its attributes and enclosed content provide the information this element needs.
