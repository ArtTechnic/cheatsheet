corner-end-end-shape

Choose corner-end-end-shape when the design needs different shape of end corner in end direction. It changes one particular part of the browser’s styling calculation.

A rule using corner-end-end-shape needs a value after the colon. One useful test is to change only that value; change only this property while practising, then compare the before and after result.

Important: This feature is experimental. Check browser support before relying on it.

Use this corner-end-end-shape sample as a starting point, then change one piece at a time:

/* Keyword values */
corner-end-end-shape: scoop;
corner-end-end-shape: notch;

/* superellipse() function values */
corner-end-end-shape: superellipse(4);
corner-end-end-shape: superellipse(-0.5);

/* Global values */
corner-end-end-shape: inherit;
corner-end-end-shape: initial;
corner-end-end-shape: revert;
corner-end-end-shape: revert-layer;
corner-end-end-shape: unset;

What this example does: This declaration gives corner-end-end-shape the value scoop. Replace that value with another valid choice to compare the two results.
