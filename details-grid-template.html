grid-template

Think of grid-template as the control for shorthand for grid definition. It helps arrange children inside a layout.

A rule using grid-template needs a value after the colon.

This short sample shows grid-template in use:

grid-template:
  "a a a" 40px
  "b c c" 40px
  "b c c" 40px / 1fr 1fr 1fr;

The important part: The colon separates grid-template from its chosen value, "a a a" 40px "b c c" 40px "b c c" 40px / 1fr 1fr 1fr.
