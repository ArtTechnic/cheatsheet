font-variant-ligatures

The font-variant-ligatures property controls ligatures for font. It changes the presentation or flow of writing.

Place a colon after font-variant-ligatures, then supply the value you want. When testing this property, remember: test several lines, long words, and zoomed text—a single short sentence can hide problems.

The code below shows a simple use of font-variant-ligatures:

font-variant-ligatures: normal;

How this sample works: Read the line as ‘set font-variant-ligatures to normal.’ That value is the instruction controlling what you see.
