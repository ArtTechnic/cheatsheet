base

The base tag marks part of the page as base URL for relative links. Think of it as a signpost: part of the code says where something is, and the browser uses that address to reach it.

Unlike most tags, base is a void element: it has no closing tag and holds no content between tags. Check the address carefully. A small spelling mistake can point to a missing page or resource.

Here is a base example to try in a practice page:

<meta property="og:image" content="https://example.com/thumbnail.jpg" />

How this sample works: Here base supplies the meaning described above; the surrounding tags provide the context needed for the example to make sense.
