template

Use template when a piece of HTML represents client-side template. This tag supports how a page is built or behaves rather than representing an ordinary paragraph or picture.

The opening template tag starts its area and the matching closing tag ends it. Place it in the correct part of the document and use it only when that extra behaviour or reusable structure is needed.

Important: This is not a standard feature, so different browsers may handle it differently. Treat it as something to recognize rather than a dependable first choice.

Here is a compact template example you can inspect and alter:

<table id="producttable">
  <thead>
    <tr>
      <td>UPC_Code</td>
      <td>Product_Name</td>
    </tr>
  </thead>
  <tbody>
    <!-- existing data could optionally be included here -->
  </tbody>
</table>

<template id="productrow">
  <tr>
    <td class="record"></td>
    <td></td>
  </tr>
</template>

What this example does: Start with the template tag in the code, then inspect what sits inside it and which attributes have been added to its opening tag.
