interactivity

With interactivity, you can control interactivity mode of element.

Different values give interactivity different instructions.

Important: This feature is experimental. Check browser support before relying on it.

Here is a compact interactivity example you can inspect and alter:

/* Keyword values */
interactivity: auto;
interactivity: inert;

/* Global values */
interactivity: inherit;
interactivity: initial;
interactivity: revert;
interactivity: revert-layer;
interactivity: unset;

What to notice: This declaration gives interactivity the value auto.
