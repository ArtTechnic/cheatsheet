animation-range-end

Think of animation-range-end as the control for end point of animation timeline range. It controls movement or a visual change over time or space.

Different values give animation-range-end different instructions.

Try the following animation-range-end code in a spare practice file:

/* Keyword or length percentage value */
animation-range-end: normal;
animation-range-end: 80%;
animation-range-end: 700px;

/* Named timeline range value */
animation-range-end: cover;
animation-range-end: contain;
animation-range-end: cover 80%;
animation-range-end: contain 700px;

/* Global values */
animation-range-end: inherit;
animation-range-end: initial;
animation-range-end: revert;
animation-range-end: revert-layer;
animation-range-end: unset;

The important part: The sample asks the browser to use normal for animation-range-end.
