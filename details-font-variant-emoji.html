font-variant-emoji

Choose font-variant-emoji when the design needs different emoji font variant handling. It changes the presentation or flow of writing.

CSS reads this as the name font-variant-emoji, a colon, and then a value.

A practical font-variant-emoji example is shown below:

/* Keyword values */
font-variant-emoji: normal;
font-variant-emoji: text;
font-variant-emoji: emoji;
font-variant-emoji: unicode;

/* Global values */
font-variant-emoji: inherit;
font-variant-emoji: initial;
font-variant-emoji: revert;
font-variant-emoji: revert-layer;
font-variant-emoji: unset;

What this example does: The colon separates font-variant-emoji from its chosen value, normal.
