anchor-name

With anchor-name, you can control names anchor for anchored positioning.

Place a colon after anchor-name, then supply the value you want.

Here is an anchor-name example to try in a practice page:

/* Single values */
anchor-name: none;
anchor-name: --name;

/* Multiple values */
anchor-name: --name, --another-name;

/* Global values */
anchor-name: inherit;
anchor-name: initial;
anchor-name: revert;
anchor-name: revert-layer;
anchor-name: unset;

How this sample works: The colon separates anchor-name from its chosen value, none.
