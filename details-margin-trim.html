margin-trim

The browser looks at margin-trim when working out trims margin at fragment breaks. It changes space around, inside, or between boxes.

CSS reads this as the name margin-trim, a colon, and then a value.

Important: This feature is experimental. Check browser support before relying on it.

Try the following margin-trim code in a spare practice file:

margin-trim: none;
margin-trim: block;
margin-trim: block-start;
margin-trim: block-end;
margin-trim: inline;
margin-trim: inline-start;
margin-trim: inline-end;

/* Global values */
margin-trim: inherit;
margin-trim: initial;
margin-trim: revert;
margin-trim: revert-layer;
margin-trim: unset;

What this example does: The important instruction in the sample is none. It is assigned to margin-trim and changes only the part described above.
