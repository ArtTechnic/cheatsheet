background-attachment

The browser looks at background-attachment when working out how background scrolls with content. It changes how something looks rather than changing what the HTML means.

CSS reads this as the name background-attachment, a colon, and then a value.

A small background-attachment example looks like this:

background-attachment: scroll;

Reading the example: The sample asks the browser to use scroll for background-attachment.
