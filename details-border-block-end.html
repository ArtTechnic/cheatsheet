border-block-end

In CSS, border-block-end is the setting for shorthand for end edge of block border. It changes a line, edge, or corner around an element.

A rule using border-block-end needs a value after the colon.

The code below shows a simple use of border-block-end:

border-block-end: solid;
writing-mode: horizontal-tb;

What this example does: The sample asks the browser to use solid for border-block-end.
