border-top-width

In CSS, border-top-width is the setting for width of top border. It helps decide how large a box or part of a box becomes.

A rule using border-top-width needs a value after the colon. One useful test is to change only that value; padding and borders can also affect the final visible size, especially when box-sizing changes.

This short sample shows border-top-width in use:

border-top-width: thick;

How this sample works: The sample asks the browser to use thick for border-top-width. The property stays the same when you experiment; the value is the part to change.
