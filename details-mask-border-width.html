mask-border-width

Choose mask-border-width when the design needs different width of mask border image. It helps decide how large a box or part of a box becomes.

A rule using mask-border-width needs a value after the colon. One useful test is to change only that value; padding and borders can also affect the final visible size, especially when box-sizing changes.

A small mask-border-width example looks like this:

/* Keyword value */
mask-border-width: auto;

/* <length> value */
mask-border-width: 1rem;

/* <percentage> value */
mask-border-width: 25%;

/* <number> value */
mask-border-width: 3;

/* top and bottom | left and right */
mask-border-width: 2em 3em;

/* top | left and right | bottom */
mask-border-width: 5% 15% 10%;

/* top | right | bottom | left */
mask-border-width: 5% 2em 10% auto;

/* Global values */
mask-border-width: inherit;
mask-border-width: initial;
mask-border-width: revert;
mask-border-width: revert-layer;
mask-border-width: unset;

How this sample works: The important instruction in the sample is auto. It is assigned to mask-border-width and changes only the part described above.
