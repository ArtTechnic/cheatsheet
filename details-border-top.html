border-top

The browser looks at border-top when working out shorthand for top border. It changes a line, edge, or corner around an element.

Add border-top inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Borders take up space in the box; outlines usually draw outside it without changing the layout.

Here is a compact border-top example you can inspect and alter:

border-top: solid;

What this example does: This declaration gives border-top the value solid. Replace that value with another valid choice to compare the two results.
