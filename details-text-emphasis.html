text-emphasis

With text-emphasis, you can control shorthand for text emphasis. It changes the presentation or flow of writing.

Add text-emphasis inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Test several lines, long words, and zoomed text—a single short sentence can hide problems.

A practical text-emphasis example is shown below:

text-emphasis: none;

Reading the example: This declaration gives text-emphasis the value none. Replace that value with another valid choice to compare the two results.
