-webkit-mask-composite

Choose -webkit-mask-composite when the design needs different defines the -webkit-mask-composite property. It changes one particular part of the browser’s styling calculation.

CSS reads this as the name -webkit-mask-composite, a colon, and then a value. As you compare values, change only this property while practising, then compare the before and after result.

Important: This is not a standard feature, so different browsers may handle it differently. Treat it as something to recognize rather than a dependable first choice.

Use this -webkit-mask-composite sample as a starting point, then change one piece at a time:

/* Keyword values */
-webkit-mask-composite: clear;
-webkit-mask-composite: copy;
-webkit-mask-composite: source-over;
-webkit-mask-composite: source-in;
-webkit-mask-composite: source-out;
-webkit-mask-composite: source-atop;
-webkit-mask-composite: destination-over;
-webkit-mask-composite: destination-in;
-webkit-mask-composite: destination-out;
-webkit-mask-composite: destination-atop;
-webkit-mask-composite: xor;

/* Global values */
-webkit-mask-composite: inherit;
-webkit-mask-composite: initial;
-webkit-mask-composite: revert;
-webkit-mask-composite: revert-layer;
-webkit-mask-composite: unset;

The important part: Here, clear is the value attached to -webkit-mask-composite. Change it, refresh the page, and compare the new result with the original.
