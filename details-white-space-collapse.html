white-space-collapse

Choose white-space-collapse when the design needs different how white space is collapsed. It changes one particular part of the browser’s styling calculation.

A rule using white-space-collapse needs a value after the colon. One useful test is to change only that value; change only this property while practising, then compare the before and after result.

Try the following white-space-collapse code in a spare practice file:

/* Keyword values */
white-space-collapse: collapse;
white-space-collapse: preserve;
white-space-collapse: preserve-breaks;
white-space-collapse: preserve-spaces;
white-space-collapse: break-spaces;

/* Global values */
white-space-collapse: inherit;
white-space-collapse: initial;
white-space-collapse: revert;
white-space-collapse: revert-layer;
white-space-collapse: unset;

Reading the example: Read the line as ‘set white-space-collapse to collapse.’ That value is the instruction controlling what you see.
