overscroll-behavior-x

In CSS, overscroll-behavior-x is the setting for horizontal overscroll behavior. It helps decide whether a box is shown and what happens when its contents do not fit normally.

The value written after overscroll-behavior-x: chooses the result.

A practical overscroll-behavior-x example is shown below:

/* Keyword values */
overscroll-behavior-x: auto; /* default */
overscroll-behavior-x: contain;
overscroll-behavior-x: none;

/* Global values */
overscroll-behavior-x: inherit;
overscroll-behavior-x: initial;
overscroll-behavior-x: revert;
overscroll-behavior-x: revert-layer;
overscroll-behavior-x: unset;

How this sample works: Here, auto is the value attached to overscroll-behavior-x.
