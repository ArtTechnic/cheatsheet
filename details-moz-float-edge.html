-moz-float-edge

Use -moz-float-edge when you need to change defines the -moz-float-edge property. It helps decide where an element sits and how it relates to nearby boxes.

Add -moz-float-edge inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Positioning properties work as a team, so inspect the containing box as well as the element itself.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

This short sample shows -moz-float-edge in use:

/* Keyword values */
-moz-float-edge: content-box;
-moz-float-edge: margin-box;

/* Global values */
-moz-float-edge: inherit;
-moz-float-edge: initial;
-moz-float-edge: unset;

The important part: The colon separates -moz-float-edge from its chosen value, content-box. The semicolon marks the end of this declaration.
