text-underline-position

In CSS, text-underline-position is the setting for position of text underline. It helps decide where an element sits and how it relates to nearby boxes.

Add text-underline-position inside a CSS rule and follow it with a colon and value.

Use this text-underline-position sample as a starting point, then change one piece at a time:

text-underline-position: auto;

What to notice: Read the line as ‘set text-underline-position to auto.’ That value is the instruction controlling what you see.
