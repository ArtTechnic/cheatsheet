column-height

In CSS, column-height is the setting for height of columns. It helps decide how large a box or part of a box becomes.

CSS reads this as the name column-height, a colon, and then a value. As you compare values, padding and borders can also affect the final visible size, especially when box-sizing changes.

Important: This feature is experimental. Check browser support before relying on it.

Try the following column-height code in a spare practice file:

/* Keyword */
column-height: auto;

/* <length> value */
column-height: 300px;
column-height: 25em;
column-height: 70vh;

/* Global values */
column-height: inherit;
column-height: initial;
column-height: revert;
column-height: revert-layer;
column-height: unset;

What this example does: In this case column-height receives auto. Trying a contrasting valid value makes the difference easier to spot.
