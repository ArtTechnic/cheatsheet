text-decoration-inset

In CSS, text-decoration-inset is the setting for inset of text decoration. It changes space around, inside, or between boxes.

CSS reads this as the name text-decoration-inset, a colon, and then a value.

Important: This feature is experimental. Check browser support before relying on it.

The code below shows a simple use of text-decoration-inset:

text-decoration-inset: 20px;

What this example does: The colon separates text-decoration-inset from its chosen value, 20px.
