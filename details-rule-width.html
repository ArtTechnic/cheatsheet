rule-width

Choose rule-width when the design needs different defines the rule-width property. It helps decide how large a box or part of a box becomes.

CSS reads this as the name rule-width, a colon, and then a value. As you compare values, padding and borders can also affect the final visible size, especially when box-sizing changes.

Important: This feature is experimental. Check browser support before relying on it.

A small rule-width example looks like this:

rule-width: thin;

Reading the example: The colon separates rule-width from its chosen value, thin. The semicolon marks the end of this declaration.
