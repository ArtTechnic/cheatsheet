stop-color

It changes how something looks rather than changing what the HTML means.

Different values give stop-color different instructions.

Use this stop-color sample as a starting point, then change one piece at a time:

/* <color> values */
stop-color: red;
stop-color: hsl(120deg 75% 25% / 60%);
stop-color: currentColor;

/* Global values */
stop-color: inherit;
stop-color: initial;
stop-color: revert;
stop-color: revert-layer;
stop-color: unset;

How this sample works: The important instruction in the sample is red. It is assigned to stop-color and changes only the part described above.
