grid-auto-flow

Choose grid-auto-flow when the design needs different direction of auto-placement. It helps arrange children inside a layout.

A rule using grid-auto-flow needs a value after the colon. One useful test is to change only that value; some layout properties only work after the parent has been made a grid or flex container.

Use this grid-auto-flow sample as a starting point, then change one piece at a time:

grid-auto-flow: row;

What this example does: Read the line as ‘set grid-auto-flow to row.’ That value is the instruction controlling what you see.
