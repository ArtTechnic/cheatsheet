isolation

Changing isolation changes create stacking context for blending. It changes one particular part of the browser’s styling calculation.

A rule using isolation needs a value after the colon. One useful test is to change only that value; change only this property while practising, then compare the before and after result.

The code below shows a simple use of isolation:

isolation: auto;

What this example does: Read the line as ‘set isolation to auto.’ That value is the instruction controlling what you see.
