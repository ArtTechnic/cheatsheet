corner-left-shape

Think of corner-left-shape as the control for shape of left edge corners. It helps decide where an element sits and how it relates to nearby boxes.

A rule using corner-left-shape needs a value after the colon. One useful test is to change only that value; positioning properties work as a team, so inspect the containing box as well as the element itself.

Important: This feature is experimental. Check browser support before relying on it.

Here is a compact corner-left-shape example you can inspect and alter:

/* Single keyword value set for both corners */
corner-left-shape: round;
corner-left-shape: bevel;

/* Single superellipse() value set for both corners */
corner-left-shape: superellipse(1.2);
corner-left-shape: superellipse(-2.5);

/* Top corner, bottom corner */
corner-left-shape: round bevel;
corner-left-shape: bevel superellipse(1.2);

/* Global values */
corner-left-shape: inherit;
corner-left-shape: initial;
corner-left-shape: revert;
corner-left-shape: revert-layer;
corner-left-shape: unset;

Reading the example: The colon separates corner-left-shape from its chosen value, round. The semicolon marks the end of this declaration.
