view-transition-scope

In CSS, view-transition-scope is the setting for scope of view transition. It controls movement or a visual change over time or space.

CSS reads this as the name view-transition-scope, a colon, and then a value.

Important: This feature is experimental. Check browser support before relying on it.

The code below shows a simple use of view-transition-scope:

/* Keyword values */
view-transition-scope: none;
view-transition-scope: all;

/* Global values */
view-transition-scope: inherit;
view-transition-scope: initial;
view-transition-scope: revert;
view-transition-scope: revert-layer;
view-transition-scope: unset;

Reading the example: In this case view-transition-scope receives none.
