padding-bottom

Choose padding-bottom when the design needs different bottom padding. It changes space around, inside, or between boxes.

A rule using padding-bottom needs a value after the colon. One useful test is to change only that value; add a temporary border while practising so you can see exactly which space moved.

A small padding-bottom example looks like this:

padding-bottom: 1em;

Reading the example: In this case padding-bottom receives 1em. Trying a contrasting valid value makes the difference easier to spot.
