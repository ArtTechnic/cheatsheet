all

Changing all changes resets all properties to initial or inherit. It changes one particular part of the browser’s styling calculation.

CSS reads this as the name all, a colon, and then a value. As you compare values, change only this property while practising, then compare the before and after result.

Use this all sample as a starting point, then change one piece at a time:

/* no all property */

The important part: The colon separates all from its chosen value, value. The semicolon marks the end of this declaration.
