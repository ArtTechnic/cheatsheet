background-blend-mode

Changing background-blend-mode changes how background layers blend together. It changes how something looks rather than changing what the HTML means.

Add background-blend-mode inside a CSS rule and follow it with a colon and value.

Use this background-blend-mode sample as a starting point, then change one piece at a time:

background-blend-mode: normal;

How this sample works: The colon separates background-blend-mode from its chosen value, normal.
