empty-cells

The empty-cells property controls what happens to cells that have no content inside them. An empty cell is a table cell (either a td or a th) where you wrote nothing between the opening and closing tags.

If you set it to show, the browser draws borders and backgrounds around empty cells just like normal cells. If you set it to hide, the borders and backgrounds disappear for those empty spots, but the cell itself stays the same size. This only affects tables where borders are separate (not collapsed).

The example below shows a table where one cell is empty. By default, empty cells still show their borders. Try changing the value to hide and see what happens.

table {
    empty-cells: show;
}
