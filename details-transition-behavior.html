transition-behavior

With transition-behavior, you can control behavior of transitions. It controls movement or a visual change over time or space.

The value written after transition-behavior: chooses the result. While experimenting, keep in mind that use gentle motion and remember that some visitors ask their device to reduce animation.

Try the following transition-behavior code in a spare practice file:

/* Keyword values */
transition-behavior: allow-discrete;
transition-behavior: normal;

/* Global values */
transition-behavior: inherit;
transition-behavior: initial;
transition-behavior: revert;
transition-behavior: revert-layer;
transition-behavior: unset;

What to notice: Read the line as ‘set transition-behavior to allow-discrete.’ That value is the instruction controlling what you see.
