-webkit-mask-repeat-x

The -webkit-mask-repeat-x property controls defines the -webkit-mask-repeat-x property. It changes one particular part of the browser’s styling calculation.

Place a colon after -webkit-mask-repeat-x, then supply the value you want. When testing this property, remember: change only this property while practising, then compare the before and after result.

Important: This is not a standard feature, so different browsers may handle it differently. Treat it as something to recognize rather than a dependable first choice.

A practical -webkit-mask-repeat-x example is shown below:

/* Keyword values */
-webkit-mask-repeat-x: repeat;
-webkit-mask-repeat-x: no-repeat;
-webkit-mask-repeat-x: space;
-webkit-mask-repeat-x: round;

/* Multiple values */
-webkit-mask-repeat-x: repeat, no-repeat, space;

/* Global values */
-webkit-mask-repeat-x: inherit;
-webkit-mask-repeat-x: initial;
-webkit-mask-repeat-x: revert;
-webkit-mask-repeat-x: revert-layer;
-webkit-mask-repeat-x: unset;

How this sample works: Here, repeat is the value attached to -webkit-mask-repeat-x. Change it, refresh the page, and compare the new result with the original.
