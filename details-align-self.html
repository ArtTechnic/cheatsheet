align-self

In CSS, align-self is the setting for override align for an item. It helps arrange children inside a layout.

Place a colon after align-self, then supply the value you want. When testing this property, remember: some layout properties only work after the parent has been made a grid or flex container.

Here is a compact align-self example you can inspect and alter:

align-self: stretch;

How this sample works: In this case align-self receives stretch. Trying a contrasting valid value makes the difference easier to spot.
