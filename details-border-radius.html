border-radius

Choose border-radius when the design needs different rounded corners. It changes a line, edge, or corner around an element.

CSS reads this as the name border-radius, a colon, and then a value. As you compare values, borders take up space in the box; outlines usually draw outside it without changing the layout.

A practical border-radius example is shown below:

border-radius: 30px;

What to notice: The important instruction in the sample is 30px. It is assigned to border-radius and changes only the part described above.
