scroll-padding-bottom

The scroll-padding-bottom property controls defines the scroll-padding-bottom property. It changes space around, inside, or between boxes.

Add scroll-padding-bottom inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Add a temporary border while practising so you can see exactly which space moved.

Try the following scroll-padding-bottom code in a spare practice file:

scroll-padding-bottom: 0;

The important part: Read the line as ‘set scroll-padding-bottom to 0.’ That value is the instruction controlling what you see.
