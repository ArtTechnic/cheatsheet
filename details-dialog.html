dialog

The name dialog tells you what it represents: dialog box. It creates a part of the page that a visitor can open, close, or interact with instead of only reading it.

Put the content belonging to dialog between its opening and closing tags. Make its purpose clear in the visible text so the visitor knows what will happen before using it.

A practical dialog example is shown below:

<button command="show-modal" commandfor="my-dialog">Open dialog</button>

<dialog id="my-dialog">
  <p>This dialog was opened using an invoker command.</p>
  <button commandfor="my-dialog" command="close">Close</button>
</dialog>

How this sample works: The key piece in this sample is <dialog>. Read outward from that tag to see what belongs to it and how it is configured.
