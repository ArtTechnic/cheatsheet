animation-iteration-count

Think of animation-iteration-count as the control for iterations. It controls movement or a visual change over time or space.

A rule using animation-iteration-count needs a value after the colon. One useful test is to change only that value; use gentle motion and remember that some visitors ask their device to reduce animation.

Try the following animation-iteration-count code in a spare practice file:

animation-iteration-count: 0;

What this example does: Here, 0 is the value attached to animation-iteration-count. Change it, refresh the page, and compare the new result with the original.
