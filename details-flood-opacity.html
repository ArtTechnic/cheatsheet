flood-opacity

Choose flood-opacity when the design needs different opacity of SVG filter flood. It changes how something looks rather than changing what the HTML means.

Different values give flood-opacity different instructions. Try them one at a time, and remember that check that text remains easy to read and that important information does not depend on colour alone.

Try the following flood-opacity code in a spare practice file:

/* numeric and percentage values */
flood-opacity: 0.2;
flood-opacity: 20%;

/* Global values */
flood-opacity: inherit;
flood-opacity: initial;
flood-opacity: revert;
flood-opacity: revert-layer;
flood-opacity: unset;

Reading the example: This declaration gives flood-opacity the value 0.2. Replace that value with another valid choice to compare the two results.
