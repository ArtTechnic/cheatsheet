scroll-margin-inline

Changing scroll-margin-inline changes defines the scroll-margin-inline property. It changes space around, inside, or between boxes.

CSS reads this as the name scroll-margin-inline, a colon, and then a value. As you compare values, add a temporary border while practising so you can see exactly which space moved.

Try the following scroll-margin-inline code in a spare practice file:

scroll-margin-inline: 0;

What to notice: The sample asks the browser to use 0 for scroll-margin-inline. The property stays the same when you experiment; the value is the part to change.
