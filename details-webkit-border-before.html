-webkit-border-before

Think of -webkit-border-before as the control for defines the -webkit-border-before property. It changes a line, edge, or corner around an element.

Different values give -webkit-border-before different instructions. Try them one at a time, and remember that borders take up space in the box; outlines usually draw outside it without changing the layout.

Important: This is not a standard feature, so different browsers may handle it differently. Treat it as something to recognize rather than a dependable first choice.

Use this -webkit-border-before sample as a starting point, then change one piece at a time:

/* Border values */
-webkit-border-before: 1px;
-webkit-border-before: 2px dotted;
-webkit-border-before: medium dashed blue;

/* Global values */
-webkit-border-before: inherit;
-webkit-border-before: initial;
-webkit-border-before: revert;
-webkit-border-before: revert-layer;
-webkit-border-before: unset;

How this sample works: The colon separates -webkit-border-before from its chosen value, 1px. The semicolon marks the end of this declaration.
