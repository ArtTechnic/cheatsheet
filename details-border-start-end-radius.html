border-start-end-radius

Choose border-start-end-radius when the design needs different radius of start edge in end direction. It changes a line, edge, or corner around an element.

A rule using border-start-end-radius needs a value after the colon.

The code below shows a simple use of border-start-end-radius:

border-start-end-radius: 80px 80px;

How this sample works: Here, 80px 80px is the value attached to border-start-end-radius.
