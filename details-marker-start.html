marker-start

The marker-start property controls marker at start of element. It changes list markers, numbering, or generated punctuation.

CSS reads this as the name marker-start, a colon, and then a value. As you compare values, keep the result understandable even when custom decoration is unavailable.

A small marker-start example looks like this:

marker-start: none;
marker-start: url("markers.svg#arrow");

/* Global values */
marker-start: inherit;
marker-start: initial;
marker-start: revert;
marker-start: revert-layer;
marker-start: unset;

The important part: The colon separates marker-start from its chosen value, none. The semicolon marks the end of this declaration.
