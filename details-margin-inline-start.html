margin-inline-start

Choose margin-inline-start when the design needs different margin on inline start edge. It changes space around, inside, or between boxes.

Add margin-inline-start inside a CSS rule and follow it with a colon and value.

A practical margin-inline-start example is shown below:

margin-inline-start: 20px;
writing-mode: horizontal-tb;

What this example does: The important instruction in the sample is 20px. It is assigned to margin-inline-start and changes only the part described above.
