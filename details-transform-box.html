transform-box

The transform-box property controls box for transform origin. It controls movement or a visual change over time or space.

Different values give transform-box different instructions. Try them one at a time, and remember that use gentle motion and remember that some visitors ask their device to reduce animation.

Here is a transform-box example to try in a practice page:

/* Keyword values */
transform-box: content-box;
transform-box: border-box;
transform-box: fill-box;
transform-box: stroke-box;
transform-box: view-box;

/* Global values */
transform-box: inherit;
transform-box: initial;
transform-box: revert;
transform-box: revert-layer;
transform-box: unset;

The important part: The sample asks the browser to use content-box for transform-box. The property stays the same when you experiment; the value is the part to change.
