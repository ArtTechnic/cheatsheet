touch-action

The browser looks at touch-action when working out touch behavior. It changes part of the way a visitor interacts with an element.

The value written after touch-action: chooses the result. While experimenting, keep in mind that do not make an object look clickable unless it really performs an action.

Here is a touch-action example to try in a practice page:

/* Keyword values */
touch-action: auto;
touch-action: none;
touch-action: pan-x;
touch-action: pan-left;
touch-action: pan-right;
touch-action: pan-y;
touch-action: pan-up;
touch-action: pan-down;
touch-action: pinch-zoom;
touch-action: manipulation;

/* Global values */
touch-action: inherit;
touch-action: initial;
touch-action: revert;
touch-action: revert-layer;
touch-action: unset;

Reading the example: This declaration gives touch-action the value auto. Replace that value with another valid choice to compare the two results.
