box-lines

Use box-lines when you need to change whether box children are on single or multiple lines. It changes the presentation or flow of writing.

Different values give box-lines different instructions. Try them one at a time, and remember that test several lines, long words, and zoomed text—a single short sentence can hide problems.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

A practical box-lines example is shown below:

/* Keyword values */
box-lines: single;
box-lines: multiple;

/* Global values */
box-lines: inherit;
box-lines: initial;
box-lines: unset;

Reading the example: Here, single is the value attached to box-lines. Change it, refresh the page, and compare the new result with the original.
