margin-block

Use margin-block when you need to change shorthand for block-direction margins. It changes space around, inside, or between boxes.

Different values give margin-block different instructions. Try them one at a time, and remember that add a temporary border while practising so you can see exactly which space moved.

Try the following margin-block code in a spare practice file:

margin-block: 10px 20px;
writing-mode: horizontal-tb;

The important part: The important instruction in the sample is 10px 20px. It is assigned to margin-block and changes only the part described above.
