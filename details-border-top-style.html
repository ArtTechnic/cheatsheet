border-top-style

Use border-top-style when you need to change style of top border. It changes a line, edge, or corner around an element.

Add border-top-style inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Borders take up space in the box; outlines usually draw outside it without changing the layout.

A small border-top-style example looks like this:

border-top-style: none;

How this sample works: The important instruction in the sample is none. It is assigned to border-top-style and changes only the part described above.
