list-style

The list-style property controls list marker style. It changes list markers, numbering, or generated punctuation.

Add list-style inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Keep the result understandable even when custom decoration is unavailable.

A practical list-style example is shown below:

list-style: square;

Reading the example: In this case list-style receives square. Trying a contrasting valid value makes the difference easier to spot.
