contain-intrinsic-height

The browser looks at contain-intrinsic-height when working out intrinsic height of contained element. It helps decide how large a box or part of a box becomes.

Place a colon after contain-intrinsic-height, then supply the value you want. When testing this property, remember: padding and borders can also affect the final visible size, especially when box-sizing changes.

A small contain-intrinsic-height example looks like this:

/* Keyword values */
contain-intrinsic-height: none;

/* <length> values */
contain-intrinsic-height: 1000px;
contain-intrinsic-height: 10rem;

/* auto <length> */
contain-intrinsic-height: auto 300px;

/* Global values */
contain-intrinsic-height: inherit;
contain-intrinsic-height: initial;
contain-intrinsic-height: revert;
contain-intrinsic-height: revert-layer;
contain-intrinsic-height: unset;

Reading the example: This declaration gives contain-intrinsic-height the value none. Replace that value with another valid choice to compare the two results.
