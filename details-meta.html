meta

In an HTML document, meta represents metadata. It gives the browser information about the document rather than adding an ordinary object inside the visible page.

Unlike most tags, meta is a void element: it has no closing tag and holds no content between tags. Although visitors may not see it in the page itself, it can affect browser tabs, search results, or how the document is interpreted.

Here is a meta example to try in a practice page:

<meta
  name="description"
  content="The HTML reference describes all elements and attributes of HTML, including global attributes that apply to all elements." />

The important part: The key piece in this sample is <meta>. Read outward from that tag to see what belongs to it and how it is configured.
