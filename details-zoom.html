zoom

The zoom property scales element content.

Place a colon after zoom, then supply the value you want.

Important: This is not a standard feature, so different browsers may handle it differently. Treat it as something to recognize rather than a dependable first choice.

Here is a zoom example to try in a practice page:

/* <percentage> values */
zoom: 50%;
zoom: 200%;

/* <number> values */
zoom: 1.1;
zoom: 0.7;

/* Non-standard keyword values */
zoom: normal;
zoom: reset;

/* Global values */
zoom: inherit;
zoom: initial;
zoom: revert;
zoom: revert-layer;
zoom: unset;

What this example does: This declaration gives zoom the value 50%.
