baseline-source

In CSS, baseline-source is the setting for whether baseline comes from first or last line. It changes the presentation or flow of writing.

CSS reads this as the name baseline-source, a colon, and then a value.

This short sample shows baseline-source in use:

/* Keyword values */
baseline-source: auto;
baseline-source: first;
baseline-source: last;

/* Global values */
baseline-source: inherit;
baseline-source: initial;
baseline-source: revert;
baseline-source: revert-layer;
baseline-source: unset;

What this example does: Read the line as ‘set baseline-source to auto.’ That value is the instruction controlling what you see.
