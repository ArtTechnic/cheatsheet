field-sizing

Use field-sizing when you need to change sizing behavior of form fields.

CSS reads this as the name field-sizing, a colon, and then a value.

A small field-sizing example looks like this:

/* Keyword values */
field-sizing: content;
field-sizing: fixed;

/* Global values */
field-sizing: inherit;
field-sizing: initial;
field-sizing: revert;
field-sizing: revert-layer;
field-sizing: unset;

What this example does: This declaration gives field-sizing the value content.
