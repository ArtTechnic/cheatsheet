text-box-edge

The browser looks at text-box-edge when working out edge style for text box. It changes the presentation or flow of writing.

Place a colon after text-box-edge, then supply the value you want.

A small text-box-edge example looks like this:

/* Single keyword */
text-box-edge: auto;
text-box-edge: text;

/* Two <text-edge> values */
text-box-edge: text text;
text-box-edge: text alphabetic;
text-box-edge: cap alphabetic;
text-box-edge: ex text;

/* Global values */
text-box-edge: inherit;
text-box-edge: initial;
text-box-edge: revert;
text-box-edge: revert-layer;
text-box-edge: unset;

What to notice: Read the line as ‘set text-box-edge to auto.’ That value is the instruction controlling what you see.
