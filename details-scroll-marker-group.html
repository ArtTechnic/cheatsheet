scroll-marker-group

Think of scroll-marker-group as the control for defines the scroll-marker-group property. It helps decide whether a box is shown and what happens when its contents do not fit normally.

Place a colon after scroll-marker-group, then supply the value you want. When testing this property, remember: hidden or clipped content may become impossible to reach, so test with more content than you expect.

Important: This feature is experimental. Check browser support before relying on it.

A small scroll-marker-group example looks like this:

/* Single values */
scroll-marker-group: before;
scroll-marker-group: after;
scroll-marker-group: none;

/* Global values */
scroll-marker-group: inherit;
scroll-marker-group: initial;
scroll-marker-group: revert;
scroll-marker-group: revert-layer;
scroll-marker-group: unset;

The important part: In this case scroll-marker-group receives before. Trying a contrasting valid value makes the difference easier to spot.
