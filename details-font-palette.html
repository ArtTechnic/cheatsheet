font-palette

Use font-palette when you need to change color palette for fonts. It changes the presentation or flow of writing.

The value written after font-palette: chooses the result. While experimenting, keep in mind that test several lines, long words, and zoomed text—a single short sentence can hide problems.

A small font-palette example looks like this:

/* Using a font-defined palette */
font-palette: normal;

/* Using a user-defined palette */
font-palette: --one;

/* Creating a new palette by blending two others */
font-palette: palette-mix(in lch, --blue, --yellow);

What to notice: In this case font-palette receives normal. Trying a contrasting valid value makes the difference easier to spot.
