border-image-width

Use border-image-width when you need to change width of border image. It helps decide how large a box or part of a box becomes.

Place a colon after border-image-width, then supply the value you want. When testing this property, remember: padding and borders can also affect the final visible size, especially when box-sizing changes.

The code below shows a simple use of border-image-width:

border-image-width: 30px;

What this example does: Read the line as ‘set border-image-width to 30px.’ That value is the instruction controlling what you see.
