widows

Changing widows changes minimum lines at top of page. It controls how content is divided across columns, pages, or separate pieces.

Place a colon after widows, then supply the value you want.

A practical widows example is shown below:

/* <integer> values */
widows: 2;
widows: 3;

/* Global values */
widows: inherit;
widows: initial;
widows: revert;
widows: revert-layer;
widows: unset;

What to notice: In this case widows receives 2.
