inset-block-end

Think of inset-block-end as the control for inset on block end edge. It changes space around, inside, or between boxes.

A rule using inset-block-end needs a value after the colon. One useful test is to change only that value; add a temporary border while practising so you can see exactly which space moved.

The code below shows a simple use of inset-block-end:

writing-mode: horizontal-tb;

What this example does: This declaration gives inset-block-end the value horizontal-tb. Replace that value with another valid choice to compare the two results.
