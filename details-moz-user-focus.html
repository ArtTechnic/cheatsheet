-moz-user-focus

CSS reads this as the name -moz-user-focus, a colon, and then a value.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

This short sample shows -moz-user-focus in use:

/* Keyword values */
-moz-user-focus: none;
-moz-user-focus: normal;
-moz-user-focus: ignore;

/* Global values */
-moz-user-focus: inherit;
-moz-user-focus: initial;
-moz-user-focus: unset;

Reading the example: The sample asks the browser to use none for -moz-user-focus.
