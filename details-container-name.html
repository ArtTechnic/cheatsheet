container-name

With container-name, you can control name for container queries. It helps decide whether a box is shown and what happens when its contents do not fit normally.

The value written after container-name: chooses the result. While experimenting, keep in mind that hidden or clipped content may become impossible to reach, so test with more content than you expect.

Here is a compact container-name example you can inspect and alter:

container-name: none;

/* A single name */
container-name: my-layout;

/* Multiple names */
container-name: my-page-layout my-component-library;

/* Global Values */
container-name: inherit;
container-name: initial;
container-name: revert;
container-name: revert-layer;
container-name: unset;

What this example does: The colon separates container-name from its chosen value, none. The semicolon marks the end of this declaration.
