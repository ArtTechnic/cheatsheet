flex

Choose flex when the design needs different flex container/shorthand. It helps arrange children inside a layout.

A rule using flex needs a value after the colon. One useful test is to change only that value; some layout properties only work after the parent has been made a grid or flex container.

A practical flex example is shown below:

flex: 1;

What to notice: In this case flex receives 1. Trying a contrasting valid value makes the difference easier to spot.
