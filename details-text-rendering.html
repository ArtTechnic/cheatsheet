text-rendering

The browser looks at text-rendering when working out rendering optimizations for text. It changes the presentation or flow of writing.

Different values give text-rendering different instructions.

Use this text-rendering sample as a starting point, then change one piece at a time:

/* Keyword values */
text-rendering: auto;
text-rendering: optimizeSpeed;
text-rendering: optimizeLegibility;
text-rendering: geometricPrecision;

/* Global values */
text-rendering: inherit;
text-rendering: initial;
text-rendering: revert;
text-rendering: revert-layer;
text-rendering: unset;

What this example does: Here, auto is the value attached to text-rendering.
