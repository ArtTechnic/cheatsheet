animation

Think of animation as the control for animation shorthand. It controls movement or a visual change over time or space.

Add animation inside a CSS rule and follow it with a colon and value.

The code below shows a simple use of animation:

animation: 3s ease-in 1s infinite reverse both running slide-in;

What to notice: This declaration gives animation the value 3s ease-in 1s infinite reverse both running slide-in.
