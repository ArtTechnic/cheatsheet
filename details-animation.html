animation

Think of animation as the control for animation shorthand. It controls movement or a visual change over time or space.

Add animation inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Use gentle motion and remember that some visitors ask their device to reduce animation.

The code below shows a simple use of animation:

animation: 3s ease-in 1s infinite reverse both running slide-in;

What to notice: This declaration gives animation the value 3s ease-in 1s infinite reverse both running slide-in. Replace that value with another valid choice to compare the two results.
