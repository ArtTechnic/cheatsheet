border-inline-end-width

In CSS, border-inline-end-width is the setting for width of end edge of inline border. It helps decide how large a box or part of a box becomes.

A rule using border-inline-end-width needs a value after the colon.

This short sample shows border-inline-end-width in use:

border-inline-end-width: thick;
writing-mode: horizontal-tb;

How this sample works: This declaration gives border-inline-end-width the value thick.
