box-flex-group

Think of box-flex-group as the control for ordinal group for box flex. It helps arrange children inside a layout.

Add box-flex-group inside a CSS rule and follow it with a colon and value.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

Try the following box-flex-group code in a spare practice file:

/* <integer> values */
box-flex-group: 1;
box-flex-group: 5;

/* Global values */
box-flex-group: inherit;
box-flex-group: initial;
box-flex-group: unset;

Reading the example: This declaration gives box-flex-group the value 1.
