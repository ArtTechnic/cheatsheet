transition-timing-function

Changing transition-timing-function changes speed curve of transition. It controls movement or a visual change over time or space.

CSS reads this as the name transition-timing-function, a colon, and then a value.

Try the following transition-timing-function code in a spare practice file:

transition-timing-function: linear;

The important part: The important instruction in the sample is linear. It is assigned to transition-timing-function and changes only the part described above.
