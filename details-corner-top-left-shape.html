corner-top-left-shape

Think of corner-top-left-shape as the control for shape of top-left corner. It helps decide where an element sits and how it relates to nearby boxes.

A rule using corner-top-left-shape needs a value after the colon.

Important: This feature is experimental. Check browser support before relying on it.

A small corner-top-left-shape example looks like this:

/* Keyword values */
corner-top-left-shape: notch;
corner-top-left-shape: squircle;

/* superellipse() function values */
corner-top-left-shape: superellipse(3);
corner-top-left-shape: superellipse(-1.5);

/* Global values */
corner-top-left-shape: inherit;
corner-top-left-shape: initial;
corner-top-left-shape: revert;
corner-top-left-shape: revert-layer;
corner-top-left-shape: unset;

What to notice: Read the line as ‘set corner-top-left-shape to notch.’ That value is the instruction controlling what you see.
