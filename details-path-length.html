path-length

Changing path-length changes scaling factor for SVG path.

Place a colon after path-length, then supply the value you want.

Important: This feature is experimental. Check browser support before relying on it.

A small path-length example looks like this:

/* Keywords */
path-length: none;

/* <length> values */
path-length: 0;
path-length: 70;
path-length: 500;

/* Global values */
path-length: inherit;
path-length: initial;
path-length: revert;
path-length: revert-layer;
path-length: unset;

The important part: Read the line as ‘set path-length to none.’ That value is the instruction controlling what you see.
