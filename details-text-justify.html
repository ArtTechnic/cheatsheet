text-justify

The text-justify property adjusts text alignment spacing. It helps arrange children inside a layout.

Place a colon after text-justify, then supply the value you want.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

Try the following text-justify code in a spare practice file:

text-justify: none;
text-justify: auto;
text-justify: inter-word;
text-justify: inter-character;
text-justify: distribute; /* Deprecated value */

/* Global values */
text-justify: inherit;
text-justify: initial;
text-justify: revert;
text-justify: revert-layer;
text-justify: unset;

What to notice: The important instruction in the sample is none. It is assigned to text-justify and changes only the part described above.
