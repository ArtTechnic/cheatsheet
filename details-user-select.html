user-select

The browser looks at user-select when working out text selection control. It changes part of the way a visitor interacts with an element.

Add user-select inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Do not make an object look clickable unless it really performs an action.

Here is a compact user-select example you can inspect and alter:

user-select: none;

The important part: Read the line as ‘set user-select to none.’ That value is the instruction controlling what you see.
