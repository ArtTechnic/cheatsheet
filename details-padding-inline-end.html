padding-inline-end

The browser looks at padding-inline-end when working out padding on inline end edge. It changes space around, inside, or between boxes.

Add padding-inline-end inside a CSS rule and follow it with a colon and value.

A small padding-inline-end example looks like this:

padding-inline-end: 20px;
writing-mode: horizontal-tb;

What to notice: This declaration gives padding-inline-end the value 20px.
