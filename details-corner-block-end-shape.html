corner-block-end-shape

With corner-block-end-shape, you can control shape of end corner on block axis.

Add corner-block-end-shape inside a CSS rule and follow it with a colon and value.

Important: This feature is experimental. Check browser support before relying on it.

Here is a corner-block-end-shape example to try in a practice page:

/* Single keyword value set for both corners */
corner-block-end-shape: square;
corner-block-end-shape: scoop;

/* Single superellipse() value set for both corners */
corner-block-end-shape: superellipse(3.5);
corner-block-end-shape: superellipse(-1.9);

/* Block-end/inline-start corner, block-end/inline-end corner */
corner-block-end-shape: square scoop;
corner-block-end-shape: square superellipse(-1.9);

/* Global values */
corner-block-end-shape: inherit;
corner-block-end-shape: initial;
corner-block-end-shape: revert;
corner-block-end-shape: revert-layer;
corner-block-end-shape: unset;

What this example does: Read the line as ‘set corner-block-end-shape to square.’ That value is the instruction controlling what you see.
