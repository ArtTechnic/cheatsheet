offset-anchor

Use offset-anchor when you need to change anchor box for offset positioning. It controls movement or a visual change over time or space.

A rule using offset-anchor needs a value after the colon. One useful test is to change only that value; use gentle motion and remember that some visitors ask their device to reduce animation.

Try the following offset-anchor code in a spare practice file:

offset-anchor: auto;

What to notice: The colon separates offset-anchor from its chosen value, auto. The semicolon marks the end of this declaration.
