button

Use button when a piece of HTML represents button control. It is a form building block: forms let a visitor enter information, choose something, or start an action.

Treat the two button tags like the covers of a folder: the related content goes between them. Every control needs a clear label, and the page should still make sense when somebody uses only a keyboard.

Important: This feature is experimental. Check browser support before relying on it.

Here is a button example to try in a practice page:

<button class="favorite styled" type="button">Add to favorites</button>

What this example does: This sample puts button into a small piece of realistic HTML. Change its content or one attribute at a time and watch what differs.
