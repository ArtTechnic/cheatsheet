container

Changing container changes shorthand for container-type and container-name. It helps decide whether a box is shown and what happens when its contents do not fit normally.

The value written after container: chooses the result.

Here is a compact container example you can inspect and alter:

/* <container-name> */
container: my-layout;

/* <container-name> / <container-type> */
container: my-layout / size;

/* Global Values */
container: inherit;
container: initial;
container: revert;
container: revert-layer;
container: unset;

The important part: Read the line as ‘set container to my-layout.’ That value is the instruction controlling what you see.
