scroll-padding-right

In CSS, scroll-padding-right is the setting for defines the scroll-padding-right property. It changes space around, inside, or between boxes.

The value written after scroll-padding-right: chooses the result. While experimenting, keep in mind that add a temporary border while practising so you can see exactly which space moved.

The code below shows a simple use of scroll-padding-right:

scroll-padding-right: 0;

What this example does: Read the line as ‘set scroll-padding-right to 0.’ That value is the instruction controlling what you see.
