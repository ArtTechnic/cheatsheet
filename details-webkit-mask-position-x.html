-webkit-mask-position-x

Choose -webkit-mask-position-x when the design needs different defines the -webkit-mask-position-x property. It helps decide where an element sits and how it relates to nearby boxes.

Different values give -webkit-mask-position-x different instructions. Try them one at a time, and remember that positioning properties work as a team, so inspect the containing box as well as the element itself.

Important: This is not a standard feature, so different browsers may handle it differently. Treat it as something to recognize rather than a dependable first choice.

This short sample shows -webkit-mask-position-x in use:

/* Keyword values */
-webkit-mask-position-x: left;
-webkit-mask-position-x: center;
-webkit-mask-position-x: right;

/* <percentage> values */
-webkit-mask-position-x: 100%;
-webkit-mask-position-x: -50%;

/* <length> values */
-webkit-mask-position-x: 50px;
-webkit-mask-position-x: -1cm;

/* Multiple values */
-webkit-mask-position-x:
  50px,
  25%,
  -3em;

/* Global values */
-webkit-mask-position-x: inherit;
-webkit-mask-position-x: initial;
-webkit-mask-position-x: revert;
-webkit-mask-position-x: revert-layer;
-webkit-mask-position-x: unset;

How this sample works: This declaration gives -webkit-mask-position-x the value left. Replace that value with another valid choice to compare the two results.
