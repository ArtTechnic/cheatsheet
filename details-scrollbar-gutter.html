scrollbar-gutter

It helps decide whether a box is shown and what happens when its contents do not fit normally.

Place a colon after scrollbar-gutter, then supply the value you want.

Here is a scrollbar-gutter example to try in a practice page:

/* Initial value */
scrollbar-gutter: auto;

/* "stable" keyword, with optional modifier */
scrollbar-gutter: stable;
scrollbar-gutter: stable both-edges;

/* Global values */
scrollbar-gutter: inherit;
scrollbar-gutter: initial;
scrollbar-gutter: revert;
scrollbar-gutter: revert-layer;
scrollbar-gutter: unset;

What this example does: Here, auto is the value attached to scrollbar-gutter.
