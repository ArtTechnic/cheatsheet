text-overflow

Choose text-overflow when the design needs different truncated text indicator. It changes the presentation or flow of writing.

Add text-overflow inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Test several lines, long words, and zoomed text—a single short sentence can hide problems.

Try the following text-overflow code in a spare practice file:

text-overflow: clip;

What this example does: Read the line as ‘set text-overflow to clip.’ That value is the instruction controlling what you see.
