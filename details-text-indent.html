text-indent

Changing text-indent changes indent of first line in block. It changes the presentation or flow of writing.

Different values give text-indent different instructions. Try them one at a time, and remember that test several lines, long words, and zoomed text—a single short sentence can hide problems.

Here is a text-indent example to try in a practice page:

text-indent: 0;

The important part: This declaration gives text-indent the value 0. Replace that value with another valid choice to compare the two results.
