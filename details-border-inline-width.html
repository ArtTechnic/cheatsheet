border-inline-width

Use border-inline-width when you need to change width of inline-start/end borders. It helps decide how large a box or part of a box becomes.

Add border-inline-width inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Padding and borders can also affect the final visible size, especially when box-sizing changes.

A practical border-inline-width example is shown below:

border-inline-width: thick;
writing-mode: horizontal-tb;

What to notice: In this case border-inline-width receives thick. Trying a contrasting valid value makes the difference easier to spot.
