vector-effect

Think of vector-effect as the control for sVG vector effect.

Place a colon after vector-effect, then supply the value you want.

Here is a vector-effect example to try in a practice page:

/* Keywords */
vector-effect: none;
vector-effect: non-scaling-stroke;

/* Global values */
vector-effect: inherit;
vector-effect: initial;
vector-effect: revert;
vector-effect: revert-layer;
vector-effect: unset;

What to notice: In this case vector-effect receives none.
