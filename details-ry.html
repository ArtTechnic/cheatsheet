ry

Use ry when you need to change defines the ry property. It changes one particular part of the browser’s styling calculation.

A rule using ry needs a value after the colon. One useful test is to change only that value; change only this property while practising, then compare the before and after result.

A practical ry example is shown below:

/* Initial value */
ry: auto;

/* Length and percentage values */
ry: 30px;
ry: 30%;

/* Global values */
ry: inherit;
ry: initial;
ry: revert;
ry: revert-layer;
ry: unset;

What this example does: Read the line as ‘set ry to auto.’ That value is the instruction controlling what you see.
