overscroll-behavior-block

Changing overscroll-behavior-block changes overscroll in block dimension. It helps decide whether a box is shown and what happens when its contents do not fit normally.

Place a colon after overscroll-behavior-block, then supply the value you want. When testing this property, remember: hidden or clipped content may become impossible to reach, so test with more content than you expect.

Use this overscroll-behavior-block sample as a starting point, then change one piece at a time:

/* Keyword values */
overscroll-behavior-block: auto; /* default */
overscroll-behavior-block: contain;
overscroll-behavior-block: none;

/* Global values */
overscroll-behavior-block: inherit;
overscroll-behavior-block: initial;
overscroll-behavior-block: revert;
overscroll-behavior-block: revert-layer;
overscroll-behavior-block: unset;

How this sample works: In this case overscroll-behavior-block receives auto. Trying a contrasting valid value makes the difference easier to spot.
