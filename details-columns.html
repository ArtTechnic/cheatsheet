CSS

columns

The columns property controls multi-column layout shorthand. It controls how content is divided across columns, pages, or separate pieces.

CSS reads this as the name columns, a colon, and then a value. As you compare values, the browser may need enough content before the effect becomes obvious.

The code below shows a simple use of columns:

columns: 2;

What this example does: The colon separates columns from its chosen value, 2. The semicolon marks the end of this declaration.
