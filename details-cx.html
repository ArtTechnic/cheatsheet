CSS

cx

Changing cx changes x coordinate of SVG element center. It changes one particular part of the browser’s styling calculation.

Place a colon after cx, then supply the value you want. When testing this property, remember: change only this property while practising, then compare the before and after result.

Here is a cx example to try in a practice page:

/* length and percentage values */
cx: 20px;
cx: 20%;

/* Global values */
cx: inherit;
cx: initial;
cx: revert;
cx: revert-layer;
cx: unset;

Reading the example: Read the line as ‘set cx to 20px.’ That value is the instruction controlling what you see.
