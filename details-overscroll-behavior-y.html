overscroll-behavior-y

Think of overscroll-behavior-y as the control for vertical overscroll behavior. It helps decide whether a box is shown and what happens when its contents do not fit normally.

Add overscroll-behavior-y inside a CSS rule and follow it with a colon and value.

The code below shows a simple use of overscroll-behavior-y:

/* Keyword values */
overscroll-behavior-y: auto; /* default */
overscroll-behavior-y: contain;
overscroll-behavior-y: none;

/* Global values */
overscroll-behavior-y: inherit;
overscroll-behavior-y: initial;
overscroll-behavior-y: revert;
overscroll-behavior-y: revert-layer;
overscroll-behavior-y: unset;

Reading the example: The sample asks the browser to use auto for overscroll-behavior-y.
