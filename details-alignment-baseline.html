alignment-baseline

Use alignment-baseline when you need to change aligns element within its parent. It helps arrange children inside a layout.

The value written after alignment-baseline: chooses the result. While experimenting, keep in mind that some layout properties only work after the parent has been made a grid or flex container.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

Use this alignment-baseline sample as a starting point, then change one piece at a time:

/* Initial value */
alignment-baseline: baseline;

/* Keyword values */
alignment-baseline: alphabetic;
alignment-baseline: central;
alignment-baseline: ideographic;
alignment-baseline: mathematical;
alignment-baseline: middle;
alignment-baseline: text-bottom;
alignment-baseline: text-top;

/* Mapped values */
alignment-baseline: text-before-edge; /* text-top */
alignment-baseline: text-after-edge; /* text-bottom */

/* Deprecated values  */
alignment-baseline: auto;
alignment-baseline: before-edge;
alignment-baseline: after-edge;
alignment-baseline: hanging;

/* Global values */
alignment-baseline: inherit;
alignment-baseline: initial;
alignment-baseline: revert;
alignment-baseline: revert-layer;
alignment-baseline: unset;

The important part: The important instruction in the sample is baseline. It is assigned to alignment-baseline and changes only the part described above.
