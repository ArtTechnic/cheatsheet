grid

Think of grid as the control for grid container. It helps arrange children inside a layout.

Add grid inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Some layout properties only work after the parent has been made a grid or flex container.

This short sample shows grid in use:

grid: auto-flow / 1fr 1fr 1fr;

What this example does: This declaration gives grid the value auto-flow / 1fr 1fr 1fr. Replace that value with another valid choice to compare the two results.
