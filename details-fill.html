fill

With fill, you can control sVG fill color. It changes one particular part of the browser’s styling calculation.

Different values give fill different instructions. Try them one at a time, and remember that change only this property while practising, then compare the before and after result.

A small fill example looks like this:

/* keywords */
fill: none;
fill: context-fill;
fill: context-stroke;

/* <color> values */
fill: red;
fill: hsl(120deg 75% 25% / 60%);

/* <url> values */
fill: url("#gradientElementID");
fill: url("star.png");

/* <url> with fallback */
fill: url("#gradientElementID") blue;
fill: url("star.png") none;

/* Global values */
fill: inherit;
fill: initial;
fill: revert;
fill: revert-layer;
fill: unset;

Reading the example: The colon separates fill from its chosen value, none. The semicolon marks the end of this declaration.
