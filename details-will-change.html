will-change

Choose will-change when the design needs different hint for upcoming changes. It changes one particular part of the browser’s styling calculation.

Place a colon after will-change, then supply the value you want. When testing this property, remember: change only this property while practising, then compare the before and after result.

Here is a compact will-change example you can inspect and alter:

/* Keyword values */
will-change: auto;
will-change: scroll-position;
will-change: contents;

/* <custom-ident> values */
will-change: transform;
will-change: opacity;

/* multiple values */
will-change: left, top;

/* Global values */
will-change: inherit;
will-change: initial;
will-change: revert;
will-change: revert-layer;
will-change: unset;

Reading the example: The colon separates will-change from its chosen value, auto. The semicolon marks the end of this declaration.
