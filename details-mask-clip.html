mask-clip

The mask-clip property controls clip box of mask. It helps decide whether a box is shown and what happens when its contents do not fit normally.

CSS reads this as the name mask-clip, a colon, and then a value.

A small mask-clip example looks like this:

/* <coord-box> values */
mask-clip: content-box;
mask-clip: padding-box;
mask-clip: border-box;
mask-clip: fill-box;
mask-clip: stroke-box;
mask-clip: view-box;

/* Keyword values */
mask-clip: no-clip;

/* Multiple values */
mask-clip: padding-box, no-clip;
mask-clip: view-box, fill-box, border-box;

/* Global values */
mask-clip: inherit;
mask-clip: initial;
mask-clip: revert;
mask-clip: revert-layer;
mask-clip: unset;

Reading the example: In this case mask-clip receives content-box.
