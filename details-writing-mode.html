writing-mode

Use writing-mode when you need to change text direction/flow. It changes the presentation or flow of writing.

Different values give writing-mode different instructions.

The code below shows a simple use of writing-mode:

writing-mode: horizontal-tb;

What this example does: Here, horizontal-tb is the value attached to writing-mode.
