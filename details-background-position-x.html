background-position-x

Changing background-position-x changes horizontal position of background image. It changes how something looks rather than changing what the HTML means.

CSS reads this as the name background-position-x, a colon, and then a value. As you compare values, check that text remains easy to read and that important information does not depend on colour alone.

Use this background-position-x sample as a starting point, then change one piece at a time:

background-position-x: left;

What this example does: The important instruction in the sample is left. It is assigned to background-position-x and changes only the part described above.
