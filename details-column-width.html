column-width

In CSS, column-width is the setting for optimal width of columns. It helps decide how large a box or part of a box becomes.

A rule using column-width needs a value after the colon. One useful test is to change only that value; padding and borders can also affect the final visible size, especially when box-sizing changes.

Here is a compact column-width example you can inspect and alter:

column-width: auto;

How this sample works: In this case column-width receives auto. Trying a contrasting valid value makes the difference easier to spot.
