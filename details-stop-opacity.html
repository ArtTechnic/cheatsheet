stop-opacity

With stop-opacity, you can control defines the stop-opacity property. It changes how something looks rather than changing what the HTML means.

Place a colon after stop-opacity, then supply the value you want. When testing this property, remember: check that text remains easy to read and that important information does not depend on colour alone.

Use this stop-opacity sample as a starting point, then change one piece at a time:

/* numeric and percentage values */
stop-opacity: 0.2;
stop-opacity: 20%;

/* Global values */
stop-opacity: inherit;
stop-opacity: initial;
stop-opacity: revert;
stop-opacity: revert-layer;
stop-opacity: unset;

How this sample works: This declaration gives stop-opacity the value 0.2. Replace that value with another valid choice to compare the two results.
