border-bottom

Use border-bottom when you need to change shorthand for bottom border. It changes a line, edge, or corner around an element.

Add border-bottom inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Borders take up space in the box; outlines usually draw outside it without changing the layout.

A practical border-bottom example is shown below:

border-bottom: solid;

Reading the example: Here, solid is the value attached to border-bottom. Change it, refresh the page, and compare the new result with the original.
