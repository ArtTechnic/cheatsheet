box-orient

The browser looks at box-orient when working out orientation of box layout.

The value written after box-orient: chooses the result.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

This short sample shows box-orient in use:

/* Keyword values */
box-orient: horizontal;
box-orient: vertical;
box-orient: inline-axis;
box-orient: block-axis;

/* Global values */
box-orient: inherit;
box-orient: initial;
box-orient: unset;

What this example does: Read the line as ‘set box-orient to horizontal.’ That value is the instruction controlling what you see.
