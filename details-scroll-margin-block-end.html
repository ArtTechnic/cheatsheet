scroll-margin-block-end

Think of scroll-margin-block-end as the control for defines the scroll-margin-block-end property. It changes space around, inside, or between boxes.

A rule using scroll-margin-block-end needs a value after the colon. One useful test is to change only that value; add a temporary border while practising so you can see exactly which space moved.

Use this scroll-margin-block-end sample as a starting point, then change one piece at a time:

scroll-margin-block-end: 0;

The important part: The sample asks the browser to use 0 for scroll-margin-block-end. The property stays the same when you experiment; the value is the part to change.
