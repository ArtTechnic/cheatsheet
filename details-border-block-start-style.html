border-block-start-style

Choose border-block-start-style when the design needs different style of start edge of block border. It changes a line, edge, or corner around an element.

Add border-block-start-style inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Borders take up space in the box; outlines usually draw outside it without changing the layout.

Here is a compact border-block-start-style example you can inspect and alter:

border-block-start-style: dotted;
writing-mode: horizontal-tb;

Reading the example: In this case border-block-start-style receives dotted. Trying a contrasting valid value makes the difference easier to spot.
