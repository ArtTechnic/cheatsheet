line-height-step

Use line-height-step when you need to change step increment for line height. It helps decide how large a box or part of a box becomes.

The value written after line-height-step: chooses the result.

Important: This feature is experimental. Check browser support before relying on it.

A practical line-height-step example is shown below:

/* Point values */
line-height-step: 18pt;

/* Global values */
line-height-step: inherit;
line-height-step: initial;
line-height-step: revert;
line-height-step: revert-layer;
line-height-step: unset;

Reading the example: The colon separates line-height-step from its chosen value, 18pt.
