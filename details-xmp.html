xmp

When you write xmp, you are marking something as obsolete preformatted text. Think of it as an HTML building block specifically meant for obsolete preformatted text.

Anything meant to belong to xmp normally sits inside the pair of tags. Use it when that description matches the content, not simply because its default appearance seems useful.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

Here is a xmp example to try in a practice page:

<xmp>...</xmp>

What this example does: Find <xmp> in the sample first. Its attributes and enclosed content provide the information this element needs.
