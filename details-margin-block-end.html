margin-block-end

The browser looks at margin-block-end when working out margin on block end edge. It changes space around, inside, or between boxes.

CSS reads this as the name margin-block-end, a colon, and then a value. As you compare values, add a temporary border while practising so you can see exactly which space moved.

Here is a margin-block-end example to try in a practice page:

margin-block-end: 20px;
writing-mode: horizontal-tb;

What to notice: Here, 20px is the value attached to margin-block-end. Change it, refresh the page, and compare the new result with the original.
