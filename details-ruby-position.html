ruby-position

Think of ruby-position as the control for position of ruby annotation. It helps decide where an element sits and how it relates to nearby boxes.

The value written after ruby-position: chooses the result.

This short sample shows ruby-position in use:

ruby-position: over;

How this sample works: The important instruction in the sample is over. It is assigned to ruby-position and changes only the part described above.
