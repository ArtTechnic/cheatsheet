fill-rule

Changing fill-rule changes fill rule for shapes. It changes one particular part of the browser’s styling calculation.

The value written after fill-rule: chooses the result. While experimenting, keep in mind that change only this property while practising, then compare the before and after result.

This short sample shows fill-rule in use:

/* keywords */
fill-rule: evenodd;
fill-rule: nonzero;

/* Global values */
fill-rule: inherit;
fill-rule: initial;
fill-rule: revert;
fill-rule: revert-layer;
fill-rule: unset;

What this example does: In this case fill-rule receives evenodd. Trying a contrasting valid value makes the difference easier to spot.
