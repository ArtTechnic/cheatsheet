column-rule-visibility-items

It helps decide whether a box is shown and what happens when its contents do not fit normally.

Add column-rule-visibility-items inside a CSS rule and follow it with a colon and value.

Important: This feature is experimental. Check browser support before relying on it.

The code below shows a simple use of column-rule-visibility-items:

column-rule-visibility-items: all;

How this sample works: The important instruction in the sample is all. It is assigned to column-rule-visibility-items and changes only the part described above.
