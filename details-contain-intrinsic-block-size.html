contain-intrinsic-block-size

With contain-intrinsic-block-size, you can control intrinsic block size of contained element. It helps decide how large a box or part of a box becomes.

Different values give contain-intrinsic-block-size different instructions. Try them one at a time, and remember that padding and borders can also affect the final visible size, especially when box-sizing changes.

Use this contain-intrinsic-block-size sample as a starting point, then change one piece at a time:

/* Keyword values */
contain-intrinsic-block-size: none;

/* <length> values */
contain-intrinsic-block-size: 1000px;
contain-intrinsic-block-size: 10rem;

/* auto <length> */
contain-intrinsic-block-size: auto 300px;

/* Global values */
contain-intrinsic-block-size: inherit;
contain-intrinsic-block-size: initial;
contain-intrinsic-block-size: revert;
contain-intrinsic-block-size: revert-layer;
contain-intrinsic-block-size: unset;

Reading the example: This declaration gives contain-intrinsic-block-size the value none. Replace that value with another valid choice to compare the two results.
