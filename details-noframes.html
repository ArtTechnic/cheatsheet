noframes

The name noframes tells you what it represents: frame fallback. Think of it as an HTML building block specifically meant for frame fallback.

Anything meant to belong to noframes normally sits inside the pair of tags. Use it when that description matches the content, not simply because its default appearance seems useful.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

Here is a noframes example to try in a practice page:

<!doctype html>
<html lang="en-US">
  <head>
    <!-- Document metadata goes here -->
  </head>
  <frameset rows="45%, 55%">
    <frame src="https://developer.mozilla.org/en/HTML/Element/frameset" />
    <frame src="https://developer.mozilla.org/en/HTML/Element/frame" />
    <noframes>
      <p>
        It seems your browser does not support frames or is configured to not
        allow them.
      </p>
    </noframes>
  </frameset>
</html>

What to notice: Start with the noframes tag in the code, then inspect what sits inside it and which attributes have been added to its opening tag.
