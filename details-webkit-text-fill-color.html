-webkit-text-fill-color

It changes how something looks rather than changing what the HTML means.

CSS reads this as the name -webkit-text-fill-color, a colon, and then a value.

Here is a compact -webkit-text-fill-color example you can inspect and alter:

/* <color> values */
-webkit-text-fill-color: red;
-webkit-text-fill-color: #123456;
-webkit-text-fill-color: rgb(100 200 0);

/* Global values */
-webkit-text-fill-color: inherit;
-webkit-text-fill-color: initial;
-webkit-text-fill-color: revert;
-webkit-text-fill-color: revert-layer;
-webkit-text-fill-color: unset;

Reading the example: Read the line as ‘set -webkit-text-fill-color to red.’ That value is the instruction controlling what you see.
