clear

The browser looks at clear when working out clear floats. It helps decide where an element sits and how it relates to nearby boxes.

A rule using clear needs a value after the colon.

Here is a compact clear example you can inspect and alter:

clear: none;

What to notice: The sample asks the browser to use none for clear.
