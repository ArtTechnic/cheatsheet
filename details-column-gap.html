column-gap

With column-gap, you can control gap between columns. It changes space around, inside, or between boxes.

A rule using column-gap needs a value after the colon. One useful test is to change only that value; add a temporary border while practising so you can see exactly which space moved.

A small column-gap example looks like this:

column-gap: 0;

How this sample works: The important instruction in the sample is 0. It is assigned to column-gap and changes only the part described above.
