border-block-end-width

With border-block-end-width, you can control width of end edge of block border. It helps decide how large a box or part of a box becomes.

A rule using border-block-end-width needs a value after the colon.

A practical border-block-end-width example is shown below:

border-block-end-width: thick;
writing-mode: horizontal-tb;

What this example does: The sample asks the browser to use thick for border-block-end-width.
