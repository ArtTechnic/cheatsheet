border-block-end-width

With border-block-end-width, you can control width of end edge of block border. It helps decide how large a box or part of a box becomes.

A rule using border-block-end-width needs a value after the colon. One useful test is to change only that value; padding and borders can also affect the final visible size, especially when box-sizing changes.

A practical border-block-end-width example is shown below:

border-block-end-width: thick;
writing-mode: horizontal-tb;

What this example does: The sample asks the browser to use thick for border-block-end-width. The property stays the same when you experiment; the value is the part to change.
