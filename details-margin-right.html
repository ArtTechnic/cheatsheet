margin-right

Choose margin-right when the design needs different right margin. It changes space around, inside, or between boxes.

A rule using margin-right needs a value after the colon. One useful test is to change only that value; add a temporary border while practising so you can see exactly which space moved.

This short sample shows margin-right in use:

margin-right: 1em;

What to notice: Read the line as ‘set margin-right to 1em.’ That value is the instruction controlling what you see.
