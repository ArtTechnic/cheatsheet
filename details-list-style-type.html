list-style-type

In CSS, list-style-type is the setting for type of list marker. It changes list markers, numbering, or generated punctuation.

Add list-style-type inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Keep the result understandable even when custom decoration is unavailable.

Here is a list-style-type example to try in a practice page:

list-style-type: space-counter;

The important part: Read the line as ‘set list-style-type to space-counter.’ That value is the instruction controlling what you see.
