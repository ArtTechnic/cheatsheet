rb

When you write rb, you are marking something as ruby base text. Think of it as an HTML building block specifically meant for ruby base text.

Anything meant to belong to rb normally sits inside the pair of tags. Use it when that description matches the content, not simply because its default appearance seems useful.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

This short sample shows rb in use:

<ruby>
  <rb>漢</rb><rb>字 </rb><rp>(</rp><rt>kan</rt><rt>ji</rt><rp>)</rp>
</ruby>

The important part: Find <rb> in the sample first. Its attributes and enclosed content provide the information this element needs.
