border-inline-end-color

Think of border-inline-end-color as the control for color of end edge of inline border. It changes how something looks rather than changing what the HTML means.

Add border-inline-end-color inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Check that text remains easy to read and that important information does not depend on colour alone.

A practical border-inline-end-color example is shown below:

border-inline-end-color: red;
writing-mode: horizontal-tb;

What this example does: Read the line as ‘set border-inline-end-color to red.’ That value is the instruction controlling what you see.
