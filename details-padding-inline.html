padding-inline

Choose padding-inline when the design needs different shorthand for inline-direction padding. It changes space around, inside, or between boxes.

A rule using padding-inline needs a value after the colon. One useful test is to change only that value; add a temporary border while practising so you can see exactly which space moved.

Here is a compact padding-inline example you can inspect and alter:

padding-inline: 5% 10%;
writing-mode: horizontal-tb;

The important part: This declaration gives padding-inline the value 5% 10%. Replace that value with another valid choice to compare the two results.
