white-space

Use white-space when you need to change whitespace handling. It changes one particular part of the browser’s styling calculation.

Different values give white-space different instructions. Try them one at a time, and remember that change only this property while practising, then compare the before and after result.

Here is a white-space example to try in a practice page:

white-space: normal;

The important part: In this case white-space receives normal. Trying a contrasting valid value makes the difference easier to spot.
