text-emphasis-color

Changing text-emphasis-color changes color of text emphasis. It changes how something looks rather than changing what the HTML means.

Add text-emphasis-color inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Check that text remains easy to read and that important information does not depend on colour alone.

Use this text-emphasis-color sample as a starting point, then change one piece at a time:

text-emphasis-color: currentColor;

What this example does: Read the line as ‘set text-emphasis-color to currentColor.’ That value is the instruction controlling what you see.
