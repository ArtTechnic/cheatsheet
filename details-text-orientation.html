text-orientation

With text-orientation, you can control orientation of text characters. It changes the presentation or flow of writing.

A rule using text-orientation needs a value after the colon. One useful test is to change only that value; test several lines, long words, and zoomed text—a single short sentence can hide problems.

A small text-orientation example looks like this:

writing-mode: vertical-rl;
text-orientation: mixed;

Reading the example: The important instruction in the sample is vertical-rl. It is assigned to text-orientation and changes only the part described above.
