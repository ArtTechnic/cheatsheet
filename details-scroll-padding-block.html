scroll-padding-block

In CSS, scroll-padding-block is the setting for defines the scroll-padding-block property. It changes space around, inside, or between boxes.

Place a colon after scroll-padding-block, then supply the value you want. When testing this property, remember: add a temporary border while practising so you can see exactly which space moved.

Try the following scroll-padding-block code in a spare practice file:

scroll-padding-block: 0;

How this sample works: The colon separates scroll-padding-block from its chosen value, 0. The semicolon marks the end of this declaration.
