box-pack

Choose box-pack when the design needs different how content is packed in box.

Place a colon after box-pack, then supply the value you want.

Important: This is an older feature. You may meet it in old websites, but you should normally choose a modern alternative for new work.

This short sample shows box-pack in use:

/* Keyword values */
box-pack: start;
box-pack: center;
box-pack: end;
box-pack: justify;

/* Global values */
box-pack: inherit;
box-pack: initial;
box-pack: unset;

How this sample works: This declaration gives box-pack the value start.
