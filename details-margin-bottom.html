margin-bottom

Think of margin-bottom as the control for bottom margin. It changes space around, inside, or between boxes.

Different values give margin-bottom different instructions. Try them one at a time, and remember that add a temporary border while practising so you can see exactly which space moved.

A small margin-bottom example looks like this:

margin-bottom: 1em;

What to notice: The sample asks the browser to use 1em for margin-bottom. The property stays the same when you experiment; the value is the part to change.
