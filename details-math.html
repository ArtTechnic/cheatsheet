math

Use math when a piece of HTML represents mathML container. Think of it as an HTML building block specifically meant for mathml container.

Anything meant to belong to math normally sits inside the pair of tags. Use it when that description matches the content, not simply because its default appearance seems useful.

This short sample shows math in use:

<p>One half can be written as:
    <math>
        <mfrac>
            <mn>1</mn>
            <mn>2</mn>
        </mfrac>
    </math>
</p>

How this sample works: Here math supplies the meaning described above; the surrounding tags provide the context needed for the example to make sense.
