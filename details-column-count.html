column-count

Changing column-count changes number of columns. It controls how content is divided across columns, pages, or separate pieces.

A rule using column-count needs a value after the colon.

This short sample shows column-count in use:

column-count: 2;

What to notice: The important instruction in the sample is 2. It is assigned to column-count and changes only the part described above.
