text-shadow

In CSS, text-shadow is the setting for shadow for text. It changes how something looks rather than changing what the HTML means.

Different values give text-shadow different instructions.

The code below shows a simple use of text-shadow:

text-shadow: 1px 1px 2px pink;

Reading the example: This declaration gives text-shadow the value 1px 1px 2px pink.
