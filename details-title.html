title

Browsers read title as a label meaning document title. It gives the browser information about the document rather than adding an ordinary object inside the visible page.

Treat the two title tags like the covers of a folder: the related content goes between them. Although visitors may not see it in the page itself, it can affect browser tabs, search results, or how the document is interpreted.

A practical title example is shown below:

<title>Grandma's Heavy Metal Festival Journal</title>

How this sample works: Start with the title tag in the code, then inspect what sits inside it and which attributes have been added to its opening tag.
