caret-shape

Think of caret-shape as the control for shape of text caret. It changes part of the way a visitor interacts with an element.

A rule using caret-shape needs a value after the colon.

Important: This feature is experimental. Check browser support before relying on it.

A practical caret-shape example is shown below:

caret-shape: auto;

What this example does: The sample asks the browser to use auto for caret-shape.
