grid-template-columns

With grid-template-columns, you can control column tracks. It helps arrange children inside a layout.

Add grid-template-columns inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Some layout properties only work after the parent has been made a grid or flex container.

Use this grid-template-columns sample as a starting point, then change one piece at a time:

grid-template-columns: 60px 60px;

Reading the example: The colon separates grid-template-columns from its chosen value, 60px 60px. The semicolon marks the end of this declaration.
