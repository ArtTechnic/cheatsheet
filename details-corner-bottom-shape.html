corner-bottom-shape

Changing corner-bottom-shape changes shape of bottom edge corners. It helps decide where an element sits and how it relates to nearby boxes.

Add corner-bottom-shape inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Positioning properties work as a team, so inspect the containing box as well as the element itself.

Important: This feature is experimental. Check browser support before relying on it.

Use this corner-bottom-shape sample as a starting point, then change one piece at a time:

/* Single keyword value set for both corners */
corner-bottom-shape: scoop;
corner-bottom-shape: square;

/* Single superellipse() value set for both corners */
corner-bottom-shape: superellipse(0.7);
corner-bottom-shape: superellipse(-2.8);

/* Left-hand corner, right-hand corner */
corner-bottom-shape: scoop square;
corner-bottom-shape: scoop superellipse(0.7);

/* Global values */
corner-bottom-shape: inherit;
corner-bottom-shape: initial;
corner-bottom-shape: revert;
corner-bottom-shape: revert-layer;
corner-bottom-shape: unset;

The important part: In this case corner-bottom-shape receives scoop. Trying a contrasting valid value makes the difference easier to spot.
