scroll-padding-block-start

It changes space around, inside, or between boxes.

A rule using scroll-padding-block-start needs a value after the colon.

A practical scroll-padding-block-start example is shown below:

scroll-padding-block-start: 0;

The important part: The important instruction in the sample is 0. It is assigned to scroll-padding-block-start and changes only the part described above.
