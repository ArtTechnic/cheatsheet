scroll-padding-block-start

Changing scroll-padding-block-start changes defines the scroll-padding-block-start property. It changes space around, inside, or between boxes.

A rule using scroll-padding-block-start needs a value after the colon. One useful test is to change only that value; add a temporary border while practising so you can see exactly which space moved.

A practical scroll-padding-block-start example is shown below:

scroll-padding-block-start: 0;

The important part: The important instruction in the sample is 0. It is assigned to scroll-padding-block-start and changes only the part described above.
