position-anchor

With position-anchor, you can control anchor box for absolutely positioned element. It helps decide where an element sits and how it relates to nearby boxes.

Add position-anchor inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Positioning properties work as a team, so inspect the containing box as well as the element itself.

Important: This is not a standard feature, so different browsers may handle it differently. Treat it as something to recognize rather than a dependable first choice.

This short sample shows position-anchor in use:

/* Single values */
position-anchor: normal;
position-anchor: auto;
position-anchor: none;
position-anchor: --anchor-name;
position-anchor: match-parent;

/* Global values */
position-anchor: inherit;
position-anchor: initial;
position-anchor: revert;
position-anchor: revert-layer;
position-anchor: unset;

The important part: The sample asks the browser to use normal for position-anchor. The property stays the same when you experiment; the value is the part to change.
