margin-inline

Think of margin-inline as the control for shorthand for inline-direction margins. It changes space around, inside, or between boxes.

A rule using margin-inline needs a value after the colon.

A practical margin-inline example is shown below:

margin-inline: 5% 10%;
writing-mode: horizontal-tb;

Reading the example: Read the line as ‘set margin-inline to 5% 10%.’ That value is the instruction controlling what you see.
