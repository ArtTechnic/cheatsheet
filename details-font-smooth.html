font-smooth

Think of font-smooth as the control for antialiasing of fonts. It changes the presentation or flow of writing.

Place a colon after font-smooth, then supply the value you want.

Important: This is not a standard feature, so different browsers may handle it differently. Treat it as something to recognize rather than a dependable first choice.

Use this font-smooth sample as a starting point, then change one piece at a time:

/* Keyword values */
font-smooth: auto;
font-smooth: never;
font-smooth: always;

/* <length> value */
font-smooth: 2em;

/* Global values */
font-smooth: inherit;
font-smooth: initial;
font-smooth: revert;
font-smooth: revert-layer;
font-smooth: unset;

The important part: The sample asks the browser to use auto for font-smooth.
