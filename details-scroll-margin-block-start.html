scroll-margin-block-start

Changing scroll-margin-block-start changes defines the scroll-margin-block-start property. It changes space around, inside, or between boxes.

A rule using scroll-margin-block-start needs a value after the colon. One useful test is to change only that value; add a temporary border while practising so you can see exactly which space moved.

Use this scroll-margin-block-start sample as a starting point, then change one piece at a time:

scroll-margin-block-start: 0;

What this example does: In this case scroll-margin-block-start receives 0. Trying a contrasting valid value makes the difference easier to spot.
