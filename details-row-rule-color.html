row-rule-color

The browser looks at row-rule-color when working out color of row rule. It changes how something looks rather than changing what the HTML means.

Add row-rule-color inside a CSS rule and follow it with a colon and value.

Important: This feature is experimental. Check browser support before relying on it.

A practical row-rule-color example is shown below:

row-rule-color: magenta;

The important part: Here, magenta is the value attached to row-rule-color.
