row-rule-color

The browser looks at row-rule-color when working out color of row rule. It changes how something looks rather than changing what the HTML means.

Add row-rule-color inside a CSS rule and follow it with a colon and value. A helpful beginner check is this: Check that text remains easy to read and that important information does not depend on colour alone.

Important: This feature is experimental. Check browser support before relying on it.

A practical row-rule-color example is shown below:

row-rule-color: magenta;

The important part: Here, magenta is the value attached to row-rule-color. Change it, refresh the page, and compare the new result with the original.
