font-synthesis-position

With font-synthesis-position, you can control whether position is synthesized. It helps decide where an element sits and how it relates to nearby boxes.

A rule using font-synthesis-position needs a value after the colon.

Important: This feature is experimental. Check browser support before relying on it.

Use this font-synthesis-position sample as a starting point, then change one piece at a time:

/* Keyword values */
font-synthesis-position: auto;
font-synthesis-position: none;

/* Global values */
font-synthesis-position: inherit;
font-synthesis-position: initial;
font-synthesis-position: revert;
font-synthesis-position: revert-layer;
font-synthesis-position: unset;

Reading the example: Read the line as ‘set font-synthesis-position to auto.’ That value is the instruction controlling what you see.
