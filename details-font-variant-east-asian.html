font-variant-east-asian

In CSS, font-variant-east-asian is the setting for glyph variants for East Asian. It changes the presentation or flow of writing.

A rule using font-variant-east-asian needs a value after the colon. One useful test is to change only that value; test several lines, long words, and zoomed text—a single short sentence can hide problems.

A practical font-variant-east-asian example is shown below:

font-variant-east-asian: normal;

How this sample works: Read the line as ‘set font-variant-east-asian to normal.’ That value is the instruction controlling what you see.
