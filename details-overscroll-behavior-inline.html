overscroll-behavior-inline

Changing overscroll-behavior-inline changes overscroll in inline dimension. It changes the presentation or flow of writing.

Add overscroll-behavior-inline inside a CSS rule and follow it with a colon and value.

The code below shows a simple use of overscroll-behavior-inline:

/* Keyword values */
overscroll-behavior-inline: auto; /* default */
overscroll-behavior-inline: contain;
overscroll-behavior-inline: none;

/* Global values */
overscroll-behavior-inline: inherit;
overscroll-behavior-inline: initial;
overscroll-behavior-inline: revert;
overscroll-behavior-inline: revert-layer;
overscroll-behavior-inline: unset;

How this sample works: Read the line as ‘set overscroll-behavior-inline to auto.’ That value is the instruction controlling what you see.
