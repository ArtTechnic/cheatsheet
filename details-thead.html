thead

The thead element groups together the header rows at the top of your table. A header row is the row that labels each column -- like the column titles in a spreadsheet. In the example, "Day" and "Hours" are the headers because they tell you what the data below them means.

In your HTML code, write the thead before the tbody. Even though the browser always puts the header row at the top visually, keeping your code in the right order makes it easier for you and other developers to read and understand later. The thead is also where you put scope="col" on your th cells so screen readers know which column each header labels.

The example below shows a table with a header row and one data row. The headers describe what each column contains.



<table>
    <thead>
        <tr><th scope="col">Day</th><th scope="col">Hours</th></tr>
    </thead>
    <tbody>
        <tr><td>Monday</td><td>6</td></tr>
    </tbody>
</table>
